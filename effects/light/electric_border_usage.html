Electric Border v1.0.0

沿宿主外圍持續移動的彩色光帶。零件只負責光效與動畫；宿主負責尺寸、背景、內容、顏色與強度。

基本使用

<article class="slowly-electric-border is-active">...</article>
active：彩色光沿外圍移動

啟用 / 停用

加入 .is-active 啟用；移除即停用。零件不綁 Favorite 或任何業務狀態。

宿主可調變數

--slowly-electric-color-1
--slowly-electric-color-2
--slowly-electric-color-3
--slowly-electric-color-4
--slowly-electric-speed
--slowly-electric-width
--slowly-electric-blur
--slowly-electric-opacity
--slowly-electric-radius

宿主覆寫範例

.my-card {
  --slowly-electric-color-1: rgb(255, 0, 90);
  --slowly-electric-color-2: rgb(0, 210, 255);
  --slowly-electric-color-3: rgb(170, 70, 255);
  --slowly-electric-color-4: rgb(80, 255, 160);
  --slowly-electric-speed: 1.8s;
  --slowly-electric-width: 3px;
  --slowly-electric-blur: 14px;
  --slowly-electric-opacity: .95;
  --slowly-electric-radius: 20px;
}

邊界

不控制宿主背景、不控制尺寸、不判斷 Favorite、不操作 DOM、不保存狀態。宿主自行決定何時切換 .is-active。

使用者偏好減少動態效果時，動畫停止並保留靜態光效。
