Slowly Data Search Sort Component

純前端搜尋與排序元件。組合 Fiction Search 與 Fiction Sort，只處理資料瀏覽控制，不負責儲存、CRUD、Filter 或 Pagination。

載入

請依照下列順序載入。Fiction Search 與 Fiction Sort 都是必要依賴。

<link rel="stylesheet"
  href="https://lib.stillnessbyslowly.com/ui/responsive.css">

<link rel="stylesheet"
  href="https://lib.stillnessbyslowly.com/component/data/data_search_sort_component.css">

<script src="https://lib.stillnessbyslowly.com/fiction/Fiction_search.js"></script>
<script src="https://lib.stillnessbyslowly.com/fiction/Fiction_sort.js"></script>
<script src="https://lib.stillnessbyslowly.com/component/data/data_search_sort_component.js"></script>

最簡單呼叫

<div id="search-sort"></div>
<div id="result"></div>

<script>
  const data = [
    { title: "作品 A", createdAt: "2026-09-08T10:00:00" },
    { title: "作品 B", createdAt: "2026-09-07T10:00:00" }
  ];

  const component = SlowlyDataSearchSort.create({
    target: "#search-sort",
    data,
    search: {
      fields: ["title"]
    },
    sort: {
      options: [
        {
          value: "newest",
          label: "最新建立",
          field: "createdAt",
          direction: "desc",
          type: "date"
        },
        {
          value: "title",
          label: "標題",
          field: "title",
          direction: "asc",
          type: "string"
        }
      ]
    },
    onChange(result) {
      console.log(result);
    }
  });
</script>

必要設定

設定說明
target元件掛載位置。可傳 selector 字串或 HTMLElement。
data要搜尋與排序的原始資料陣列。

元件不負責 storage。資料可來自 localStorage、API、其他元件或宿主自己的陣列。

Search

search: {
  fields: ["title", "author", "tags"],
  placeholder: "搜尋標題、作者或標籤",
  label: "搜尋"
}
設定說明
fields指定要搜尋的欄位，可使用巢狀欄位路徑。未指定時由 Fiction Search 搜尋資料項目的值。
placeholder搜尋輸入框提示文字，預設為「搜尋」。
label搜尋欄位標籤，預設為「搜尋」。

如果宿主只需要排序，可設定：

search: false

Sort

sort: {
  defaultValue: "newest",
  label: "排序",
  options: [
    {
      value: "newest",
      label: "最新建立",
      field: "createdAt",
      direction: "desc",
      type: "date"
    }
  ]
}
設定說明
defaultValue預設選取的排序 option value。未指定或找不到時使用第一個 option。
label排序欄位標籤，預設為「排序」。
options排序選項陣列。啟用 sort 時至少需要一個。

Sort Option

設定說明
value必填。select 使用的唯一值。
label必填。顯示文字。
field排序欄位，預設 createdAt，可使用巢狀欄位路徑。
directionasc 或 desc，其他值會視為 asc。
typeauto、number、date、string。預設 auto。
compare可傳自訂比較函式，交給 Fiction Sort 使用。

如果宿主只需要搜尋，可設定：

sort: false

search 與 sort 可以單獨停用其中一個，但不可同時停用。

onChange

onChange(result) {
  renderList(result);
}

搜尋文字、排序選項或 data 改變後，元件會依序執行：Fiction Search → Fiction Sort → onChange(result)。

元件只回傳處理後的資料，不負責結果列表怎麼顯示。

已 create 後

component.setData(newData);
component.refresh();
const result = component.getResult();
component.destroy();
方法用途
setData(data)替換原始資料並立即重新搜尋、排序與回傳結果。
refresh()使用目前 data、搜尋文字與排序選項重新處理結果。
getResult()取得目前處理完成的結果陣列。
destroy()移除事件與元件內容。destroy 後不可再呼叫其他操作方法。

改色

Slowly Data Search Sort 的 CSS 只處理搜尋／排序基本排列、表單不爆版、focus 可辨識與窄容器堆疊。宿主不需要修改 data_search_sort_component.css，可直接覆寫 .slowly-data-search-sort 的 CSS Variables。

#search-sort .slowly-data-search-sort {
  --sdss-text: var(--text);
  --sdss-line: var(--line);
  --sdss-accent: var(--accent);
}

原則：Component 負責結構與功能，宿主頁面負責自己的視覺。Responsive 依元件自己的容器寬度處理，不依整台裝置 viewport。
