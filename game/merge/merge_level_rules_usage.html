Merge Level Rules｜使用說明

單純比較兩個等級是否相同、有效、低於最大等級，回傳是否能合併升一級。

正式 HTTPS 引用順序

<script src="https://lib.stillnessbyslowly.com/game/merge/merge_level_rules.js"></script>

以上為 GitHub Pages 完成部署後的預期路徑。若尚未上傳，網址不會自動存在。

公開 API

window.SlowlyMergeLevelRules，版本 1.0.0。

inspect_merge({first_level, second_level, max_level, empty_level?, eligible_first?, eligible_second?})。

參數與單位

first_level／second_level／max_level 是非負安全整數；empty_level 預設 null，可由宿主指定 0 或其他整數；eligible_first／eligible_second 是可選布林值。

回傳結果

回傳 {mergeable, next_level, reason}；失敗時 next_level=null，reason 為 empty／ineligible／different_levels／max_level。成功 reason=mergeable。

實際宿主接法

const result = SlowlyMergeLevelRules.inspect_merge({
  first_level: 0, second_level: 0, max_level: 6, empty_level: null
}); // {mergeable:true,next_level:1,reason:'mergeable'}

錯誤／退化情境

非法等級、非整數、非有限值會擲錯；預設「0」是合法級別，只有宿主明確設 empty_level=0 才會視作空格。

職責邊界、清理與限制

不看碰撞、無法自動消除格子或水果；升級後物件、級別圖像、合併鎖與計分由宿主處理。

除了有狀態零件需在宿主結束局面時呼叫 reset()，其餘純運算 API 不保留 DOM 監聽器，也不需 destroy。所有輸入時間單位、可選依賴及限制以上述公開函式契約為準。
