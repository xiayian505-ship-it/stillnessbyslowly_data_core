Action Playback｜動作演出協調

逐次取得已結算動作、播放演出、至多一次命中通知、顯示結果；不預取後續動作。

載入方式

將以下 URL 作為 script src，並按需要先載入既有依賴：

https://lib.stillnessbyslowly.com/state/action_playback.js

本 ZIP 是待合併更新包，URL 代表部署後的預定位置，並非已確認在線。

公開全域 API

SlowlyActionPlayback｜1.0.0

方法說明
create(options)必填 nextAction、playAction、presentState callbacks；可選 onImpact、shouldStop、onComplete、onCancel、onError。
start()Promise<{ status, count, error }>；執行中呼叫同一 Promise，不重跑。
cancel()中止後續動作並通知目前 controls.signal；不可回滾宿主已結算內容。
isRunning()查詢目前是否執行中。
getState()回傳不可直接修改內部狀態的快照。

最小使用範例

const playback = SlowlyActionPlayback.create({
  nextAction: () => getOneResolvedAction(),
  playAction: (action, controls) => animate(action, controls.impact),
  onImpact: action => playImpactSound(action),
  presentState: action => drawBattleState(action.after),
  shouldStop: action => Boolean(action.after?.outcome)
});
const result = await playback.start();

依賴、限制、宿主責任

nextAction 一次只取得一個已結算動作；絕不預算後續動作。controls.impact() 每動作最多只呼叫 onImpact 一次；playAction 完成後才 presentState。animationError: "present"（預設，動畫失敗仍呈現已結算結果）或 "stop"；cancel() 只中止後續流程，已結算內容不回滾，宿主的非同步 callback 應留意 controls.signal。宿主自行結束回合。
