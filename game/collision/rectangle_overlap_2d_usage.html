rectangle_overlap_2d｜使用說明

功能：純二維軸對齊矩形 AABB 重疊檢查

公開 API

`SlowlyRectangleOverlap2D.inspect(first_rectangle,second_rectangle,options?)`、`overlaps(...)`。

依賴與載入順序

無（零件本體沒有其他軍火庫依賴）

<script src="https://lib.stillnessbyslowly.com/game/collision/rectangle_overlap_2d.js"></script>

以上是部署後的 HTTPS 絕對網址，必須先上傳新零件才會存在；依賴 JS 必須先載入。

輸入參數

`rectangle={x,y,width,height}`，寬高非負；`options.inclusive=true` 時正面積矩形只接邊亦視為接觸，預設接邊不算重疊。零面積永不視為碰撞。

回傳結果

`inspect` 回傳 `{overlapping,overlap_x,overlap_y,touching}`；`overlaps` 回傳布林。

宿主實際接法

const first = { x: 0, y: 0, width: 20, height: 15 };
const second = { x: 18, y: 3, width: 10, height: 12 };
const overlap = SlowlyRectangleOverlap2D.inspect(first, second);
console.log(overlap.overlapping, overlap.overlap_x);

限制與錯誤

不支援旋轉矩形、反彈、物理推離、角色扣血；非法／負尺寸明確拒絕。

JS 會針對非法資料或缺少依賴明確拋出錯誤；宿主應自行 try/catch 處理使用者輸入。純計算零件沒有 destroy 生命週期；Undo 使用 clear 清空歷史。外觀、聲音與動畫完全由宿主控制。
