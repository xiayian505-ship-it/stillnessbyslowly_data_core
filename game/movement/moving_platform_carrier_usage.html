Moving Platform Carrier｜使用說明

在宿主已確認支撐的情況下，將平台的前後位置差轉移到乘載物。可選擇用既有矩形檢查搜尋候選平台。

正式 HTTPS 引用順序

<script src="https://lib.stillnessbyslowly.com/game/collision/rectangle_overlap_2d.js"></script>
<script src="https://lib.stillnessbyslowly.com/game/movement/moving_platform_carrier.js"></script>

以上為 GitHub Pages 完成部署後的預期路徑。若尚未上傳，網址不會自動存在。

公開 API

window.SlowlyMovingPlatformCarrier，版本 1.0.0。

carry({position, platform_previous, platform_current, supported})；find_support({actor_rectangle, candidates, rectangle_of?, is_eligible?})。

參數與單位

position、platform_previous、platform_current 都是 {x,y} 有限數字；supported 必須由宿主提供布林值；find_support 的候選預設是 {rectangle:{x,y,width,height}}，支援 rectangle_of／is_eligible callback。

回傳結果

carry 回傳 {supported, displacement:{x,y}, carried_position:{x,y}}；find_support 回傳 {supported, platform, index}。無支撐時位移為 0。

實際宿主接法

const support = SlowlyMovingPlatformCarrier.find_support({
  actor_rectangle: {x:4,y:8,width:2,height:2},
  candidates: [{rectangle:{x:0,y:10,width:12,height:2}}]
});
const result = SlowlyMovingPlatformCarrier.carry({
  position:{x:4,y:8}, platform_previous:{x:0,y:10},
  platform_current:{x:1,y:10}, supported:support.supported
});

錯誤／退化情境

缺少 required 點、坐標非法、supported 非布林會擲錯；呼叫 find_support 缺少 SlowlyRectangleOverlap2D.inspect 會擲錯。

職責邊界、清理與限制

find_support 僅為幾何候選，是否真正著地／站在平台上仍由宿主或 One Way Platform Contact 判定。候選同水平中心距離時，以輸入陣列先後決勝；宿主可預先排序。

除了有狀態零件需在宿主結束局面時呼叫 reset()，其餘純運算 API 不保留 DOM 監聽器，也不需 destroy。所有輸入時間單位、可選依賴及限制以上述公開函式契約為準。
