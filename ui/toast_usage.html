Toast 使用說明

載入

<link
  rel="stylesheet"
  href="https://lib.stillnessbyslowly.com/ui/toast.css"
>

<script
  src="https://lib.stillnessbyslowly.com/ui/toast.js"
></script>

HTML

<div
  id="toast"
  class="slowly-toast"
  role="status"
></div>

toast.css 只提供必要的顯示 / 隱藏狀態。 位置、背景、字色、圓角、陰影等視覺由宿主自行設定。

JavaScript

const toast =
  SlowlyToast.create("#toast", {
    duration: 1800
  });

toast.show("儲存完成");

單次覆寫 duration

toast.show("顯示久一點", {
  duration: 3000
});

手動隱藏

toast.hide();

不自動隱藏

toast.show("持續顯示", {
  duration: 0
});

宿主自訂外觀

.slowly-toast {
  position: fixed;
  left: 50%;
  bottom: 24px;
  transform: translateX(-50%);
  padding: 10px 14px;
  border-radius: 999px;
  background: #222;
  color: #fff;
}

CSS 變數

.slowly-toast {
  --slowly-toast-duration: 220ms;
}

API

SlowlyToast.create(target, options)

instance.show(message, options)
instance.hide()
instance.destroy()

同一個元素重複呼叫 SlowlyToast.create() 會回傳同一個既有實例。
