Circle Collision 使用說明

獨立判定兩個圓形的接觸與重疊深度，圓形恰好相切預設算接觸。

部署引用與順序

<script src="https://lib.stillnessbyslowly.com/game/collision/circle_collision.js"></script>

公開 API：window.SlowlyCircleCollision

inspect(first_circle, second_circle, {inclusive=true}) → {distance, radius_sum, touching, exactly_tangent, overlap_depth}。
  touches(first_circle, second_circle, options?) → boolean。
  輸入 x/y/radius 必須為有限數字，半徑不可為負數；半徑 0 合法。
  只回傳幾何資料，不執行扣血、擊退、獎勵或物理碰撞回應。

宿主呼叫範例

const result = SlowlyCircleCollision.inspect(
    { x: 20, y: 30, radius: 10 },
    { x: 36, y: 30, radius: 8 }
  );
  console.log(result.touching, result.distance, result.overlap_depth);

  // 若要「必須穿透才算」：
  const touching_only_if_overlapping = SlowlyCircleCollision.touches(
    first_circle, second_circle, { inclusive: false }
  );

使用邊界

本零件遵循 IIFE + window 全域 API。宿主決定顏色、字型、角色、遊戲規則、渲染與操作 UI。凡涉及現有軍火庫能力，僅透過上方 HTTPS 絕對 URL 載入，不複製原碼。

程式未壓縮，Demo 僅供操作，Test 會逐項實際 PASS／FAIL。手機操作與跨瀏覽器相容性仍請以部署後設備實測。
