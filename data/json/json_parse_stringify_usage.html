JSON Parse / Stringify 使用說明

用途

這組提供可重用的 JSON 解析與輸出核心， 統一處理 BOM、錯誤模式與輸出縮排。

它不是 JSON Viewer，也不負責讀檔、Storage、Schema 驗證或 UI。

載入

<script src="json_parse_stringify.js"></script>

Parse

const data = SlowlyJSON.parse(jsonText);

預設維持原生行為：解析失敗直接 throw。

Safe Parse

const result = SlowlyJSON.parse(jsonText, {
  safe: true
});

if (result.ok) {
  console.log(result.value);
} else {
  console.error(result.error);
}

safe 模式不會靜默回傳空值，而是明確回傳成功／失敗狀態。

Stringify

const text = SlowlyJSON.stringify(data);

預設使用 2 spaces，方便人類閱讀。

const compact = SlowlyJSON.stringify(data, {
  space: 0
});

Safe Stringify

const result = SlowlyJSON.stringify(data, {
  safe: true
});

if (result.ok) {
  console.log(result.value);
} else {
  console.error(result.error);
}

原生選項

Parse 可傳入 reviver：

SlowlyJSON.parse(text, {
  reviver(key, value) {
    return value;
  }
});

Stringify 可傳入 replacer 與 space：

SlowlyJSON.stringify(data, {
  replacer: ["id", "name"],
  space: 2
});

BOM

解析前會移除字串開頭的 UTF-8 BOM 字元， 避免從某些文字檔取得的 JSON 因 BOM 而失敗。

責任邊界

這組不處理：

  • File / Blob 讀取。
  • JSON 結構 Viewer。
  • JSON Schema 驗證。
  • 資料匯入 commit / rollback。
  • localStorage 或 Supabase。
  • CSV。
  • 循環參照自動修復。
