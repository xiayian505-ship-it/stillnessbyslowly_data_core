Import Merge

只處理「現有陣列 + 匯入陣列」的合併，以及識別鍵衝突時的重新配號。

讀檔、JSON 解析、驗證、Storage、覆蓋模式與 UI 都由宿主決定。

<script src="import_merge.js"></script>
<script>
const result = ImportMerge.merge(existingRecords, importedRecords, {
  key: "id",
  createKey({ usedKeys }) {
    let id;
    do {
      id = crypto.randomUUID();
    } while (usedKeys.has(`string:${id}`));
    return id;
  }
});

console.log(result.records);
console.log(result.collisions);
</script>
