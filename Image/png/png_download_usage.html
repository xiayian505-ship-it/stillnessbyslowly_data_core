PNG Download

下載 PNG Blob 或 PNG Data URL。Blob 下載會自動建立並釋放 Object URL。

載入

<script src="https://lib.stillnessbyslowly.com/Image/png/png_download.js"></script>

Blob

SlowlyPNGDownload.fromBlob(blob, "card.png");

Data URL

SlowlyPNGDownload.fromDataURL(dataURL, "card.png");

檔名

const safe = SlowlyPNGDownload.sanitizeFilename('作品:01');

API

SlowlyPNGDownload.version
SlowlyPNGDownload.sanitizeFilename(name, fallback?)
SlowlyPNGDownload.fromBlob(blob, filename?)
SlowlyPNGDownload.fromDataURL(dataURL, filename?)
