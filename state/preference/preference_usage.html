Preference

通用 boolean 偏好狀態核心，使用 localStorage 保存使用者選擇。 不綁定 DOM、Switch、Checkbox、Effects 或特定功能。

載入

<script src="https://lib.stillnessbyslowly.com/state/preference.js"></script>

載入後使用 window.Preference。

建立

const effectPreference = Preference.create({
  key: "impulse-list:effects",
  defaultValue: true
});

API

get()

讀取目前偏好。若尚未儲存，回傳 defaultValue。

effectPreference.get(); // true / false

set(value)

寫入偏好並回傳寫入後的 boolean 值。

effectPreference.set(false);

toggle()

反轉目前偏好、保存並回傳新值。

effectPreference.toggle();

搭配 Electric Border

const rgbPreference = Preference.create({
  key: "impulse-list:electric-border",
  defaultValue: true
});

card.classList.toggle(
  "is-active",
  rgbPreference.get()
);

Preference 只決定「使用者選了什麼」； Electric Border 仍只負責效果本身。

自訂 storage

預設使用 window.localStorage。 若宿主提供具有 getItem() 與 setItem() 的 storage， 可透過 storage 傳入。 

const memoryPreference = Preference.create({
  key: "demo",
  defaultValue: false,
  storage: customStorage
});

注意

  • key 必填，且必須是非空字串。
  • defaultValue 未設定時預設為 false。
  • 只處理 boolean 偏好，不處理文字、數字或複合設定。
  • 不建立 UI；Checkbox、Switch、按鈕等由宿主自行決定。
