Card Deck Presets｜多套牌組管理

維護多套實體卡 ID 組牌配置，切換啟用牌組、批次移除失效實體引用。

一、載入方式

本地開發測試：

<script src="./card_deck_presets.js"></script>

正式部署在你的軍火庫後，其他宿主可以採絕對網址：

https://lib.stillnessbyslowly.com/game/card/strategy/card_deck_presets.js

注意：本 ZIP 尚未部署，上列 HTTPS 網址為預計發布路徑，不代表目前已上線。

二、公開 API

全域物件：CardDeckPresets；版本 1.0.0。錯誤輸入通常丟出 TypeError／RangeError／Error，應由宿主捕捉。

函式用途與輸入輸出
create({ presetCount, maximumCards, ownedIds? })預設 3 套、每套 30 張；ownedIds 不提供時不檢查所有權
getPreset(id) / getActive()取得指定／啟用的配置副本
setActive(id)切換目前啟用牌組
addCard(id, instanceId) / removeCard(id, instanceId)新增／移除指定實體 ID
replacePreset(id, instanceIds)直接覆蓋整套配置，驗證重複與上限
setName(id, name)設定牌組名稱
removeUnavailable(ownedIds)同步所有權清單並清除全部牌組中的失效引用
snapshot() / restore(data)匯出／還原目前配置；格式錯誤不覆蓋原狀態

三、最小使用範例

const decks = CardDeckPresets.create({
  presetCount: 3, maximumCards: 30, ownedIds: ["copy_1", "copy_2"]
});
decks.addCard("preset_1", "copy_1");
decks.addCard("preset_2", "copy_1"); // 共享引用，不轉移所有權
const selected = decks.getActive().instanceIds;
// 出戰前另外交給 CardLoadoutValidation.validateSelection()。

四、相依及宿主責任

核心獨立運作，沒有強制依賴任何其他軍火庫零件。這不代表要重做既有能力：宿主仍應使用適當的軍火庫零件處理逐字效果、導航、牌組合法性、卡牌升級與儲存等工作。

牌組使用固定穩定識別 preset_1、preset_2……；實體 ID 使用非空字串。若不傳 ownedIds，核心不能判斷所有權，後續可呼叫 removeUnavailable() 同步。禁止戰鬥期間切換由宿主決定。
