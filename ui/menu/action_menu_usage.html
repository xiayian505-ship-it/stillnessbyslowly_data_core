Action Menu 使用說明

用途：用來執行編輯／分享等操作，而不是替代 SlowlySelect 或自動刪除資料。ArrowUp/Down/Home/End、Escape、Tab 可操作。

載入（部署後 HTTPS 絕對路徑）

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/ui/menu/action_menu.css">
<script src="https://lib.stillnessbyslowly.com/ui/menu/action_menu.js"></script>

公開 API

SlowlyActionMenu.create({ trigger, menu, on_action })

輸入／設定：trigger、menu 為 DOM/selector；menu 內每項使用 data-action，支援 disabled 或 aria-disabled=true；選中發 slowlyaction 事件。

實例操作：open(last?)、close(return_focus?)、toggle()、is_open()、destroy()

宿主接法示例

<button id="more" aria-label="其他操作">⋮</button><div id="commands" class="slowly-action-menu" hidden><button data-action="edit">編輯</button><button data-action="share">分享</button></div>
<script>const menu = SlowlyActionMenu.create({trigger:'#more',menu:'#commands',on_action:({action})=>console.log(action)}); /* menu.destroy(); */</script>

生命週期與限制

用來執行編輯／分享等操作，而不是替代 SlowlySelect 或自動刪除資料。ArrowUp/Down/Home/End、Escape、Tab 可操作。

新 JS 使用 IIFE 並提供 window.SlowlyActionMenu；錯誤 DOM／參數會明確報錯。不同宿主負責提供 UI 樣式、文字、實際業務操作，銷毀實例時清除監聽器和計時器。

部署前新網址只是預定位置；若還沒把檔案上架，請先以 ZIP 的相同路徑部署。若在本機測試，可使用測試伺服器映射同路徑。

提醒：這批不會複製已有的 Toast、Confirm、Tabs、Custom Select 或 Loader Progress；現有零件保留原樣。
