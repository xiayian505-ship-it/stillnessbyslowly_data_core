Camera Movement Player｜時間軸播放器

管理 RAF 播放、暫停、seek、重播、停止、循環及銷毀。每幀只呼叫宿主的 on_progress，不決定鏡頭種類。

可操作 Demo ｜ 功能測試

載入方式（完整 HTTPS 絕對路徑）

<script src="https://lib.stillnessbyslowly.com/effects/camera/camera_movement_player.js"></script>

公開 API 與回傳值

const player = SlowlyCameraMovementPlayer.create(options)
options: duration_ms（正數，預設 5000）、loop（boolean）、on_progress(progress,state)、on_complete(state)。
實例：play()、pause()、seek(progress)、restart()、stop()、setLoop(boolean)、getState()、destroy()。
getState(): {progress, is_playing, loop, duration_ms, destroyed}。

宿主呼叫示例

const initial_camera = { x: 0, y: 0, z: 0, focal: 600 };
const player = SlowlyCameraMovementPlayer.create({
    duration_ms: 5000,
    on_progress(progress) {
        const camera = SlowlyCameraMovementPresets.calculate("pan", progress, initial_camera);
        // 宿主在這裡繪圖，不由播放器繪圖。
    }
});
player.play();
// 卸載頁面時 player.destroy();

參數、生命週期與座標約定

首次 play() 立即通知目前進度，下一 RAF 建立起始時間，不跳秒。pause() 取消未執行 RAF，恢復時不補算暫停時間。非循環結束停在 1 並呼叫 on_complete；loop 會取模循環。seek() 可在暫停狀態使用，且會重置上一影格時間。stop() 回到 0；restart() 回到 0 並播放。

功能邊界與例外

不支援離線直接匯出影片（請搭配軍火庫 video/recording/）；on_progress 若自行拋錯，例外會直接由宿主處理。destroy() 後操作會明確拋錯。

這是獨立零件：場景、人物、繪圖、美術、DOM、外觀、觸發時機皆由宿主決定。未提供額外 CSS，不依賴原運鏡 Demo。
