Slowly Tabs｜使用說明

同頁畫面切換的通用 UI 零件。只負責分頁與內容對應、點擊／鍵盤切換、選中狀態及事件；不綁定遊戲、Repo、Router、hash、Storage 或宿主的外觀。

1. 載入

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/ui/tabs/tabs.css">
<script src="https://lib.stillnessbyslowly.com/ui/tabs/tabs.js"></script>

上述網址須在零件正式進貨並部署後使用；測試候選檔案時，請用同資料夾下的 ./tabs.css 和 ./tabs.js。

2. HTML

<main id="appTabs" data-slowly-tabs>
  <nav role="tablist" aria-label="功能分頁">
    <button type="button" role="tab" data-view-target="settings" aria-selected="true">設定</button>
    <button type="button" role="tab" data-view-target="game">遊戲</button>
    <button type="button" role="tab" data-view-target="ranking">排行</button>
  </nav>
  <section role="tabpanel" data-view-panel="settings">設定內容</section>
  <section role="tabpanel" data-view-panel="game" hidden>遊戲內容</section>
  <section role="tabpanel" data-view-panel="ranking" hidden>排行內容</section>
</main>

每個 data-view-target 必須有同名且唯一的 data-view-panel。兩個群組請分別放在各自的根元素中。

3. 初始化與切換

const tabs = SlowlyTabs.create("#appTabs", {
  initial: "game",
  onChange({ name, previousName }) {
    console.log(previousName, "→", name);
    // 遊戲自動暫停、表單檢查等行為，由宿主自行處理。
  }
});

tabs.show("ranking");
console.log(tabs.current);
tabs.destroy();

未傳 initial 時，優先使用 HTML 裡 aria-selected="true" 的有效分頁，否則選擇第一個可用分頁。重複切到同一頁不重送變更通知。不存在或停用的分頁會明確拋出錯誤。

4. 同頁多組

const allTabs = SlowlyTabs.createAll();
// 預設尋找 [data-slowly-tabs]，每組獨立切換。
// 同一根元素重複 create() 會回傳原實例。

5. 事件與鍵盤

document.querySelector("#appTabs").addEventListener(
  "slowlytabschange",
  event => console.log(event.detail.name, event.detail.previousName)
);

預設支援左右方向鍵、Home、End；若 tablist 設定 aria-orientation="vertical"，則改為上下方向鍵。停用的按鈕會被跳過。程式切換可使用 tabs.show("game", { focus: true, silent: true })；silent 不發送變更事件。

6. CSS／宿主外觀

tabs.css 是軍火庫的必要基礎 CSS，只負責讓非作用中的內容確實隱藏，並提供鍵盤焦點提示。它不替宿主設定按鈕的形狀、顏色、字體、間距或選中底線；請在宿主自己的 CSS 中定義這些外觀，不要修改軍火庫的 tabs.css。

#appTabs [role="tablist"] { display: flex; gap: 16px; }
#appTabs [data-view-target] {
  border: 0;
  border-bottom: 2px solid transparent;
  background: transparent;
  color: var(--muted);
  font: inherit;
}
#appTabs [data-view-target][aria-selected="true"] {
  color: var(--text);
  border-bottom-color: var(--accent);
}

7. 邊界

本模組不建立 Tab 的視覺皮膚、不儲存所選分頁、不改網址、不負責宿主業務。若需要網址 hash，宿主可另行引用軍火庫的 Navigation Hash 零件。請勿把單純資料分頁的 Fiction Paginate 與畫面 Tabs 混用。
