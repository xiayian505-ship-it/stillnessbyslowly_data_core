展示頁　功能測試

Canvas Fireflies｜Canvas 螢火蟲

提供獨立 Canvas 螢火蟲漂浮、閃爍與光暈；不含雨絲、森林及任何選單。

載入方式

將以下 URL 作為 script src，並按需要先載入既有依賴：

https://lib.stillnessbyslowly.com/effects/background/canvas_fireflies.js

本 ZIP 是待合併更新包，URL 代表部署後的預定位置，並非已確認在線。

公開全域 API

SlowlyCanvasFireflies｜1.0.0

方法說明
create(options)指定 canvas、count（0～2000）、color、glowColor、minSize/maxSize、glowRadius、driftX/Y、speed、opacity、maxDpr、autoResize、clearCanvas、reducedMotion。
start()啟動；重複呼叫不重複排程。
stop()停止動畫，之後可以再次啟動。
resize()重新測量容器尺寸與 DPR，重建粒子。
draw(time?)繪製單幀，適合宿主控制畫面。
setOptions(next)調整參數；尺寸、粒子數及尺寸範圍變動會重新建粒子。
getState()取得狀態副本。
destroy()取消動畫、移除事件監聽，銷毀後不可重啟。

最小使用範例

const fireflies = SlowlyCanvasFireflies.create({ canvas: document.querySelector("#scene") });
fireflies.start();
// 離開時 fireflies.destroy();

依賴、限制、宿主責任

單實例使用獨立 Canvas 最安全。共用畫布時設 clearCanvas: false，請宿主統一清畫布；reducedMotion 可為 "system"、true、false。預設色只供展示，宿主可覆寫。Canvas 寬高由宿主 CSS 決定。
