保存參與者順序、目前輪到誰、整輪計數和宿主自訂的階段標記。

一、職責與界線

保存參與者順序、目前輪到誰、整輪計數和宿主自訂的階段標記。

宿主決定能不能推進回合、每回合有哪些行動、何時抽牌、AI 與勝負；本零件只保存順序狀態。

三、公開 API

全域物件：CardTurnOrder。名稱、參數與回傳結果以此頁和實際原始碼為準。

函式行為與結果
createTurnOrder(participantIds, options?) 建立順序；options.startRound 與 options.currentPhase 可自訂。
getCurrentParticipant() / getNextParticipant() 查詢目前與下一位參與者。
advanceTurn() / setCurrentParticipant(participantId) 推進或指定目前參與者。
setCurrentPhase(phaseLabel) 保存宿主階段標籤。
getSnapshot() / restoreSnapshot(savedState) / resetTurnOrder() 快照、還原與重置。

四、最小使用範例

const turnOrder = CardTurnOrder.createTurnOrder(
  ["participant-a", "participant-b", "participant-c"],
  { currentPhase: "planning" }
);

turnOrder.advanceTurn();
turnOrder.setCurrentPhase("action");
console.log(turnOrder.getSnapshot());
