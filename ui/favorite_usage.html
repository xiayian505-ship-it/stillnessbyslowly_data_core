Slowly Favorite

通用「最愛／收藏／釘選」UI 狀態積木。只負責互動狀態，不負責儲存資料。

載入

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/ui/favorite.css">
<script src="https://lib.stillnessbyslowly.com/ui/favorite.js"></script>

最小用法

const favorite = SlowlyFavorite.create('[data-favorite-id="product-001"]', {
  inactiveLabel: '最愛',
  activeLabel: '已最愛'
});

由宿主寫入既有資料

const favorite = SlowlyFavorite.create('#favoriteButton', {
  initial: product.favorite,
  onChange({ active }) {
    product.favorite = active;
    // 這裡交給宿主自己的 Storage / CRUD 儲存
  }
});

同步外部狀態

favorite.set(true);              // 會觸發 change
favorite.set(false, { silent: true }); // 只更新 UI
favorite.toggle();
console.log(favorite.active);

批次初始化

SlowlyFavorite.createAll();
// 預設尋找 [data-slowly-favorite]

事件

document.addEventListener('slowlyfavoritechange', (event) => {
  console.log(event.detail.id);
  console.log(event.detail.active);
});

設計原則

  • 不綁商品、圖片、文字或任何資料類型。
  • 宿主只要能提供一個 ID，就能掛上 Favorite UI。
  • 不自行寫 localStorage；持久化交給宿主既有資料層。
  • CSS 只提供必要互動骨架，外觀由宿主決定。
