Pine Forest（松樹森林剪影）｜使用說明

只繪製靜態松樹森林剪影；不提供背景排版、漸層動畫或 Canvas 定位。

開啟獨立功能測試頁

載入（正式 HTTPS 路徑）

<script src="https://lib.stillnessbyslowly.com/effects/background/pine_forest.js"></script>

正式 URL 必須等零件部署到軍火庫後才會有效；ZIP 本身不會修改 GitHub 或目錄資料。

宿主自行決定 CSS

零件不載入 CSS、不寫入 Canvas 的 style、不建立舞台、不決定定位、層級或版面。宿主提供 Canvas 元素與尺寸。

<div class="my-stage">
  <canvas id="effect"></canvas>
</div>

<style>
  .my-stage { position: relative; width: 100%; height: 280px; }
  .my-stage canvas { display: block; width: 100%; height: 100%; }
</style>

上述 CSS 只是宿主範例，不是軍火庫零件的樣式或依賴。

基本使用

const forest = SlowlyPineForest.create({
  canvas: '#effect',
  seed: 11,
  density: 1,
  background: '#122b2b',
  layers: [
    { baseline: 0.72, minHeight: 0.16, maxHeight: 0.31, color: '#254542' },
    { baseline: 0.85, minHeight: 0.21, maxHeight: 0.40, color: '#153130' },
    { baseline: 1.03, minHeight: 0.35, maxHeight: 0.58, color: '#081d20' }
  ]
});

forest.draw();
forest.destroy();

建立參數

選項預設說明
canvas必填Canvas 元素，或可找到元素的 CSS 選擇器。
background不填（透明）繪製前填滿指定顏色，可保留透明以使用宿主背景。
layers內建 3 層各層 baseline/minHeight/maxHeight/color/width/fillBelow。高度和 baseline 為 Canvas 高度的比例。
seed11固定亂數種子，尺寸不變時可重現樹形。
density1森林密度倍率；越大越密。
maxDpr2最高裝置像素比，避免過大的畫布像素數。
width / height從 Canvas 的 CSS 尺寸讀取手動指定繪圖尺寸（像素）；指定後不跟隨 CSS 畫布尺寸。
autoResizetrue使用 ResizeObserver（環境不支援則監聽 resize）；false 要自行呼叫 resize()。

公開方法

forest.draw();    // 在目前 Canvas 重新繪製（同種子、同尺寸得到相同森林）
forest.resize();  // 同步 Canvas 內部解析度，尺寸有變化時重新繪製
forest.destroy(); // 解除尺寸監聽

注意事項

靜態零件不需要 requestAnimationFrame；create() 已初始化尺寸並繪圖。色彩由 layers/background 參數決定，Canvas 位置、大小與合成由宿主 CSS 決定。

零件不引用其他軍火庫 JS。每個 Canvas 由一個效果管理，若宿主需要疊加不同效果，應建立各自的 Canvas 圖層並由宿主決定排列。

宿主負責在移除元件或離開場景時呼叫 destroy() 釋放資源。
