Frame Loop

通用 requestAnimationFrame 迴圈。 只負責每一幀通知宿主，不決定每幀要更新什麼。

載入

<script
  defer
  src="https://lib.stillnessbyslowly.com/date/timer/frame_loop.js"
></script>

基本使用

const loop = FrameLoop.create({
  callback({ timestamp, delta, elapsed, frame }) {
    // 宿主自行更新動畫 / 遊戲 / 狀態
  }
});

loop.start();

控制

loop.start();
loop.pause();
loop.resume();
loop.stop();
loop.reset();

loop.getState();

單步執行

loop.step(1000);
loop.step(1016);

step() 不會自動啟動 requestAnimationFrame， 適合測試或由宿主自行提供時間來源。

替換 callback

loop.setCallback(({ delta }) => {
  // 新的每幀邏輯
});

Callback 資料

{
  timestamp, // requestAnimationFrame timestamp
  delta,     // 與上一幀的差（毫秒）
  elapsed,   // 累積執行時間（不含暫停）
  frame      // 已執行幀數，從 1 開始
}

設計原則

FrameLoop 不知道自己正在驅動什麼。 信紙老化、漂浮動畫、Canvas、遊戲角色或其他逐幀更新， 都由宿主自行決定。
