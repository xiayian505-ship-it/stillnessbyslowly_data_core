Slowly JSON Viewer

JSON Viewer 是底層結構顯示工具。 Slowly JSON Viewer Component 是可直接使用的完成品。

依賴

<link rel="stylesheet"
href="https://lib.stillnessbyslowly.com/data/json/json_viewer.css">

<link rel="stylesheet"
href="https://lib.stillnessbyslowly.com/component/data/json_viewer_component.css">

<script src="https://lib.stillnessbyslowly.com/fiction/Fiction_storage.js"></script>

<script src="https://lib.stillnessbyslowly.com/data/json/json_viewer.js"></script>

<script src="https://lib.stillnessbyslowly.com/component/data/json_viewer_component.js"></script>

使用

<div id="json-viewer"></div>

<script>
const viewer =
  SlowlyJSONViewerComponent.mount(
    "#json-viewer"
  );
</script>

Options

{
  namespace:"slowly-json-viewer",
  collection:"documents",
  initialValue:null,
  rootLabel:"root",
  showTypes:true,
  collapsedDepth:Infinity,
  sortKeys:false
}

功能

  • 貼上 JSON
  • 匯入 JSON / TXT
  • JSON Viewer 結構顯示
  • 搜尋與標亮
  • 全部展開 / 收合
  • 使用 Fiction Storage 儲存、開啟、更新、刪除

Component 不使用 Fiction Change。 目前資料操作皆由同一個完成品發起， 儲存後直接刷新自己的清單。
