Combat Stats

通用戰鬥數值核心，管理 HP、maxHP、shield，以及傷害、治療與護盾增減。

它不認識玩家、敵人、卡牌、回合、AI 或 DOM。宿主只要提供符合格式的物件即可。

引入

<script src="./combat_stats.js"></script>

基本資料

const unit = {
  hp: 20,
  maxHP: 20,
  shield: 5
};

常用 API

CombatStats.damage(unit, 8);
CombatStats.heal(unit, 3);
CombatStats.addShield(unit, 4);
CombatStats.clearShield(unit);
CombatStats.isDefeated(unit);
CombatStats.isFull(unit);
