Modal 使用說明

用途：任意 DOM 內容的原生 dialog；不是 SlowlyConfirm 的 Promise<boolean> 確認流程，也不改寫表單和使用者內容。

載入（部署後 HTTPS 絕對路徑）

<script src="https://lib.stillnessbyslowly.com/ui/modal/modal.js"></script>

公開 API

SlowlyModal.create(dialog, { close_on_backdrop, on_open, on_close })

輸入／設定：dialog 必須是宿主已有的 <dialog>；可選遮罩關閉（預設 true）；close(reason) 用於區分程式／內容／遮罩／Escape。

實例操作：open()、close(reason?)、is_open()、destroy()

宿主接法示例

<button id="show_settings">設定</button><dialog id="settings"><form method="dialog"><label>稱呼<input name="label"></label><button value="close">結束</button></form></dialog>
<script>const modal = SlowlyModal.create('#settings'); document.querySelector('#show_settings').onclick=()=>modal.open(); /* modal.destroy() */</script>

生命週期與限制

任意 DOM 內容的原生 dialog；不是 SlowlyConfirm 的 Promise<boolean> 確認流程，也不改寫表單和使用者內容。

新 JS 使用 IIFE 並提供 window.SlowlyModal；錯誤 DOM／參數會明確報錯。不同宿主負責提供 UI 樣式、文字、實際業務操作，銷毀實例時清除監聽器和計時器。

部署前新網址只是預定位置；若還沒把檔案上架，請先以 ZIP 的相同路徑部署。若在本機測試，可使用測試伺服器映射同路徑。

提醒：這批不會複製已有的 Toast、Confirm、Tabs、Custom Select 或 Loader Progress；現有零件保留原樣。
