多資源池｜使用說明

保存宿主自訂名稱的資源，檢查多種資源是否足夠，並在足額時一次扣除。

一、職責與界線

保存宿主自訂名稱的資源，檢查多種資源是否足夠，並在足額時一次扣除。

宿主決定資源種類、上限、補充時機與每張卡需要的費用；本零件不定義行動點或魔法點。

三、公開 API

全域物件：CardResourcePool。名稱、參數與回傳結果以此頁和實際原始碼為準。

函式行為與結果
createPool(initialAmounts?) 建立獨立資源池。
getAmount(resourceName) / setAmount(resourceName, resourceAmount) 讀取或設定指定資源的非負有限數值。
addAmount(resourceName, resourceAmount) / clearAmount(resourceName) 增加或清零。
canAfford(requiredAmounts) / spend(requiredAmounts) 檢查或一次扣除多項費用；不足時不扣除任何資源。
getSnapshot() / restoreSnapshot(replacementAmounts) 匯出和還原資源狀態；永久儲存由宿主處理。

四、最小使用範例

const resourcePool = CardResourcePool.createPool({ movement: 5, crystals: 2 });

const cardCost = { movement: 2, crystals: 1 }; // 宿主決定
if (resourcePool.canAfford(cardCost)) {
  resourcePool.spend(cardCost);
}

console.log(resourcePool.getSnapshot());
