Data Diff 使用說明

用途

Data Diff 是純資料差異比較核心，用來比較兩份 JavaScript 資料， 回傳新增、移除與變更項目。

核心不負責 JSON 字串解析、檔案讀取、DOM、UI、標亮或畫面顯示。

載入

<script src="data_diff.js"></script>

基本使用

const result = SlowlyDataDiff.diff(
  {
    name: "Slowly",
    count: 1
  },
  {
    name: "Slowly",
    count: 2,
    active: true
  }
);

console.log(result);

回傳格式

{
  equal: false,

  added: [
    {
      type: "added",
      path: "$.active",
      segments: ["active"],
      newValue: true
    }
  ],

  removed: [],

  changed: [
    {
      type: "changed",
      path: "$.count",
      segments: ["count"],
      oldValue: 1,
      newValue: 2
    }
  ],

  summary: {
    added: 1,
    removed: 0,
    changed: 1,
    total: 2
  }
}

路徑格式

一般欄位使用點記法：

$.user.name

陣列使用索引：

$.items[0].title

無法安全使用點記法的 key，會改用括號格式：

$["hello-world"]

比較規則

  • Object 依 key 比較。
  • Array 依索引比較。
  • 巢狀 Object / Array 會繼續往下比較。
  • 不同容器型態，例如 Object → Array，視為該路徑的一筆 changed。
  • primitive 使用 Object.is() 判斷是否相同。

責任邊界

Data Diff 不處理：

  • JSON.parse() / JSON.stringify()
  • CSV
  • 檔案讀取
  • DOM 與 UI
  • 文字標亮
  • 陣列依 ID 對齊
  • 循環參照資料

若之後需要 JSON Diff 完成品，可再由 JSON Parser、Data Diff、 Custom File、Clipboard、Toast 等積木組合。
