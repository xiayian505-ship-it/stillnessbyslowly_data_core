Deck

通用牌庫循環核心，管理抽牌堆、手牌與棄牌堆。模組只負責項目在三個區域之間的流動；卡片資料、使用條件、效果、戰鬥規則、UI 與儲存方式都由宿主決定。

基本使用

<script src="./deck.js"></script>
<script>
  const deck = Deck.create({
    items: myCards,
    handSize: 4
  });

  deck.drawToHand();
  deck.discardAt(0);

  console.log(deck.snapshot());
</script>

建立選項

選項用途預設
items宿主提供的任意項目陣列；也接受 cards。[]
handSizedrawToHand() 預設補到的手牌數。0
recycleDiscard抽牌堆空時是否自動回收棄牌堆。true
shuffleOnReset建立／重設牌庫時是否洗牌。true
shuffleOnRecycle棄牌堆回收時是否洗牌。true
random宿主可傳入自訂亂數函式。Math.random

API

reset(items?)重建抽牌堆並清空手牌、棄牌堆。
shuffle()洗目前的抽牌堆。
recycle()手動把棄牌堆移回抽牌堆。
draw(count)抽指定數量到手牌，回傳實際抽到的項目。
drawToHand(size?)把手牌補到指定數量。
discardAt(index)把指定手牌位置移到棄牌堆。
discardItem(item)依項目參照找到手牌並棄掉。
discardAll()把全部手牌移到棄牌堆。
setHandSize(size)修改預設手牌數。
snapshot()取得 drawPile、hand、discardPile、handSize 的快照。
