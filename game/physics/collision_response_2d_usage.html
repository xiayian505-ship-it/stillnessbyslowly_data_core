Collision Response 2D｜使用說明

使用已知法線、物體速度和表面速度求碰後速度；來源為 hitSeg 的法線反彈計算。

檔案與載入順序

<script src="https://lib.stillnessbyslowly.com/game/physics/collision_response_2d.js"></script>

公開 API

window.SlowlyCollisionResponse2D

  • calculate({ velocity:{x,y}, normal:{x,y}, surface_velocity?:{x,y}, restitution?, minimum_bounce_speed? }) → 碰後運動資訊

選項、數值與輸出

  • 速度與表面速度：宿主座標單位／秒；預設表面靜止。
  • 法線必須是非零向量，函式會正規化。
  • restitution 介於 0..1，預設 0.5；minimum_bounce_speed ≥0，預設 0。
  • 回傳 collided、impact_speed、normal_speed、restitution_applied、impulse_per_unit_mass、velocity、normal。

使用範例（請先按上列順序載入腳本）

const impact = SlowlyCollisionResponse2D.calculate({
  velocity: { x: 10, y: 50 }, normal: { x: 0, y: -1 },
  restitution: 0.6, minimum_bounce_speed: 2
});
console.log(impact.velocity, impact.impact_speed);

錯誤、清理與限制

只在相對法線速度小於零時反彈；遠離表面的物體原速返回。碰撞幾何、位移修正及接觸物件搜索由宿主與其他零件提供。

若輸入格式錯誤、非法負值或非有限數字，原則上拋出 TypeError 或 RangeError。 需保留狀態的物件可使用 reset/cancel/clear/destroy 或非同步 stop，實際方法以上列 API 為準。

這顆 JS 不附加遊戲造型、不依賴打包工具，使用獨立 IIFE ＋ window API。 本頁文中的 HTTPS 新零件網址須等使用者部署後才會可用。
