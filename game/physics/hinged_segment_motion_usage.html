Hinged Segment Motion｜使用說明

以轉軸旋轉有長度的線段，計算端點與接觸點切線速度；來源 tip 與 stepFlipper。

檔案與載入順序

<script src="https://lib.stillnessbyslowly.com/game/physics/hinged_segment_motion.js"></script>

公開 API

window.SlowlyHingedSegmentMotion

  • step({pivot:{x,y}, length, angle, target_angle, maximum_angular_speed, delta_seconds}) → {angle, angular_velocity, end_point, reached_target}
  • end_point({pivot, length, angle}) → {x,y}
  • point_velocity({pivot, point:{x,y}, angular_velocity}) → {x,y}

選項、數值與輸出

  • 角度使用弧度，角速度為弧度／秒；delta_seconds 為秒。
  • length、maximum_angular_speed、delta_seconds 必須 ≥0。
  • 角度直接朝目標值前進（不採最短環繞路徑）；可讓宿主控制角度上下限。
  • 端點等於 pivot + length × (cos(angle), sin(angle))。

使用範例（請先按上列順序載入腳本）

const moved = SlowlyHingedSegmentMotion.step({
  pivot:{x:100,y:120}, length:80, angle:0,
  target_angle:-0.6, maximum_angular_speed:4, delta_seconds:1/60
});
const surface = SlowlyHingedSegmentMotion.point_velocity({
  pivot:{x:100,y:120}, point:moved.end_point,
  angular_velocity:moved.angular_velocity
});

錯誤、清理與限制

在 Canvas y 軸向下的畫面，正角度看起來是順時針；無時間步長時角速度歸零、不除以 0。沒有碰撞與按鍵邏輯。

若輸入格式錯誤、非法負值或非有限數字，原則上拋出 TypeError 或 RangeError。 需保留狀態的物件可使用 reset/cancel/clear/destroy 或非同步 stop，實際方法以上列 API 為準。

這顆 JS 不附加遊戲造型、不依賴打包工具，使用獨立 IIFE ＋ window API。 本頁文中的 HTTPS 新零件網址須等使用者部署後才會可用。
