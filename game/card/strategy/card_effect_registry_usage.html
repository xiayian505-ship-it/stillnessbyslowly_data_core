三、公開 API

全域物件：CardEffectRegistry。名稱、參數與回傳結果以此頁和實際原始碼為準。

函式行為與結果
createRegistry() 建立彼此獨立的效果登記表。
registerEffect(effectKey, effectDefinition) 登記函式或 { canRun, execute }；不允許重名。
checkEffect(effectKey, effectContext) 回傳 { ok } 或 { ok:false, reason }。
executeEffect(effectKey, effectContext) 檢查後同步執行，成功回傳 { ok:true, value }。
hasEffect(effectKey) / removeEffect(effectKey) / listEffectKeys() 查詢、移除與列出登記名稱。

四、最小使用範例

const registry = CardEffectRegistry.createRegistry();
registry.registerEffect("gain-points", {
  canRun: context => context.allowed,
  execute: context => context.total + context.award
});

const result = registry.executeEffect("gain-points", {
  allowed: true,
  total: 2,
  award: 3
});
console.log(result.value); // 5
