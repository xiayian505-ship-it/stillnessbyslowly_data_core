Serial Queue

通用非同步序列佇列。 每一件工作完成後才會執行下一件； 某一件失敗不會讓後面的工作停止。

載入

<script
  defer
  src="https://lib.stillnessbyslowly.com/state/queue/serial_queue.js"
></script>

基本使用

const queue = SerialQueue.create();

queue.add(async () => {
  await saveFirst();
});

queue.add(async () => {
  await saveSecond();
});

即使第二件工作在第一件尚未完成時加入， 也一定會等第一件完成後才開始。

取得單一工作結果

try {
  const result = await queue.add(async () => {
    return await saveSomething();
  });

  console.log(result);
} catch (error) {
  console.error(error);
}

單一工作失敗不會中斷後續工作

queue
  .add(async () => {
    throw new Error("這一件失敗");
  })
  .catch(console.error);

queue.add(async () => {
  // 這一件仍然會照常執行
});

等待佇列清空

await queue.idle();

console.log("目前排隊工作都完成了");

查看狀態

queue.getState();

// {
//   running: true,
//   pending: 2,
//   size: 3
// }

設計原則

Serial Queue 不知道自己正在排什麼。 儲存、Render、API 請求或其他非同步工作， 全部由宿主自行決定。

Retry、Timeout、錯誤提示與業務規則也不屬於本零件。
