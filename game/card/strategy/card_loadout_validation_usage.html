出戰清單驗證｜使用說明

根據收藏中的實體卡 ID 還原出戰清單，檢查遺失、重複、資格與宿主設定的數量上限。

一、職責與界線

根據收藏中的實體卡 ID 還原出戰清單，檢查遺失、重複、資格與宿主設定的數量上限。

宿主決定收藏存在哪裡、能出戰哪些卡、可選幾張與 UI；本零件只驗證資料，不管理收藏存檔。

二、相依與載入

無。

三、公開 API

全域物件：CardLoadoutValidation。名稱、參數與回傳結果以此頁和實際原始碼為準。

函式行為與結果
validateSelection(ownedCards, selectedInstanceIds, options?) 回傳 isValid、resolvedCards、missingInstanceIds、duplicateInstanceIds、ineligibleInstanceIds、exceedsMaximum。
getInstanceIds(cards, options?) 取出卡牌 ID 清單，由宿主自行儲存。

四、最小使用範例

const ownedCards = [
  { id: "one", name: "甲" },
  { id: "two", name: "乙" }
];

const selection = CardLoadoutValidation.validateSelection(
  ownedCards,
  ["two", "one"],
  { maximumCards: 2 }
);

if (selection.isValid) {
  console.log(selection.resolvedCards);
}
