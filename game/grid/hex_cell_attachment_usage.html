hex_cell_attachment｜使用說明

功能：泡泡撞擊後挑選最近合法六角空格

公開 API

`SlowlyHexCellAttachment.find_attachment(options)`。

依賴與載入順序

game/grid/hex_grid_geometry.js

<script src="https://lib.stillnessbyslowly.com/game/grid/hex_grid_geometry.js"></script>
<script src="https://lib.stillnessbyslowly.com/game/grid/hex_cell_attachment.js"></script>

以上是部署後的 HTTPS 絕對網址，必須先上傳新零件才會存在；依賴 JS 必須先載入。

輸入參數

`grid`：矩形二維陣列；`point={x,y}`：飛行物落點；`hit_position={r,c}` 可選（必須指向被佔的合法格）；`geometry_options={radius,odd_row_offset?,origin_x?,origin_y?}`；`is_occupied` 可選。

回傳結果

`{found,position,distance,reason}`。有命中格時先比六鄰格空位；全滿再尋找頂排或鄰接既有佔位的空格；同距離依列、欄升序決定。

宿主實際接法

const grid = [
  [null, { color: "red" }, null],
  [null, null, null]
];
const result = SlowlyHexCellAttachment.find_attachment({
  grid, point: { x: 45, y: 25 }, hit_position: { r: 0, c: 1 },
  geometry_options: { radius: 10 }
});
if (result.found) grid[result.position.r][result.position.c] = { color: "blue" };

限制與錯誤

六角中心、鄰居全部引用 `SlowlyHexGridGeometry`；不做命中偵測、顏色判定、泡泡放置或同色連鎖。無格可放回傳 `found:false`。

JS 會針對非法資料或缺少依賴明確拋出錯誤；宿主應自行 try/catch 處理使用者輸入。純計算零件沒有 destroy 生命週期；Undo 使用 clear 清空歷史。外觀、聲音與動畫完全由宿主控制。
