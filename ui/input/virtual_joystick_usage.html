Virtual Joystick 使用說明

手指或滑鼠在宿主指定元素上拖曳，輸出方向、距離與強度。零件不建立按鈕、不繪製搖桿，也不移動角色。

部署引用與順序

<script src="https://lib.stillnessbyslowly.com/ui/canvas/canvas_rect_drag.js"></script>
  <script src="https://lib.stillnessbyslowly.com/ui/input/virtual_joystick.js"></script>

公開 API：window.SlowlyVirtualJoystick

create({target, dead_zone=10, max_distance=70, enabled=true, on_change?}) → instance。
  instance.snapshot() → {active, enabled, pointer_id, origin, current, direction_x, direction_y, strength, distance}。
  instance.set_enabled(boolean) → snapshot；instance.destroy() → 釋放事件監聽及 Pointer 捕捉。
  Canvas 元素必須先載入 CanvasRectDrag，並由其 pointFromEvent 完成座標映射。
  一般 DOM 元素則使用該元素自身的局部座標。宿主需設定操作區 touch-action:none，否則手機瀏覽器可能優先捲動頁面。單一實例一次追蹤一個 Pointer ID，其他指標不會奪取控制。

宿主呼叫範例

const joystick = SlowlyVirtualJoystick.create({
    target: document.querySelector('#touch_area'),
    dead_zone: 10,
    max_distance: 70,
    on_change: (state) => {
      // direction_x / direction_y 是正規化方向，strength 為 0～1。
      console.log(state.direction_x, state.direction_y, state.strength);
    }
  });

  console.log(joystick.snapshot());
  joystick.set_enabled(false);
  joystick.destroy();

使用邊界

本零件遵循 IIFE + window 全域 API。宿主決定顏色、字型、角色、遊戲規則、渲染與操作 UI。凡涉及現有軍火庫能力，僅透過上方 HTTPS 絕對 URL 載入，不複製原碼。

程式未壓縮，Demo 僅供操作，Test 會逐項實際 PASS／FAIL。手機操作與跨瀏覽器相容性仍請以部署後設備實測。
