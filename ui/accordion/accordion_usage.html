Accordion 使用說明

用途：使用原生 details/summary 支援 Enter/Space；不取代 Tabs、不處理內容載入；巢狀群組需各自建立實例。

載入（部署後 HTTPS 絕對路徑）

<script src="https://lib.stillnessbyslowly.com/ui/accordion/accordion.js"></script>

公開 API

SlowlyAccordion.create(root, { multiple, on_change })

輸入／設定：root: data-slowly-accordion 容器；每個 details 要有 data-accordion-id 和直接子 summary。multiple 預設 false（單開）。

實例操作：open(key)、close(key)、toggle(key)、open_all()（限多開）、close_all()、snapshot()、destroy()

宿主接法示例

<div data-slowly-accordion id="questions"><details data-accordion-id="one"><summary>問題一</summary><p>說明</p></details><details data-accordion-id="two"><summary>問題二</summary><p>說明</p></details></div>
<script>const sections = SlowlyAccordion.create('#questions', { multiple: false }); sections.open('one'); /* 不再需要時 sections.destroy() */</script>

生命週期與限制

使用原生 details/summary 支援 Enter/Space；不取代 Tabs、不處理內容載入；巢狀群組需各自建立實例。

新 JS 使用 IIFE 並提供 window.SlowlyAccordion；錯誤 DOM／參數會明確報錯。不同宿主負責提供 UI 樣式、文字、實際業務操作，銷毀實例時清除監聽器和計時器。

部署前新網址只是預定位置；若還沒把檔案上架，請先以 ZIP 的相同路徑部署。若在本機測試，可使用測試伺服器映射同路徑。

提醒：這批不會複製已有的 Toast、Confirm、Tabs、Custom Select 或 Loader Progress；現有零件保留原樣。
