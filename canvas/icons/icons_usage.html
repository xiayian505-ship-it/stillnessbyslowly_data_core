Slowly Canvas Icons

Canvas icon 軍火庫。icon 家族只負責「怎麼畫」， 尺寸、顏色、粗細、比例等視覺參數由宿主呼叫時決定。

載入順序

<script src="https://lib.stillnessbyslowly.com/canvas/icons/core.js"></script>
<script src="https://lib.stillnessbyslowly.com/canvas/icons/arrows.js"></script>

基本呼叫

const canvas = document.querySelector("#icon");

SlowlyCanvasIcons.draw(
  "arrows",
  "horizontal",
  canvas,
  {
    size: 64,
    color: "#ffffff",
    thickness: 10,
    headRatio: 1.55
  }
);

目前家族

  • arrows：方向、雙向、轉彎與旋轉箭頭。

目前 icon

  • up、upRight、right、downRight
  • down、downLeft、left、upLeft
  • vertical、horizontal
  • turnLeft、turnRight、turnUp、turnDown
  • rotateClockwise、rotateCounterClockwise

主要參數

  • size：整顆 icon 的繪製尺寸。
  • color：填色／線條顏色。
  • thickness：箭桿或線條粗細。
  • headRatio：箭頭相對於箭桿的寬度。
  • headLength：箭頭尖端到箭頭底部的長度。
  • padding：icon 繪製範圍內距。
  • x / y：可選；指定圖示中心。未傳時自動畫在 Canvas 中央。
  • clear：預設 true；設為 false 時不先清空 Canvas。

與 PNG 零件組合

Canvas Icons 本身不負責輸出圖片。需要 PNG 時， 宿主可把畫好的 Canvas 再交給軍火庫既有的 Canvas PNG / PNG Download 零件。 這樣 icon 與匯出流程彼此不依賴。
