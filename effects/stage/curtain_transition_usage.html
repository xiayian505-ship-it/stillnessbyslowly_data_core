宿主外觀變數

效果提供預設紅幕與暖色聚光燈；宿主可只覆寫 CSS 變數，不需修改軍火庫本體。

.slowly-curtain-transition {
  --sbs-curtain-color-top: #8f2529;
  --sbs-curtain-color-mid: #671619;
  --sbs-curtain-color-bottom: #4d0f12;
  --sbs-curtain-trim: rgba(238,190,91,.42);
  --sbs-curtain-shadow: rgba(32,5,7,.38);
  --sbs-curtain-stage-bg: #1d120d;

  --sbs-curtain-spotlight-core: rgba(255,253,222,.98);
  --sbs-curtain-spotlight-mid: rgba(255,237,164,.58);
  --sbs-curtain-spotlight-soft: rgba(255,218,119,.20);
  --sbs-curtain-spotlight-fade: rgba(255,217,133,0);
  --sbs-curtain-spotlight-wash-top: rgba(255,250,215,.48);
  --sbs-curtain-spotlight-wash-mid: rgba(255,220,128,.12);
  --sbs-curtain-spotlight-wash-end: rgba(255,216,130,0);
  --sbs-curtain-spotlight-strength: 1;

  --sbs-curtain-vignette-mid: rgba(24,12,7,.08);
  --sbs-curtain-vignette-edge: rgba(18,8,5,.56);
  --sbs-curtain-vignette-top: rgba(17,9,5,.48);
  --sbs-curtain-vignette-strength: 1;

  --sbs-curtain-duration: 1720ms;
}

--sbs-curtain-spotlight-strength 與 --sbs-curtain-vignette-strength 可直接調整聚光燈與暗場強度，例如 .7 會較淡、1.2 會較明顯。
