Slowly Clipboard Component 使用說明

Slowly Clipboard 是 Clipboard Copy、Cut、Paste、Select 四顆零件的完成品。 它會為指定的 input 或 textarea 建立一組原生按鈕： 複製、剪下、貼上、全選。

Component 不重寫剪貼簿能力；實際操作由四顆 Clipboard 零件執行。 CSS 只提供最低限度結構，宿主可以直接覆寫外觀。

1. 載入 / 依賴

請照以下順序載入：

<link rel="stylesheet"
      href="https://lib.stillnessbyslowly.com/component/clipboard/clipboard_component.css">

<script src="https://lib.stillnessbyslowly.com/ui/clipboard/clipboard_copy.js"></script>
<script src="https://lib.stillnessbyslowly.com/ui/clipboard/clipboard_cut.js"></script>
<script src="https://lib.stillnessbyslowly.com/ui/clipboard/clipboard_paste.js"></script>
<script src="https://lib.stillnessbyslowly.com/ui/clipboard/clipboard_select.js"></script>

<script src="https://lib.stillnessbyslowly.com/component/clipboard/clipboard_component.js"></script>

2. 最簡單使用

<textarea id="editor"></textarea>

<script>
  const clipboard = SlowlyClipboard.mount("#editor");
</script>

預設會把按鈕列插在目標元素後面。

3. Options

labels

修改建立時的按鈕文字。

const clipboard = SlowlyClipboard.mount("#editor", {
  labels: {
    copy: "Copy",
    cut: "Cut",
    paste: "Paste",
    selectAll: "Select All"
  }
});

ariaLabel

修改按鈕群組的 aria-label。

SlowlyClipboard.mount("#editor", {
  ariaLabel: "文字編輯操作"
});

container

指定按鈕列要放進哪個容器。可傳 selector 或 Element。 未指定時，按鈕列會插在目標 input / textarea 後面。 

SlowlyClipboard.mount("#editor", {
  container: "#toolbar"
});

onError

按鈕操作失敗時的錯誤處理。Paste 可能受 HTTPS、瀏覽器權限與使用者操作限制。 

SlowlyClipboard.mount("#editor", {
  onError(error, action, instance) {
    console.log(action, error.message);
  }
});

4. Public API

const clipboard = SlowlyClipboard.mount("#editor");

await clipboard.copy();
await clipboard.cut();
await clipboard.paste();
clipboard.selectAll();
clipboard.destroy();

copy() 只複製目前選取的文字；沒有選取時回傳空字串，不會改寫剪貼簿。

cut()、paste()、selectAll() 分別直接呼叫 Clipboard Cut、Paste、Select 零件。

5. 呼叫後修改 DOM

完成品建立的是普通原生 DOM，沒有把按鈕文字或外觀寫死。 Instance 會提供 elements： 

const clipboard = SlowlyClipboard.mount("#editor");

clipboard.elements.root;
clipboard.elements.target;
clipboard.elements.copy;
clipboard.elements.cut;
clipboard.elements.paste;
clipboard.elements.selectAll;

例如：

clipboard.elements.copy.textContent = "複製文字";
clipboard.elements.copy.classList.add("my-copy-button");

6. CSS / 宿主外觀

clipboard_component.css 只處理基本排列、按鈕可點擊、 disabled 與 focus-visible。顏色、字體、圓角、陰影等由宿主自行覆寫。 

.slowly-clipboard {
  gap: 12px;
}

.slowly-clipboard-button {
  border-radius: 999px;
  background: #222;
  color: #fff;
}

7. 邊界

  • 完成品目標只接受 input / textarea，因為 Cut 與 Paste 零件的共同可用範圍就是 input / textarea。
  • 完成品不自行實作 Clipboard API，不重寫 Copy / Cut / Paste / Select。
  • 完成品不負責 Toast、成功訊息或品牌樣式。
  • Paste 是否可用仍取決於瀏覽器環境與權限。
