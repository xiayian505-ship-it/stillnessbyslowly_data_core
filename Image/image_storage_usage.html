Image Storage｜使用說明

IndexedDB Blob 儲存，保留既有公開 API 並補 Demo／Test。

本頁是已編寫的使用說明；正式公開網址需在檔案上傳部署後才可使用。

既有圖片儲存核心

僅引用原有 Image/image_storage.js，不重做資料庫驅動；不是 localStorage，不是雲端服務，也不需要 Image Resize。網站必須在允許 IndexedDB 的安全來源上運作。

API 與輸入

方法說明
ImageStorage.create({dbName,storeName,dbVersion})預設 slowly_image_storage、images、1，回傳實例。
save(blob,meta)寫 Blob，回傳 ID；meta 可含 id 等資料。
get(id)、getBlob(id)取得記錄或原始 Blob。
remove(id)、clear()、count()刪單筆、清 store、記錄計數。
close()釋放共用於此實例的資料庫連線；之後方法可再開啟。

限制與風險

同 dbName 同 dbVersion 但不同 storeName 時，不會自動新增 store，需以新版本建置。原有 save() 的 Promise 目前綁 IDB request.onsuccess，並非 transaction.oncomplete：資料完整交易提交的保證需另驗證。meta 可覆寫既有欄位，不能直接接受不可信任的 meta。儲存容量及持續時間依瀏覽器環境。

完整引用範例（部署後 HTTPS 絕對路徑）

<script src="https://lib.stillnessbyslowly.com/Image/image_storage.js"></script>
<script>
const image_store = window.ImageStorage.create({
  dbName: "my_gallery", storeName: "images", dbVersion: 1
});
async function store_image(file) {
  if (!(file instanceof Blob)) return;
  try {
    const id = await image_store.save(file, {filename: file.name});
    const restored = await image_store.getBlob(id);
    console.log(id, restored);
  } catch (error) {
    console.error("存取失敗", error);
  }
}
window.addEventListener("pagehide", () => image_store.close());
</script>
