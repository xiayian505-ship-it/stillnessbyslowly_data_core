Forward Target Selector｜使用說明

根據方向、路線、資格和距離，搜尋最近的前方目標。不是射擊碰撞或卡牌目標選擇器。

正式 HTTPS 引用順序

<script src="https://lib.stillnessbyslowly.com/game/targeting/forward_target_selector.js"></script>

以上為 GitHub Pages 完成部署後的預期路徑。若尚未上傳，網址不會自動存在。

公開 API

window.SlowlyForwardTargetSelector，版本 1.0.0。

select({origin_x, lane, direction, candidates, lane_of?, position_of?, is_eligible?, max_distance?, allow_origin?})。

參數與單位

direction 可用 right／left 或 1／-1；origin_x 有限數字；候選預設欄位是 {lane,x}，可用 lane_of、position_of 自訂資料欄位；is_eligible 過濾死亡／隱藏對象；allow_origin 預設 true。

回傳結果

回傳 {found, target, distance, index}；找不到時 target=null、distance=null、index=-1。同距目標以候選陣列順序優先。

實際宿主接法

const result = SlowlyForwardTargetSelector.select({
  origin_x: 4, lane: 'upper', direction: 'right',
  candidates: [{lane:'upper',x:9},{lane:'lower',x:5}]
}); // 選中第一個 upper 目標，distance=5

錯誤／退化情境

無效方向、原點、負搜尋距離與非陣列 candidates 擲錯；無效候選 x 或跨路線候選略過；不得修改候選物件。

職責邊界、清理與限制

不包含植物、殭屍、HP 等特殊欄位；不計算 AABB、傷害、射擊冷卻、彈藥或移動。

除了有狀態零件需在宿主結束局面時呼叫 reset()，其餘純運算 API 不保留 DOM 監聽器，也不需 destroy。所有輸入時間單位、可選依賴及限制以上述公開函式契約為準。
