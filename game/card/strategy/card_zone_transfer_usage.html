卡牌區域移轉｜使用說明

借用既有 Deck 的快照與還原介面，在牌庫／手牌／棄牌區之間移動或交換卡牌。

一、職責與界線

借用既有 Deck 的快照與還原介面，在牌庫／手牌／棄牌區之間移動或交換卡牌。

宿主決定什麼卡能移動、何時移動、費用以及是否允許交換；本零件不重新實作抽牌、洗牌或改變 Deck 的原始牌組。

二、相依與載入

需要軍火庫既有的 ../deck.js（Deck 1.1.0）；先引用 Deck，再引用本零件。

下方為在軍火庫 repo 對應目錄的相對路徑示例，發布後宿主再改用軍火庫 HTTPS 絕對 URL。

<script src="../deck.js"></script>
<script src="./card_zone_transfer.js"></script>

三、公開 API

全域物件：CardZoneTransfer。名稱、參數與回傳結果以此頁和實際原始碼為準。

函式行為與結果
moveCard({ sourceDeck, sourceZone, destinationDeck, destinationZone, cardSelection }) 移動指定單張卡，找不到回傳 { ok:false, reason:"not_found" }。
moveZoneCards({ sourceDeck, sourceZone, destinationDeck, destinationZone }) 將來源區域所有卡移到目標區域。
swapCards({ firstDeck, secondDeck, firstZone?, secondZone?, firstSelection, secondSelection }) 交換指定兩張卡，預設區域為 hand。
swapZoneCards({ firstDeck, secondDeck, firstZone?, secondZone? }) 交換兩個完整區域，預設為 hand。

四、最小使用範例

const firstDeck = Deck.create({ items: ["A", "B"], shuffleOnReset: false });
const secondDeck = Deck.create({ items: ["C"], shuffleOnReset: false });

firstDeck.draw(1);

CardZoneTransfer.moveCard({
  sourceDeck: firstDeck,
  sourceZone: "hand",
  destinationDeck: secondDeck,
  destinationZone: "discardPile",
  cardSelection: 0
});
