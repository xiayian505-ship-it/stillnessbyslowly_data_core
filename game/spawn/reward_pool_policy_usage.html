Reward Pool Policy｜使用說明

以「分類 → 可選子群 → 候選項目」分層權重抽選；每次獨立放回。

Demo　Test

引用方式

<script src="https://lib.stillnessbyslowly.com/game/spawn/reward_pool_policy.js"></script>

以上為部署後的預定網址，並非保證已經上架。使用全域 SlowlyRewardPoolPolicy。

規則

頂層 groups 必填，每項有非空 id、可選非負 weight（預設 1）；每個群組包含 items 非空陣列，或一層 groups 子群（不可同時存在）。選定分類、子群後，再均勻抽取 items。支援最多兩層群組，**不**支援保底、不放回或資產發放。

API用途
create(policy, { random?, maxBatch? }?)建立規則，random 需每次回傳 0 ≤ r ＜ 1，預設 Math.random；maxBatch 預設 10000。
pick(), pickMany(count)獨立放回抽選單筆／批次；回傳候選項目的 JSON 副本，不建立實體卡。
getPolicy(), validate()回傳規則副本／驗證結果。

各層權重按該層相對比例計算，不以類別內物品數量改變最外層選中機率。零權重不會被抽到，全零、負數、非有限權重、空候選池會在建立時拒絕。資料與隨機來源錯誤以 TypeError／RangeError／Error 回報。

與既有 data/random/random.js（基礎亂數）、state/reward_claim_flow.js（領獎順序）責任不同；宿主可自由組合，不強制引用。

最小使用範例

const policy = SlowlyRewardPoolPolicy.create({
  groups: [
    { id:"ordinary", weight:2, items:["a", "b"] },
    { id:"special", weight:1, groups:[
      { id:"common", weight:1, items:["s1", "s2"] },
      { id:"unique", weight:1, items:["s3"] }
    ]}
  ]
});
const chosenId = policy.pick();
const fiveIds = policy.pickMany(5); // 有可能重複

以上 JS 不負責畫面、永久儲存、遊戲專屬規則；宿主自行提供資料、UI 與必要回呼。
