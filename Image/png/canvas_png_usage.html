Canvas PNG

將 Canvas 用瀏覽器原生 API 輸出為 PNG Blob 或 PNG Data URL。

載入

<script src="https://lib.stillnessbyslowly.com/Image/png/canvas_png.js"></script>

Canvas → Blob

const blob = await SlowlyCanvasPNG.toBlob(canvas);

Canvas → Data URL

const dataURL = SlowlyCanvasPNG.toDataURL(canvas);

API

SlowlyCanvasPNG.version
SlowlyCanvasPNG.toBlob(canvas, options?)
SlowlyCanvasPNG.toDataURL(canvas, options?)

不負責 Canvas 繪製、預覽、下載或儲存。
