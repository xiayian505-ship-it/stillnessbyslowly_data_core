Slowly Custom Date v1

取代瀏覽器原生 date 的可見介面，但保留原生 <input type="date"> 作為真正資料欄位。

載入順序

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/ui/custom_date.css">

<input type="date" id="myDate" data-slowly-date>

<script src="https://lib.stillnessbyslowly.com/ui/custom_date.js"></script>
<script>
  SlowlyDate.create("#myDate");
</script>

功能範圍

  • 年月切換
  • 日期選取
  • 今天提示與「今天」按鈕
  • 已選日期
  • 清除
  • 同步原生 input value
  • 觸發原生 input / change 事件
  • 支援 min / max / disabled

單一實例

const myDate = SlowlyDate.create("#myDate");

批次建立

const dates = SlowlyDate.createAll(
  'input[type="date"][data-slowly-date]'
);

API

instance.sync();
instance.open();
instance.close();
instance.destroy();

宿主覆寫顏色

#dateArea .slowly-date{
  --sd-bg:var(--panel);
  --sd-text:var(--ink);
  --sd-border:var(--line);
  --sd-hover:var(--surface-soft);
  --sd-selected-bg:var(--accent-soft);

Custom Date 只負責結構與互動；圓角、陰影、字級、網站配色等視覺風格由宿主決定。
