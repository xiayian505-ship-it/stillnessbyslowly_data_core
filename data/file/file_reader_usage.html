File Reader 使用說明

用途

File Reader 是通用 File / Blob 讀取核心， 將瀏覽器中的 File 或 Blob 讀為文字、ArrayBuffer 或 Data URL。

它不負責選擇檔案，也不解析 JSON、CSV、圖片或其他內容格式。

載入

<script src="file_reader.js"></script>

讀為文字

const text = await SlowlyFileReader.text(file);

需要指定文字編碼時：

const text = await SlowlyFileReader.text(file, "utf-8");

讀為 ArrayBuffer

const buffer = await SlowlyFileReader.arrayBuffer(file);

讀為 Data URL

const dataURL = await SlowlyFileReader.dataURL(file);

統一 read() 介面

const text = await SlowlyFileReader.read(file, {
  mode: "text",
  encoding: "utf-8"
});

const buffer = await SlowlyFileReader.read(file, {
  mode: "arrayBuffer"
});

const dataURL = await SlowlyFileReader.read(file, {
  mode: "dataURL"
});

與 Custom File 的關係

Custom File 負責「讓使用者選檔」； File Reader 負責「讀取已取得的 File / Blob」。 兩者責任分開。

責任邊界

File Reader 不處理：

  • 建立 file input 或檔案選擇 UI。
  • 檔案類型 accept 限制。
  • JSON.parse() 或 CSV 解析。
  • 圖片解碼與尺寸處理。
  • DOM 預覽。
  • 下載與 Object URL。
  • localStorage、IndexedDB 或後端儲存。

錯誤

輸入不是 File / Blob、讀取失敗、讀取被取消或指定未知 mode 時， Promise 會 reject；宿主自行決定如何顯示錯誤。
