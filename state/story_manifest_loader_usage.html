Story Manifest Loader｜使用說明

讀取篇章索引並安全載入各小節 JSON，提供快取與過期請求防護。

Demo　Test

引用方式

<script src="https://lib.stillnessbyslowly.com/state/story_manifest_loader.js"></script>

以上為部署後的預定網址，並非保證已經上架。使用全域 SlowlyStoryManifestLoader。

資料結構與 API

索引需包含 main、extras 兩個陣列；每篇必須有唯一 id 及非空 sections，每小節有全域唯一 id 及 file。小節 JSON 必須具有一致的 id 和 events: []。

方法結果
create({ baseUrl, manifestUrl?, fetcher? })建立獨立實例；baseUrl 是允許讀取的 HTTP(S) 資料目錄，建議以 / 結尾
loadManifest(source?)取得並驗證索引，亦可傳入索引物件；若較新的索引載入取代舊請求，舊請求回傳 null
loadSection(sectionId)依小節 ID 載入並快取；同小節同時請求共用工作，過期請求回傳 null
getManifest(), getSection(id), hasSection(id)取得安全副本／快取狀態
clearCache(id?), getState()清除一筆或全部快取；查詢狀態

限制與錯誤

禁止離開指定 baseUrl 目錄、其他 origin 或非 JSON 路徑。錯誤會以 TypeError／RangeError／Error 或 fetcher 原始錯誤拋出。索引重新載入成功後清除舊快取；重新載入失敗不覆蓋舊索引。clearCache 讓尚未完成的指定小節回應失效，但不取消 HTTP。索引可包含多小節；本零件不負責播放或預載全部小節。快取僅在記憶體。

依賴：原生 URL、fetch（或宿主提供 fetcher）。故事播放可另搭配既有 state/story_event_player.js，但不強制載入。

最小使用範例

const loader = SlowlyStoryManifestLoader.create({
  baseUrl: "https://example.com/story/data/",
  manifestUrl: "chapters.json"
});
await loader.loadManifest();
const section = await loader.loadSection("prologue");
// 將 section.events 交給宿主或 Story Event Player。

以上 JS 不負責畫面、永久儲存、遊戲專屬規則；宿主自行提供資料、UI 與必要回呼。
