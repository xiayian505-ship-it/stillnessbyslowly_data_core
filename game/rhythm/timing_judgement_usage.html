timing_judgement｜使用說明

功能：節奏音符時間差純判定：Perfect／Great／Good／Miss

公開 API

`SlowlyTimingJudgement.judge(options)`。

依賴與載入順序

無（零件本體沒有其他軍火庫依賴）

<script src="https://lib.stillnessbyslowly.com/game/rhythm/timing_judgement.js"></script>

以上是部署後的 HTTPS 絕對網址，必須先上傳新零件才會存在；依賴 JS 必須先載入。

輸入參數

`expected_ms`：預定音符時間；`actual_ms`：按鍵時間；`windows`：由嚴到寬，`[{label:"perfect",within_ms:60}, ...]`，必須嚴格遞增，皆非負有限數。

回傳結果

`{label,delta_ms,absolute_delta_ms,timing,hit}`；負值為 early、正值為 late、0 為 exact。超出最後一窗為 miss。

宿主實際接法

const judgement = SlowlyTimingJudgement.judge({
  expected_ms: 1000, actual_ms: 1098,
  windows: [
    { label: "perfect", within_ms: 60 },
    { label: "great", within_ms: 120 },
    { label: "good", within_ms: 200 }
  ]
});
console.log(judgement.label); // great

限制與錯誤

不處理 BPM 轉換（請用 `BeatTime`）、譜面、Combo、分數或排名。時間值單位固定毫秒，示範閾值可由宿主完全覆寫。

JS 會針對非法資料或缺少依賴明確拋出錯誤；宿主應自行 try/catch 處理使用者輸入。純計算零件沒有 destroy 生命週期；Undo 使用 clear 清空歷史。外觀、聲音與動畫完全由宿主控制。
