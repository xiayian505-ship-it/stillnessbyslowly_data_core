SVG Viewer｜使用說明

慢慢軍火庫獨立零件。由宿主決定輸入、操作、外觀和結果如何使用。零件不建立網站 UI。

載入順序

<script src="https://lib.stillnessbyslowly.com/data/blob/blob_url.js"></script>
<script src="https://lib.stillnessbyslowly.com/Image/svg/svg_viewer.js"></script>

公開 API：window.SlowlySVGViewer

const viewer = SlowlySVGViewer.create({
    image: document.querySelector("#svg_image"),
    stage: document.querySelector("#svg_stage"),
    viewport: document.querySelector("#svg_viewport"),
    on_state({ info, zoom, message, is_error }) {
        console.log(info, zoom, message, is_error);
    },
    maximum_bytes: 15728640,
    minimum_zoom: 0.1,
    maximum_zoom: 16,
    padding: 20
});
await viewer.open_file(file);               // 也可以 viewer.load_text(svg_text, name)
viewer.set_zoom(2);
const information = viewer.get_info();
viewer.clear();
viewer.destroy();

參數、回傳值與限制

create(options) 建立獨立檢視實例；image 必須是 img；stage 與 viewport 由宿主提供。

load_text(svg_text, name) / open_file(file) 非同步載入 SVG，回傳尺寸與動畫標記的資訊物件。

set_zoom(number) 設定倍率（預設 0.1～16），超界拋 RangeError。

get_info() 回傳資訊複本或 null；clear() 清空；destroy() 移除監聽、回收網址。

錯誤會拋出；on_state 用來接收一般訊息與顯示失敗通知。

預覽使用 img 而非 SVG innerHTML。CSS / SMIL 是否播放取決於瀏覽器；本模組不會保證安全展示所有 SVG。
