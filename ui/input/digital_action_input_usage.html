Digital Action Input｜使用說明

鍵盤和多指 Pointer 融合成數位按下／放開事件，來源彈珠台 KEYMAP、press 與 Pointer 控制。

檔案與載入順序

<script src="https://lib.stillnessbyslowly.com/ui/canvas/canvas_rect_drag.js"></script>
<script src="https://lib.stillnessbyslowly.com/ui/input/digital_action_input.js"></script>

公開 API

window.SlowlyDigitalActionInput

  • create({key_map?, pointer_targets?, keyboard_target?, blur_target?, on_change?, prevent_default?, enabled?}) → instance
  • instance.pressed(action) → boolean
  • instance.snapshot() → {enabled, actions}
  • instance.clear()；instance.set_enabled(boolean)；instance.destroy()

選項、數值與輸出

  • key_map：鍵碼（KeyboardEvent.code）到任意 action 字串，例如 {Space:"launch"}。
  • pointer_targets 陣列：{element, action:"launch"} 或 {element, resolve_action(event,local_point)}。
  • on_change(event) 回傳 {action,type:"pressed"/"released",pressed,source}；多個來源共用同一動作只觸發一次轉換。
  • Canvas resolve_action 會引用 CanvasRectDrag.pointFromEvent，因此需要先載入既有 CanvasRectDrag。
  • blur、pointercancel、lostpointercapture、停用和 destroy 都清理來源。

使用範例（請先按上列順序載入腳本）

const actions = SlowlyDigitalActionInput.create({
  key_map: { Space:"launch", ArrowLeft:"move_left" },
  pointer_targets: [{ element: document.getElementById("launch"), action:"launch" }],
  on_change: event => console.log(event.action, event.type)
});
console.log(actions.pressed("launch"));
// 頁面卸載或控制器不再需要時呼叫 actions.destroy();

錯誤、清理與限制

只監聽宿主提供的目標，不替宿主建立 UI；無虛擬搖桿向量控制功能。手指多來源狀態不應互相覆蓋；destroy 移除所有監聽。

若輸入格式錯誤、非法負值或非有限數字，原則上拋出 TypeError 或 RangeError。 需保留狀態的物件可使用 reset/cancel/clear/destroy 或非同步 stop，實際方法以上列 API 為準。

這顆 JS 不附加遊戲造型、不依賴打包工具，使用獨立 IIFE ＋ window API。 本頁文中的 HTTPS 新零件網址須等使用者部署後才會可用。
