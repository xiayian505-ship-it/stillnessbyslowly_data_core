Audio Oscillator

只負責 OscillatorNode；AudioContext 與輸出鏈由宿主決定。

最小使用

const ctx = SlowlyAudioContext.create();
const osc = SlowlyAudioOscillator.create(ctx, { type: "triangle", frequency: 440 });
osc.connect(ctx.destination);
SlowlyAudioOscillator.start(osc);
SlowlyAudioOscillator.stop(osc, ctx.currentTime + 0.2);
