Slowly Grid Shuffle Until v1.0.0

把矩形二維 grid 反覆重新排列，直到宿主提供的驗收條件成立，或達到最大嘗試次數。

<script src="https://lib.stillnessbyslowly.com/game/grid/shuffle_until.js"></script>

const result = SlowlyGridShuffleUntil.run(grid, {
  maxAttempts: 5,

  shuffle(values) {
    return myShuffle(values);
  },

  accept(currentGrid) {
    return !hasImmediatePattern(currentGrid);
  }
});
