Data Validation 使用說明

用途

Data Validation 是通用資料驗證核心，依 schema 驗證 JavaScript 資料並回傳錯誤清單。

不負責 DOM、表單 UI、錯誤訊息顯示、資料儲存、提交或 JSON Schema 標準。

載入

<script src="data_validation.js"></script>

基本使用

const schema = {
  name: {
    required: true,
    type: "string",
    min: 2,
    max: 20
  },

  age: {
    type: "integer",
    min: 18
  },

  email: {
    pattern: /^[^\s@]+@[^\s@]+\.[^\s@]+$/
  },

  "profile.nickname": {
    required: true
  },

  code: {
    validate(value, data) {
      return value === "SBS" || "code 必須是 SBS。";
    }
  }
};

const result = SlowlyDataValidation.validate(data, schema);

支援規則

  • required：必填。
  • type：string、number、boolean、function、array、object、integer、null 等。
  • min / max：數字比較數值；字串與陣列比較 length。
  • pattern：使用 RegExp 驗證字串。
  • validate：自訂驗證函式。

自訂驗證

validate(value, data) {
  if (value === "SBS") {
    return true;
  }

  return "code 必須是 SBS。";
}

回傳 true 或 undefined 視為通過；回傳字串時，字串會成為錯誤訊息。

回傳格式

{
  valid: false,
  errors: [
    {
      path: "age",
      rule: "min",
      message: "不可小於 18。",
      value: 15
    }
  ],
  errorCount: 1
}

巢狀欄位

欄位名稱可使用點記法：

{
  "profile.nickname": {
    required: true
  }
}

責任邊界

Data Validation 不處理：

  • DOM 與表單元素。
  • Toast 或錯誤文字顯示。
  • 資料提交與儲存。
  • JSON.parse()。
  • JSON Schema 標準。
  • 非同步／遠端驗證。
  • 欄位自動轉型。
