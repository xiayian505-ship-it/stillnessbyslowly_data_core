Combatant Config

通用戰鬥單位基礎數值正規化工具。 將不同寫法的 HP、Shield 與攻擊範圍整理成固定格式。

不負責 ID 查表、EnemyData、玩家／敵人身份、AI Pattern、傷害計算、回合或 UI。

引入

<script src="./combatant_config.js"></script>

輸出格式

{
  maxHP: 25,
  hp: 25,
  shield: 0,
  attackMin: 3,
  attackMax: 6
}

接受不同輸入寫法

const config = CombatantConfig.normalize({
  hp: 25,
  atk: [3, 6]
});

也可以使用較明確的欄位：

const config = CombatantConfig.normalize({
  maxHP: 25,
  currentHP: 18,
  shield: 4,
  attackMin: 3,
  attackMax: 6
});

宿主提供預設值

const defaults = {
  maxHP: 20,
  shield: 0,
  attackMin: 1,
  attackMax: 3
};

const config = CombatantConfig.normalize(source, defaults);

資料來源由宿主處理

const source = EnemyData[id];

const enemy = CombatantConfig.normalize(
  source,
  defaultEnemyStats
);

Combatant Config 不知道 EnemyData 是什麼，也不會自行查 ID。
