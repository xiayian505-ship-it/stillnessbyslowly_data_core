Demo 功能測試

Story Reading Progress｜故事閱讀進度

分開追蹤看過與讀完，保存單一篇章書籤，支援還原與驗證，不預設任何儲存平台。

一、載入方式

本地開發測試：

<script src="./story_reading_progress.js"></script>

正式部署在你的軍火庫後，其他宿主可以採絕對網址：

https://lib.stillnessbyslowly.com/state/story_reading_progress.js

注意：本 ZIP 尚未部署，上列 HTTPS 網址為預計發布路徑，不代表目前已上線。

二、公開 API

全域物件：SlowlyStoryReadingProgress；版本 1.0.0。錯誤輸入通常丟出 TypeError／RangeError／Error，應由宿主捕捉。

函式用途與輸入輸出
create(initialData?)建立管理器，也可用快照初始化
markSeen(id) / markCompleted(id)標記已看過／已完成（完成同時看過）
skip(id) / finish(id)略過／完成，並清除該篇書籤
getStatus(id)回傳 { seen, completed }
setBookmark(id, position)position 為 { eventId?, eventIndex? }；至少一項有效
getBookmark() / clearBookmark(id?)取得書籤副本／清除指定或全部書籤
resolveBookmark(events)優先用 eventId 查找；失效不悄悄跳其他位置
snapshot() / restore(data)取出或匯入已看／已完成／書籤資料
reset(id) / clear()清除指定篇章或所有閱讀紀錄

三、最小使用範例

const progress = SlowlyStoryReadingProgress.create();
progress.markSeen("prologue");
progress.setBookmark("prologue", { eventId: "line_3", eventIndex: 2 });
const saved = progress.snapshot();
// 儲存時由宿主自行 JSON.stringify(saved) 並選擇儲存方式。
progress.finish("prologue");

四、相依及宿主責任

核心獨立運作，沒有強制依賴任何其他軍火庫零件。這不代表要重做既有能力：宿主仍應使用適當的軍火庫零件處理逐字效果、導航、牌組合法性、卡牌升級與儲存等工作。

只支援單一最近書籤。當 eventId 已不存在時，回傳 found:false/missing-id，刻意不回退到可能已位移的 eventIndex；沒有自動 localStorage。
