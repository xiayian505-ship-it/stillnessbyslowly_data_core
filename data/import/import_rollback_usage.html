Import Rollback v1.0.0

Import Rollback 只管理匯入前快照的生命週期。 真正要保存什麼、如何恢復，由宿主透過 capture 與 restore 決定。

本模組沒有 UI，因此不需要宿主載入 CSS。

引用

<script src="https://lib.stillnessbyslowly.com/data/import/import_rollback.js"></script>

基本使用

const rollback = ImportRollback.create({
  capture: async () => {
    return {
      records: await collection.all()
    };
  },

  restore: async snapshot => {
    await collection.clear();

    for (const record of snapshot.records) {
      await collection.add(record);
    }
  }
});

await rollback.capture();

const result = await SafeImport.run({
  prepare,
  validate,
  commit,

  rollback: async context => {
    await rollback.rollback(context);
  }
});

if (result.ok) {
  rollback.release();
}

含 Blob / 圖片的宿主

const importedImageIds = new Set();

const rollback = ImportRollback.create({
  capture: async () => {
    const records = await collection.all();
    const images = [];

    for (const record of records) {
      if (!record.imageId) continue;

      const blob = await imageStore.getBlob(record.imageId);

      if (blob) {
        images.push({
          id: record.imageId,
          blob
        });
      }
    }

    return { records, images };
  },

  restore: async snapshot => {
    for (const id of importedImageIds) {
      await imageStore.remove(id).catch(() => {});
    }

    await collection.clear();

    const restoredIds = new Map();

    for (const image of snapshot.images) {
      const id = await imageStore.save(image.blob, {
        id: image.id
      });

      restoredIds.set(image.id, id);
    }

    for (const record of snapshot.records) {
      const restored = { ...record };

      if (restored.imageId && restoredIds.has(restored.imageId)) {
        restored.imageId = restoredIds.get(restored.imageId);
      }

      await collection.add(restored);
    }
  }
});

API

API 說明
ImportRollback.create({ capture, restore }) 建立一個匯入 rollback scope。
capture(context) 執行宿主提供的 capture，保存匯入前快照。
rollback(context) 用已保存的快照呼叫 restore；沒有快照時不執行恢復。
release() 匯入成功後丟棄快照。
ready 目前是否已保存快照。
restoring 目前是否正在恢復。
restored 最近一次 rollback 是否成功完成。

設計邊界

  • 不解析 JSON。
  • 不讀寫 localStorage 或 IndexedDB。
  • 不假設 snapshot 的資料格式。
  • 不自動清除宿主資料。
  • 不處理 UI、confirm 或 toast。
  • 不取代 Safe Import；它只補上 rollback 快照生命週期。
