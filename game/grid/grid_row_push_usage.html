Grid Row Push｜使用說明

矩形棋盤整排下推；由宿主決定內容、壓力週期與後果。

本頁是已編寫的使用說明；正式公開網址需在檔案上傳部署後才可使用。

職責與 Grid Gravity 的不同

本件只做整排向下位移，將最後一列交給 overflow；不逐欄壓實、不算連通、不產生新泡泡，也不觸發 Game Over。來源靈感為泡泡龍 addPressureRow()，但由宿主供給頂列。

輸入與回傳

參數契約
grid規則矩形的二維列陣列（可為 []）。
new_row與 grid 第一列等寬，頂列由宿主提供；空 grid 只接受 []。
options.is_empty(cell,index,row_index)可選；預設 null／undefined 才算空。0、false 均當占用。
options.clone_cell(cell)可選；預設回傳原參照，僅新建列陣列；需要深層隔離時由宿主提供。
回傳{ grid, overflow, overflow_occupied, shifted_rows }；原 grid 及 new_row 不變。

特殊情況

零列加空新列回傳空棋盤；單列會直接被新列取代，原列變成 overflow；零寬矩形仍保留列數。原物件不是自動深拷貝，不能修改新棋盤中的巢狀資料後宣稱原資料不變。

驗證入口

可操作 Demo ｜ 逐項 PASS／FAIL Test。無第三方依賴。

完整引用範例（部署後 HTTPS 絕對路徑）

<script src="https://lib.stillnessbyslowly.com/game/grid/grid_row_push.js"></script>
<script>
const old_grid = [[null, 1], [2, null], [null, 3]];
const pressure_row = [1, null];
const result = window.SlowlyGridRowPush.push_down(old_grid, pressure_row);
console.log(result.grid, result.overflow, result.overflow_occupied);
// 若儲存格含巢狀物件，可加：{ clone_cell: cell => structuredClone(cell) }
</script>
