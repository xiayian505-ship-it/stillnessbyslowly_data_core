Slowly Game Shell v1.0.0

通用遊戲外殼。 Game Shell 不知道裡面是哪一款遊戲； 它只透過 Game Adapter 管理開始、暫停、重新開始、 遊戲時間與可選存檔。

FictionStorage、Toast、Audio、 Effects、Preference 都不是 Game Shell 的硬依賴。 宿主需要時再接。

最小使用方式 

const shell = SlowlyGameShell.mount("#game", {
  game: {
    mount(target, hooks) {
      return MyGame.mount(target, {
        autoStart: false,

        onChange(state) {
          hooks.stateChange({ state });
        },

        onFinish(result) {
          hooks.finish({ result });
        }
      });
    },

    start(game) {
      game.start();
    },

    restart(game) {
      game.restart();
    },

    destroy(game) {
      game.destroy();
    }
  }
});

Game Adapter

唯一必要方法是 mount(target, hooks)。

其餘能力全部依遊戲實際功能決定。 遊戲沒有 pause() 也能使用 Shell： Shell 仍會暫停自己的計時， 並把 Game Slot 設為 inert。 

{
  mount(target, hooks), // 必要

  start(game),          // 可選
  pause(game),          // 可選
  resume(game),         // 可選
  restart(game),        // 可選

  snapshot(game),       // 使用儲存時需要
  restore(game, data),  // 使用載入時需要

  destroy(game)         // 可選
}

hooks 

hooks.stateChange(meta)

hooks.finish({
  result,
  ...
})

hooks.notify(message)

Shell 不解析遊戲自己的 state 結構， 也不規定勝負字串。 Adapter 只需要在適當時間通知 Shell。

手動 / 自動開始 

SlowlyGameShell.mount("#game", {
  lifecycle: {
    autoStart: false
  },

  game
});

false： 使用者按「開始」後才 mount / start。

true： Shell 建立後立即開始。

Save Adapter

Game Shell 不知道資料存在 localStorage、Supabase、 REST API 或其他後端。

只要求三個 async 方法： 

const saveAdapter = {
  async get(id) {
    // 讀取一筆存檔
  },

  async save(record) {
    // 新增或覆寫存檔
  },

  async remove(id) {
    // 刪除存檔
  }
};
const shell = SlowlyGameShell.mount("#game", {
  game,

  save: {
    adapter: saveAdapter,

    id: "slot-1",

    auto: true,

    resumePlayingOnLoad: true
  }
});

Save Adapter 就是後端預留接口。 現在可以接 FictionStorage， 未來可換成 Save Manager、 Supabase 或自訂 API， Game Shell 本體不需要改。

存檔格式 

{
  id: "slot-1",

  version: 1,

  savedAt: "...",

  shell: {
    phase: "playing",
    result: null,
    elapsedMs: 12345
  },

  game: {
    // gameAdapter.snapshot()
  }
}

自動存檔 

shell.setAutoSave(true);
shell.setAutoSave(false);

自動存檔只在 Save Adapter 與 game.snapshot() 都可用時生效。

通知

沒有設定 notify 時， Shell 會把訊息顯示在自己的 message 區。

若宿主要使用 Toast： 

SlowlyGameShell.mount("#game", {
  game,

  notify(message) {
    toast.show(message);
  }
});

CSS 原則

Game Shell CSS 只提供基本排列、 控制列、狀態列， 以及暫停時的必要互動狀態。

顏色、字體、按鈕皮膚、 陰影與動畫全部交給宿主。

刻意不包進 Shell 的功能

排行榜規則、 音效語意、 特效語意與遊戲內容， 都留在宿主或其他完成品。

例如「最快通關 TOP 3」 和「最高分 TOP 3」 是不同規則， 不應由 Game Shell 猜測。
