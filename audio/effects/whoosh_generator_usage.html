Whoosh Generator｜程式化呼嘯音效｜使用說明

使用 Noise → 動態 Bandpass Filter → Gain／Envelope 合成單次呼嘯。沒有內嵌音檔。

產生噪音後使用既有 Filter 與 Envelope 排程「起始 → 高峰 → 結束」掃頻；音量另以 Attack/Release 包絡控制。這是組合層，不會生成 WAV/MP3、不依賴素材庫，也不代替現有 AudioContext／Noise／Gain。

公開 API

await window.SlowlyAudioWhooshGenerator.play(options) 會回傳 { context, start_at_seconds, end_at_seconds, silent, stop() }。

start_at_seconds／end_at_seconds 是 Web Audio Context 時間線上的絕對秒數。stop() 可以重複呼叫；提前停止會以短淡出避免直接硬切。每次播放有獨立節點，結束後斷開連線。它不會關閉共用 AudioContext。

當 volume = 0 時不建立音源，回傳 silent: true；其他合法播放為 silent: false。啟動 AudioContext 失敗時 Promise 會拒絕，不會回報假成功。

參數

options 名稱單位／限制示範預設
duration_seconds秒；單次長度（0.02～8）0.45
volume音量（0～1）；0 不建立音源0.15
noise_type噪音音色（white、pink、brown）white
frequency_start_hz起始濾波頻率 Hz；不得超出取樣率安全範圍350
frequency_peak_hz高峰濾波頻率 Hz2600
frequency_end_hz結束濾波頻率 Hz600
peak_position高峰位於總時長比例，必須嚴格介於 0 與 10.5
filter_q帶通濾波 Q0.7
attack_seconds起音秒數；和 release 不得超過總長0.06
release_seconds淡出秒數0.14
start_delay_seconds延後開始秒數0
  • destination：可選 AudioNode，宿主的總音量／混音節點；不接管宿主全域靜音。
  • random：可選 () => number，只轉交既有 Noise 給測試控制取樣。

高峰比例必須嚴格介於 0～1；頻率不得超過 context.sampleRate * 0.475。同時設 attack＋release 不得大於 duration；若只縮短總長，預設 attack／release 會按總長調整。所有數值須為有限 number，不接受字串形式數字，非法資料會拋 TypeError 或 RangeError。超出實際取樣率上限會在 AudioContext 啟用後檢查。

宿主如何呼叫

<button id="play_sound">播放音效</button>
<button id="stop_sound">提前停止</button>
<output id="sound_status"></output>
let active_sound = null;
const status = document.getElementById("sound_status");
document.getElementById("play_sound").addEventListener("click", async function () {
  try {
    active_sound = await window.SlowlyAudioWhooshGenerator.play({
    duration_seconds: 0.45,
    volume: 0.15,
    noise_type: 'white',
    frequency_start_hz: 350,
    frequency_peak_hz: 2600,
    // destination: my_audio_bus // 選用，須為同個 AudioContext 的 AudioNode
  });
  status.textContent = "已排程：" + active_sound.start_at_seconds.toFixed(3);
  } catch (error) {
    status.textContent = "播放失敗：" + error.message;
  }
});
document.getElementById("stop_sound").addEventListener("click", function () {
  if (active_sound) active_sound.stop();
});

使用限制與生命週期

  • 手機瀏覽器通常需要在使用者點擊時解鎖音訊；若被拒絕必須顯示錯誤。
  • 多次播放可交錯進行；播放太多聲音仍可能造成總音量疊加，請由宿主安排呼叫頻率、Master Bus 及靜音設定。
  • 停止本次播放不會停止其他音效，也不會關閉共用 Context。已排程的來源自然結束會自動斷線。
  • Noise 樣本由軍火庫既有 Noise 產生；不內嵌資料音檔，沒有聲音檔可下載。
  • 不支援 Background Audio、陀螺儀、震動、音效素材匯出或 AudioContext 共用總線管理。
  • 缺少依賴時直接報錯；不會偷偷建立自製替代音源或引入 vendor。
