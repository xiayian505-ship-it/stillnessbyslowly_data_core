FreeCell｜使用說明

慢慢軍火庫的可嵌入 FreeCell 完成品。只提供隨機開局、標準移牌、主動結束、勝利判定與末盤自動收牌。無 DB、UID、牌局庫、音效、勝利特效或持久化紀錄。

1. HTTPS 載入

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/component/solitaire/FreeCell/FreeCell.css">
<div id="my-freecell"></div>

<script src="https://lib.stillnessbyslowly.com/game/card/deck.js"></script>
<script src="https://lib.stillnessbyslowly.com/component/solitaire/FreeCell/FreeCell.js"></script>
<script>
  const game = window.SlowlyFreeCell.mount("#my-freecell");
</script>

需要先載入軍火庫 Deck 零件；兩者都是 HTTPS 絕對網址，不需要複製軍火庫 JS 到專案。

2. 遊玩方式

按「開始遊戲」隨機發 52 張牌（前四欄各 7 張，後四欄各 6 張）。點選牌或合法遞減紅黑交錯牌串，再點目的欄位、空自由格或對應回收格。八欄與四自由格決定可一次搬動的牌串數。回收格依花色從 A 排至 K，不支援由回收格取回牌。剩餘全部牌能按回收順序直接收完時，自動完成收牌並宣告勝利。

「結束遊戲」直接結束當局，不產生勝利事件；結束或破關後可以再開始隨機一局。

3. JavaScript API

const game = SlowlyFreeCell.mount("#my-freecell");
game.start();      // 隨機開始一局；遊戲中不會覆蓋目前牌局
game.end();        // 主動結束目前牌局
game.getState();   // 取得目前狀態快照（非即時參照）
game.destroy();    // 清除元件與事件監聽

4. 宿主事件

const host = document.querySelector("#my-freecell");
host.addEventListener("freecell:start", (event) => {
  // 隨機開局
});
host.addEventListener("freecell:end", (event) => {
  // 使用者主動結束，event.detail.reason === "manual"
});
host.addEventListener("freecell:win", (event) => {
  // 遊戲完成。宿主要播放特效或存紀錄，可以自行處理。
});

事件從元件容器觸發且可冒泡；event.detail.moves 是該局移動次數。元件不會主動執行宿主專屬功能。

5. 宿主換皮

#my-freecell.slowly-freecell {
  --sfc-surface: #eff4f9; /* 選用：牌桌底色 */
  --sfc-card: #ffffff;    /* 選用：不透明牌面 */
  --sfc-line: #8da2b9;
  --sfc-action-bg: #ffffff;
  --sfc-ink: #23384d;
  --sfc-red: #b52b51;
  --sfc-black: #243245;
  --sfc-selected: #dfb75e;
  --sfc-stack-step: 25px;
}

元件預設不替宿主設定底色、主題色或字體。空牌桌、按鈕和空槽透明；牌張使用不透明的系統底色以確保重疊時可讀，宿主可用變數自行設定。樣式只作用在 .slowly-freecell，不覆寫宿主 body 或全域按鈕。
