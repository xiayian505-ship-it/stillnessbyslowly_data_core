Circle Segment Collision｜使用說明

圓形接觸有限線段的幾何檢查；來源為原彈珠台 hitSeg 最近點計算。純計算、不修改球體。

檔案與載入順序

<script src="https://lib.stillnessbyslowly.com/game/physics/circle_segment_collision.js"></script>

公開 API

window.SlowlyCircleSegmentCollision

  • inspect({ circle: {x, y, radius}, segment: {start:{x,y}, end:{x,y}}, thickness?, inclusive?, fallback_normal? }) → 接觸結果
  • touches(options) → boolean

選項、數值與輸出

  • 圓心與線段端點均為有限數字；radius / thickness ≥ 0。
  • inclusive 預設 true；相切算接觸。
  • fallback_normal 為同點退化時可選的非零向量。
  • 回傳 touching、distance、collision_distance、overlap_depth、exactly_tangent、segment_parameter、closest_point、normal、degenerate_segment、normal_was_fallback。

使用範例（請先按上列順序載入腳本）

const contact = SlowlyCircleSegmentCollision.inspect({
  circle: { x: 40, y: 30, radius: 12 },
  segment: { start: { x: 0, y: 45 }, end: { x: 100, y: 45 } },
  thickness: 3
});
if (contact.touching) console.log(contact.normal, contact.overlap_depth);

錯誤、清理與限制

normal 指向從線段最近點到圓心；同點時先採備援向量，否則線段左法線，再否則 (1,0)。幾何結果不推進時間、不修改位置。若要反彈，另外引用 Collision Response 2D。

若輸入格式錯誤、非法負值或非有限數字，原則上拋出 TypeError 或 RangeError。 需保留狀態的物件可使用 reset/cancel/clear/destroy 或非同步 stop，實際方法以上列 API 為準。

這顆 JS 不附加遊戲造型、不依賴打包工具，使用獨立 IIFE ＋ window API。 本頁文中的 HTTPS 新零件網址須等使用者部署後才會可用。
