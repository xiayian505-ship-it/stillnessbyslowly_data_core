undo_snapshot_stack｜使用說明

功能：可保存 Set、Map 等資料的局面 Undo 快照堆疊

公開 API

`SlowlyUndoSnapshotStack.create({capacity?,clone?})` 建立獨立實例，支援 `push`、`undo`、`clear`、`size`、`can_undo`、`snapshot`。

依賴與載入順序

無（零件本體沒有其他軍火庫依賴）

<script src="https://lib.stillnessbyslowly.com/state/undo_snapshot_stack.js"></script>

以上是部署後的 HTTPS 絕對網址，必須先上傳新零件才會存在；依賴 JS 必須先載入。

輸入參數

`capacity`：正整數，預設 200。`clone(value)`：可自訂深拷貝，預設為瀏覽器 `structuredClone`；不支援此 API 時必須自行提供 clone，否則明確拋錯。

回傳結果

`push` 回傳目前堆疊數量；`undo` 回傳獨立的快照副本，若無歷史則 `null`。`snapshot()` 僅回傳 `{size,capacity,can_undo}` 中繼資料。

宿主實際接法

const history = SlowlyUndoSnapshotStack.create({ capacity: 200 });
let state = { moves: 0, boxes: new Set(["2:3"]) };
history.push(state); // 修改前保存
state.moves += 1;
state.boxes.add("3:3");
state = history.undo(); // boxes 還是 Set；沒有修改保存前的物件

限制與錯誤

不包含 Redo、不讀寫 window.history、不管理 DOM、遊戲狀態由宿主自行恢復。無法深拷貝的值（例如 DOM Node）需由宿主自訂 clone 或轉換。

JS 會針對非法資料或缺少依賴明確拋出錯誤；宿主應自行 try/catch 處理使用者輸入。純計算零件沒有 destroy 生命週期；Undo 使用 clear 清空歷史。外觀、聲音與動畫完全由宿主控制。
