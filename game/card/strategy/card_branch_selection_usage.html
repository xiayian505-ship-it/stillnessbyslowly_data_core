Card Branch Selection｜使用說明

檢查單張實體卡是否有資格切換戰術分支；回傳新卡片，不改動原始資料。

Demo　Test

引用方式

<script src="https://lib.stillnessbyslowly.com/game/card/strategy/card_branch_selection.js"></script>

以上為部署後的預定網址，並非保證已經上架。使用全域 SlowlyCardBranchSelection。

API

方法說明
create({ branchesByType, defaultBranch?, minimumLevel?, canSelect?, getInstanceId?, getCardType?, getCardLevel?, getBranch? })建立分支規則。預設最低等級 1、預設分支為每類首項。
getAvailable(card, context?)取得目前等級及宿主自訂條件允許的分支陣列。
getCurrent(card)取得卡目前分支，未設定時回退類型預設。
canSelect(card, branch, context?)回傳 { ok, reason }，可能原因：unsupported_type / invalid_branch / insufficient_level / not_allowed。
select(card, branch, context?), reset(card, context?)成功回傳 { ok:true, card:新副本 }；規則不成立回傳 { ok:false, reason, card:null }。
getRules()規則安全副本。

界線

實體識別預設讀 card.id，不是卡種 card.cardId。選擇採非修改式回傳，由宿主自己保存。宿主可透過 canSelect 回呼限制遊戲階段，必須同步回傳布林值。格式錯誤拋 TypeError／RangeError；未達等級不拋錯，回傳原因。此零件不執行破盾、汲取等戰術效果，也不升級卡牌。

獨立可用；如有需要可與既有 game/card/strategy/card_level_progression.js、card_effect_registry.js 組合。

最小使用範例

const branches = SlowlyCardBranchSelection.create({
  branchesByType: { attack: ["標準", "破盾", "汲取"] },
  minimumLevel: 1
});
const original = { id:"instance-1", cardId:"attack-1", type:"attack", level:2, branch:"標準" };
const result = branches.select(original, "破盾");
if (result.ok) {
  // 宿主自行以 result.card 更新收藏；original 保持不變。
}

以上 JS 不負責畫面、永久儲存、遊戲專屬規則；宿主自行提供資料、UI 與必要回呼。
