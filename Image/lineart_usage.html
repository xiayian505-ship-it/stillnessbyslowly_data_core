Lineart｜使用說明

沿用既有 Sobel 線稿的內圈計算，只修正輸出邊框的不透明白底，並補齊 Demo／Test。

本頁是已編寫的使用說明；正式公開網址需在檔案上傳部署後才可使用。

既有 API

window.Lineart.draw(img, canvas, { threshold })，同步回傳 canvas。img 可用已載入的 HTMLImageElement 或有寬高的可繪來源；canvas 由宿主建立。並不是新創建的 Edge Detection 引擎。

處理流程

原版灰階 → 3×3 均值降噪 → Sobel X/Y 邊緣梯度 → 大於 threshold 為黑色、否則白色。預設 threshold=12；threshold 欄位不能轉有限數時亦採 12。輸出 Canvas 尺寸強制改為來源尺寸。

限制與需人工驗收

Sobel 只迭代內圈 (1 .. width-2 / height-2)，最外圈已修正為不透明白色；低於 3px 的來源無內圈可運算，輸出為白色底。跨域圖片若無 CORS，Canvas getImageData 可能拋 SecurityError。原有內圈演算法與手動測試頁 Image/test_lineart.html 不修改。

驗收入口

實際 Demo ｜ 原核心 PASS／FAIL Test ｜ 舊手動測試。

完整引用範例（部署後 HTTPS 絕對路徑）

<script src="https://lib.stillnessbyslowly.com/Image/lineart.js"></script>
<input type="file" id="local_image" accept="image/*">
<canvas id="output_canvas"></canvas>
<script>
document.querySelector("#local_image").addEventListener("change", function (event) {
  const file = event.target.files?.[0];
  if (!file) return;
  const temporary_url = URL.createObjectURL(file);
  const source_image = new Image();
  source_image.onload = function () {
    try {
      window.Lineart.draw(source_image, document.querySelector("#output_canvas"), {threshold: 12});
    } catch (error) {
      console.error("線稿繪製失敗", error);
    } finally {
      URL.revokeObjectURL(temporary_url);
    }
  };
  source_image.onerror = function () {
    URL.revokeObjectURL(temporary_url);
    console.error("圖片解碼失敗");
  };
  source_image.src = temporary_url;
});
</script>
