卡牌等級處理｜使用說明

計算暫時等級增減後的有效等級；依宿主條件及上限升級選定卡牌。

一、職責與界線

計算暫時等級增減後的有效等級；依宿主條件及上限升級選定卡牌。

宿主決定升級條件、成本、成長公式與上限；本零件不預設某款遊戲的最高等級或升級獎勵。

二、相依與載入

無。

三、公開 API

全域物件：CardLevelProgression。名稱、參數與回傳結果以此頁和實際原始碼為準。

函式行為與結果
calculateEffectiveLevel(baseLevel, temporaryBonus?, options?) 計算暫時等級並限制至 options.maximumLevel。
upgradeEligibleCards(cards, options?) 依 options.canUpgradeCard、levelIncrease、maximumLevel、getCardLevel、setCardLevel 批次升級。

四、最小使用範例

const ownedCards = [
  { id: "one", level: 1, canUpgrade: true },
  { id: "two", level: 4, canUpgrade: false }
];

const upgradedCards = CardLevelProgression.upgradeEligibleCards(ownedCards, {
  levelIncrease: 2,
  maximumLevel: 5,
  canUpgradeCard: card => card.canUpgrade
});
console.log(upgradedCards);
