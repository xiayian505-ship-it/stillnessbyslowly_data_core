Iframe Create

只負責建立 iframe 元素並回傳。它不設定 src、不插入 DOM、不處理顯示／隱藏，也不管理 History。

載入

<script src="https://lib.stillnessbyslowly.com/ui/iframe/iframe_create.js"></script>

最簡單使用

const iframe = SlowlyIframeCreate.create();
document.querySelector("#host").appendChild(iframe);

建立時設定基本識別資訊

const iframe = SlowlyIframeCreate.create({
  id: "viewer",
  className: "embedded-page",
  title: "慢慢內容"
});

document.querySelector("#host").appendChild(iframe);

搭配 Iframe Source

const iframe = SlowlyIframeCreate.create({
  className: "embedded-page",
  title: "慢慢內容"
});

document.querySelector("#host").appendChild(iframe);
SlowlyIframeSource.set(iframe, "story.html");

Public API

SlowlyIframeCreate.create(options)

Options

{
  id: "viewer",
  className: "embedded-page",
  title: "慢慢內容"
}
