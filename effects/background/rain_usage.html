Canvas Rain（持續雨幕）｜使用說明

獨立的 Canvas 持續雨線效果，不附帶漣漪、閃電、雷聲或雨聲。

開啟獨立功能測試頁

載入（正式 HTTPS 路徑）

<script src="https://lib.stillnessbyslowly.com/effects/background/rain.js"></script>

正式 URL 必須等零件部署到軍火庫後才會有效；ZIP 本身不會修改 GitHub 或目錄資料。

宿主自行決定 CSS

零件不載入 CSS、不寫入 Canvas 的 style、不建立舞台、不決定定位、層級或版面。宿主提供 Canvas 元素與尺寸。

<div class="my-stage">
  <canvas id="effect"></canvas>
</div>

<style>
  .my-stage { position: relative; width: 100%; height: 280px; }
  .my-stage canvas { display: block; width: 100%; height: 100%; }
</style>

上述 CSS 只是宿主範例，不是軍火庫零件的樣式或依賴。

基本使用

const rain = SlowlyCanvasRain.create({
  canvas: '#effect',
  count: 180,
  color: '#d7f2f1',
  wind: 0.2,
  speed: 1
});

rain.start();
// 不需要時
rain.stop();
rain.destroy();

建立參數

選項預設說明
canvas必填Canvas 元素，或 CSS 選擇器。
countmin(320, floor(width / 4))雨滴數（範圍 0–1200）。
color#d7f2f1雨線顏色（Canvas CSS 顏色字串）。
opacity1雨線整體透明度（0–1）。
speed1雨落速度倍率。
wind0.2水平風向量；正值向右、負值向左。
length1雨線長度倍率。
maxDpr1.5最高裝置像素比。
width / height從 Canvas 的 CSS 尺寸讀取手動指定畫布繪圖尺寸（像素）。
autoResizetrue自動偵測 Canvas 尺寸。
autoStartfalsetrue 為建立後即開始動畫。

公開方法

rain.start();         // 啟動或繼續動畫（重複呼叫安全）
rain.stop();          // 停止並保留最後畫面
rain.advance(0.016);  // 手動推進（秒；每次最多 0.05 秒）
rain.draw();          // 重畫目前雨滴
rain.resize();        // 重新適配 Canvas 尺寸
rain.destroy();       // 停止並解除監聽

注意事項

下雨僅負責雨滴位置與雨線繪製；使用其他軍火庫的音效、閃光、漣漪時，必須由宿主自行安排觸發。reduced-motion 啟用時不執行逐幀動畫，視覺停留在靜態雨滴。

零件不引用其他軍火庫 JS。每個 Canvas 由一個效果管理，若宿主需要疊加不同效果，應建立各自的 Canvas 圖層並由宿主決定排列。

宿主負責在移除元件或離開場景時呼叫 destroy() 釋放資源。
