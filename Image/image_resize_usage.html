Image Resize｜使用說明

已存在的縮圖核心，只補正式使用說明與驗收入口。

本頁是已編寫的使用說明；正式公開網址需在檔案上傳部署後才可使用。

既有零件，非新核心

維持現有 Image/image_resize.js 不變，補齊 Usage、獨立 Demo 和新 Test。舊人工頁 Image/test_image_resize.html 也保留。與 Image/image_compress_to_size.js 的「位元組壓縮」不同，Resize 只保證尺寸縮小（不放大）。

公開 API 與參數

名稱意義
ImageResize.resize(blob, options)Promise<result>，輸入 File／Blob。
maxWidth / maxHeight最大寬／高，預設 600／600。
type / quality預設 image/jpeg、0.82；JPEG 會填白底。
maxInputBytes預設 12 MiB。
結果blob、width、height、sourceWidth、sourceHeight、sourceBytes、outputBytes、type。

限制與安全

原版 JS 的 options 邊界驗證不完善；不要把非正長寬、越界品質當成已完全拒絕。JPEG 不保留 alpha；高解析度圖片仍受手機 Canvas 記憶體限制。物件 URL 由核心讀圖後釋放，宿主自己建立的預覽 URL 要自己釋放。部分格式由瀏覽器本身決定支援程度。

完整引用範例（部署後 HTTPS 絕對路徑）

<script src="https://lib.stillnessbyslowly.com/Image/image_resize.js"></script>
<input type="file" id="local_image" accept="image/*">
<script>
document.querySelector("#local_image").addEventListener("change", async function (event) {
  const file = event.target.files?.[0];
  if (!file) return;
  try {
    const resized = await window.ImageResize.resize(file, {
      maxWidth: 800, maxHeight: 600, type: "image/png", quality: 0.85
    });
    console.log(resized.width, resized.height, resized.blob);
  } catch (error) {
    console.error("無法縮圖", error);
  }
});
</script>
