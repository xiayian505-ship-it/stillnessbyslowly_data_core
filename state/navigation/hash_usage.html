API

SlowlyNavigationHash.normalizeHash("chapter-2");
SlowlyNavigationHash.get();
SlowlyNavigationHash.value();
SlowlyNavigationHash.set("/page.html", "chapter-2");
SlowlyNavigationHash.remove("/page.html#chapter-2");
SlowlyNavigationHash.matches("chapter-2", "#chapter-2");
SlowlyNavigationHash.go("chapter-2");
SlowlyNavigationHash.clear();

go() 只設定 location.hash；不查找或操作 DOM 元素。
