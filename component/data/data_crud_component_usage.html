Slowly Data CRUD Component

純前端 CRUD 元件。依欄位設定自動建立資料列表、查看、新增、修改與刪除介面，資料儲存於 localStorage。

載入

請依照下列順序載入。Timestamp 與 Fiction Storage 都是必要依賴。

<link rel="stylesheet"
  href="https://lib.stillnessbyslowly.com/ui/responsive.css">

<link rel="stylesheet"
  href="https://lib.stillnessbyslowly.com/component/data/data_crud_component.css">

<script src="https://lib.stillnessbyslowly.com/date/timestamp.js"></script>
<script src="https://lib.stillnessbyslowly.com/fiction/Fiction_storage.js"></script>
<script src="https://lib.stillnessbyslowly.com/component/data/data_crud_component.js"></script>

最簡單呼叫

<div id="crud"></div>

<script>
  const crud = SlowlyDataCRUD.create({
    target: "#crud",
    storageKey: "my-tool-data",
    fields: [
      { key: "name", label: "名稱", type: "text", required: true },
      { key: "amount", label: "金額", type: "number" },
      { key: "date", label: "日期", type: "date" }
    ]
  });
</script>

必要設定

設定說明
target元件掛載位置。可傳 selector 字串或 HTMLElement。
storageKey每個宿主工具自己的唯一資料名稱。沒有預設值，空白時會停止初始化。
fields欄位設定陣列，至少需要一個欄位。

元件內部固定使用 records collection，因此實際 localStorage key 會是 <storageKey>:records。

Fields

{
  key: "name",
  label: "名稱",
  type: "text",
  required: true,
  placeholder: "請輸入名稱",
  defaultValue: "",
  list: true
}
欄位設定說明
key必填。資料欄位名稱，同一組 fields 不可重複。
label必填。顯示名稱。
type可用：text、number、textarea、date、select、checkbox。未填時為 text。
required是否必填。
placeholder非 select 欄位可使用的提示文字。
defaultValue新增資料時的預設值。checkbox 未設定時預設為 false，其餘為空字串。
list設為 false 時，不顯示在列表摘要；仍會出現在查看與編輯介面。

第一個 field 會作為列表主要標題。

Select

select 的 options 可使用單純字串：

{
  key: "status",
  label: "狀態",
  type: "select",
  options: ["進行中", "已完成"]
}

也可以分開設定 value 與 label：

{
  key: "status",
  label: "狀態",
  type: "select",
  options: [
    { value: "active", label: "進行中" },
    { value: "done", label: "已完成" }
  ]
}

其他 Options

設定預設說明
title空字串元件內標題。
addLabel新增新增按鈕文字。
emptyText目前沒有資料。沒有資料時的文字。
confirmDelete原生 confirm可傳入函式，自行決定刪除確認流程。函式會收到 record，可回傳 boolean 或 Promise。

系統欄位

id、createdAt、updatedAt 由元件與 Fiction Storage 管理，不需要加入 fields，也不會出現在表單中。

新增資料時，元件使用 Timestamp.create() 產生 YYYYMMDDHHmmssSSS 格式的 ID。

已 create 後

const crud = SlowlyDataCRUD.create({
  target: "#crud",
  storageKey: "my-tool-data",
  fields: [
    { key: "name", label: "名稱", type: "text" }
  ]
});

await crud.refresh();
crud.openCreate();
await crud.openView(id);
await crud.openEdit(id);
await crud.deleteRecord(id);
crud.closePanel();
crud.destroy();
方法用途
refresh()重新讀取 storage 並更新列表，回傳目前 records。
openCreate()開啟新增表單。
openView(id)開啟指定資料的查看面板。
openEdit(id)開啟指定資料的編輯表單。
deleteRecord(id)刪除指定資料，會先經過刪除確認。
closePanel()關閉目前查看／編輯／新增面板。
destroy()移除事件與元件內容。destroy 後不可再呼叫其他操作方法。

改色

Slowly Data CRUD 的 CSS 只處理基本結構、表單可用性、列表分隔與自適應。宿主不需要修改 data_crud_component.css，可直接覆寫 .slowly-data-crud 的 CSS Variables。

#crud .slowly-data-crud {
  --sdc-text: var(--text);
  --sdc-muted: var(--muted);
  --sdc-line: var(--line);
  --sdc-accent: var(--accent);
  --sdc-danger: var(--danger);
}

原則：Component 負責結構與功能，宿主頁面負責自己的視覺。Responsive 依元件自己的容器寬度處理，不依整台裝置 viewport。
