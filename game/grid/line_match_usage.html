Grid Line Match v1.0.0

通用二維格狀橫／直連線掃描核心。只找連線，不處理交換、消除、特殊物件、分數或 DOM。

載入

<script src="https://lib.stillnessbyslowly.com/game/grid/line_match.js"></script>

最小使用

const result = SlowlyGridLineMatch.find([
  [1, 1, 1, 2],
  [2, 3, 4, 5]
]);

console.log(result.groups);

物件格子

const result = SlowlyGridLineMatch.find(grid, {
  minLength: 3,

  getValue(cell) {
    return cell.color;
  },

  isBlocked(cell) {
    return cell.empty || cell.special === "bomb";
  }
});

回傳

{
  groups: [
    {
      type: "h", // 或 "v"
      len: 4,
      value: 2,
      cells: [
        { r: 1, c: 0 },
        { r: 1, c: 1 },
        { r: 1, c: 2 },
        { r: 1, c: 3 }
      ]
    }
  ]
}

Options

minLength 預設 3；getValue 決定比對值；isBlocked 決定哪些格子中斷連線；equals 可自訂值比較方式。
