自由配置插槽舞台｜使用說明

宿主以具名插槽和 CSS Grid 矩陣定義舞台布局；依容器寬度挑選布局，不把敵我角色位置或卡牌區寫死。

一、負責什麼

驗證宿主宣告的布局矩陣，將每一個插槽放入 CSS Grid 指定區域；依容器寬度選擇適用的 minWidth，支援多組布局與動態更新。

二、不負責什麼

不建立插槽、不渲染角色、不管理玩家或 Boss、不設定顏色與卡牌特效，也不代替宿主撰寫遊戲規則。

三、宿主使用 HTTPS 絕對路徑引用

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/ui/layout/slot_stage_layout.css">
<script src="https://lib.stillnessbyslowly.com/ui/layout/slot_stage_layout.js"></script>

在正式部署前，隨包提供的測試頁及 Demo 使用同資料夾的檔案驗收，不需要先上傳或依賴尚未發布的 HTTPS 網址。

四、HTML 結構

<div id="myStage">
  <section data-stage-slot="characterOne">角色 A</section>
  <section data-stage-slot="characterTwo">角色 B</section>
  <section data-stage-slot="centralContent">中央內容</section>
  <section data-stage-slot="actions">操作區</section>
</div>

五、JavaScript 使用範例

const layouts = [
  {
    name: "compact",
    minWidth: 0,
    areas: [
      ["characterOne", "characterOne"],
      ["characterTwo", "characterTwo"],
      ["centralContent", "centralContent"],
      ["actions", "actions"]
    ],
    columns: ["minmax(0, 1fr)", "minmax(0, 1fr)"]
  },
  {
    name: "wide",
    minWidth: 620,
    areas: [
      ["characterOne", "centralContent", "characterTwo"],
      ["actions", "actions", "actions"]
    ],
    columns: ["1fr", "minmax(0, 2fr)", "1fr"]
  }
];

const stage = SlowlySlotStageLayout.create("#myStage", {
  layouts
});

console.log(stage.activeLayout); // compact 或 wide
console.log(stage.getSlot("actions")); // 宿主的 DOM 元素
stage.refresh();

// 宿主可決定重新配置插槽，無須更換舞台元件。
stage.setLayouts(layouts);
stage.destroy();

六、公開 API

瀏覽器全域物件：SlowlySlotStageLayout。不要從檔案名稱猜 API。

名稱用途或回傳值
create(target, { layouts }) 傳入根元素與布局陣列；同根元素重複呼叫回傳原實例。
instance.activeLayout 目前採用的布局名稱。
instance.refresh() 依根容器 clientWidth 重新挑選布局，回傳布局名稱。
instance.getSlot(name) 取得宿主原本的具名插槽 DOM，找不到回傳 null。
instance.setLayouts(layouts) 驗證並替換布局設定，立即重新排版。
instance.destroy() 取消監聽並還原被本零件設定的 Grid inline style。

七、重要限制與宿主責任

每一組布局都必須包含所有插槽。areas 是等欄數的二維陣列；同名插槽必須形成完整矩形，空格可用 "."。必須有 minWidth: 0 的後備布局。columns 和 rows 如有提供，數量要與矩陣的欄／列相同。插槽名稱使用英文字母、底線與數字（不可數字開頭），不支援 auto／none／span 保留字。

八、驗收與展示

Demo 可以互動操作， 功能測試 在瀏覽器中列出 PASS／FAIL。 兩種頁面職責獨立，且均不屬於 JS 零件本體。
