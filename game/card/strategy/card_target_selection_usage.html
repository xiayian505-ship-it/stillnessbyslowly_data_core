候選目標選擇｜使用說明

從宿主提供的卡牌區域收集候選目標，依自訂條件篩選、查找或選取。

一、職責與界線

從宿主提供的卡牌區域收集候選目標，依自訂條件篩選、查找或選取。

宿主判斷敵我、合法性與是否允許隨機選擇；本零件不自動出牌，也不操作畫面。

二、相依與載入

無。

下方為在軍火庫 repo 對應目錄的相對路徑示例，發布後宿主再改用軍火庫 HTTPS 絕對 URL。

<script src="./card_target_selection.js"></script>

三、公開 API

全域物件：CardTargetSelection。名稱、參數與回傳結果以此頁和實際原始碼為準。

函式行為與結果
collectCandidates(cardZones, isEligibleCandidate?) 收集目標並保留 owner、zone、cardIndex 和 card。
findCandidate(eligibleCandidates, candidateSelector) 依候選名單位置或條件查找；找不到回傳 null。
pickRandomCandidate(eligibleCandidates, randomNumberGenerator?) 宿主主動要求時隨機挑選；空名單回傳 null。

四、最小使用範例

const cardZones = [
  { owner: "team-one", zone: "hand", cards: [{ id: "a" }, { id: "b" }] },
  { owner: "team-two", zone: "hand", cards: [{ id: "c" }] }
];

const eligibleCandidates = CardTargetSelection.collectCandidates(
  cardZones,
  candidate => candidate.owner === "team-two"
);
console.log(eligibleCandidates);
