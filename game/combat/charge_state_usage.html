Charge State

通用 Charge / Bonus 累積狀態核心。 只負責保存一個非負數值，並提供累積、設定、消耗與清除。

不負責角色、敵人、傷害計算、攻擊流程、回合、卡牌或 UI。

引入

<script src="./charge_state.js"></script>

基本使用

const charge = ChargeState.create();

charge.add(4);
charge.add(2);

console.log(charge.get()); // 6

const bonus = charge.consume();

console.log(bonus);        // 6
console.log(charge.get()); // 0

與 Damage Roll 組合

const charge = ChargeState.create();

charge.add(4);

const bonus = charge.consume();

const damage = DamageRoll.value(
  enemy.atkMin,
  enemy.atkMax,
  { bonus }
);

Charge State 不知道這個 bonus 最後是拿去加傷害、技能倍率、移動距離或其他用途。 實際用途由宿主決定。

部分消耗

charge.set(10);

const used = charge.consume(3);

console.log(used);         // 3
console.log(charge.get()); // 7

主要 API

  • ChargeState.create(options)：建立狀態，可傳 initial。
  • get()：取得目前值。
  • set(value)：直接設定值。
  • add(amount)：累積數值。
  • consume()：取出全部數值並歸零。
  • consume(amount)：只消耗指定數量。
  • clear()：清空並回傳清除前的值。
  • has(amount)：判斷目前值是否足夠。
  • isEmpty()：判斷是否為 0。
  • getState()：取得目前狀態。
