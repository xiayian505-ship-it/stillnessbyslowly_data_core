Slowly JSON Viewer Component v1.0.0

這版重做為 Lite CSS。

原則：
- JSON Viewer：底層結構顯示。
- Fiction Storage：儲存能力。
- Component：完成品操作介面。
- CSS 只保留必要結構，不定義完整視覺。
- 不使用 Fiction Change。
