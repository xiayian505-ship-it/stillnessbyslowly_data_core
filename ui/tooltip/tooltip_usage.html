Tooltip 使用說明

用途：只供非互動文字提示，非 Toast／Modal；鍵盤 focus、hover、手機 tap；保留既有 aria-describedby。

載入（部署後 HTTPS 絕對路徑）

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/ui/tooltip/tooltip.css">
<script src="https://lib.stillnessbyslowly.com/ui/tooltip/tooltip.js"></script>

公開 API

SlowlyTooltip.create({ trigger, tooltip, text, placement, delay_ms })

輸入／設定：trigger、tooltip 為 DOM/selector；可選 text 以 textContent 設定；placement=top/bottom；delay_ms 非負。

實例操作：show()、hide()、is_open()、destroy()

宿主接法示例

<button id="help">說明</button><span id="hint" class="slowly-tooltip" hidden>簡短文字提示</span>
<script>const hint = SlowlyTooltip.create({trigger:'#help',tooltip:'#hint',delay_ms:0}); /* hint.destroy(); */</script>

生命週期與限制

只供非互動文字提示，非 Toast／Modal；鍵盤 focus、hover、手機 tap；保留既有 aria-describedby。

新 JS 使用 IIFE 並提供 window.SlowlyTooltip；錯誤 DOM／參數會明確報錯。不同宿主負責提供 UI 樣式、文字、實際業務操作，銷毀實例時清除監聽器和計時器。

部署前新網址只是預定位置；若還沒把檔案上架，請先以 ZIP 的相同路徑部署。若在本機測試，可使用測試伺服器映射同路徑。

提醒：這批不會複製已有的 Toast、Confirm、Tabs、Custom Select 或 Loader Progress；現有零件保留原樣。
