Impact Slash｜指定位置斬擊光線

取材自《霧林之契》的瞬間斜向斬擊光線，重新抽成可自訂參數的通用視覺積木。

一、與現有軍火庫零件的差別

Sweep Line 是沿水平或垂直方向掃過一個區域；本積木是在宿主指定的位置，瞬間顯示一條帶光暈的斜向線條。

不整合攻擊、卡牌、命中判定、音效、震動、閃光或畫面晃動，也不依賴那些零件。

二、HTTPS 絕對路徑

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/effects/line/impact_slash.css">
<script src="https://lib.stillnessbyslowly.com/effects/line/impact_slash.js"></script>

宿主必須為容器設定 position: relative 或其他合適的定位方式。積木不會替宿主修改容器布局。

三、公開 API

全域名稱：SlowlyImpactSlash

函式／參數用途
play(root, options?)在指定容器播放斜線，回傳 Promise，結果包含 played、interrupted。
clear(root)清除該容器內本積木建立的動畫，回傳清除的數量。
options.target宿主提供的容器內目標元素。填入時以元素中心定位。
xPercent / yPercent沒有 target 時的百分比位置，預設 50／50。
angle光線傾斜角度（度），預設 -39。
length / thickness可傳像素數字或 CSS 長度字串。
color / glow光線核心色及周圍光暈色，使用 CSS 顏色值。
duration播放毫秒數，預設 320。
zIndex疊放層級，預設 5。
interrupt設定 true 時，先清除同容器先前的斬擊再播放；預設允許多條同時存在。
respectReducedMotion預設 true，若使用者偏好減少動態效果則略過；傳 false 可讓宿主明確覆寫 JS 略過，但 CSS 仍遵守瀏覽器減少動態偏好。

四、最小使用範例

<div id="stage" style="position: relative; min-height: 240px;">
  <div id="target">任意內容</div>
</div>

<script>
  const stage = document.getElementById("stage");
  const target = document.getElementById("target");

  // 宿主選擇目標和視覺參數。積木不處理命中或傷害。
  SlowlyImpactSlash.play(stage, {
    target: target,
    angle: -45,
    duration: 320,
    length: 130,
    thickness: 4,
    color: "rgba(245, 255, 250, 0.95)",
    glow: "rgba(90, 210, 160, 0.6)"
  });
</script>

若已經有其他震波、閃光、音效或震動零件，宿主自行決定同時或依序觸發；這支零件不替宿主組裝。
