one_way_platform_contact｜使用說明

功能：依上下幀腳底跨越與下降方向計算單向平台落地

公開 API

`SlowlyOneWayPlatformContact.inspect_landing(options)`。

依賴與載入順序

game/collision/rectangle_overlap_2d.js

<script src="https://lib.stillnessbyslowly.com/game/collision/rectangle_overlap_2d.js"></script>
<script src="https://lib.stillnessbyslowly.com/game/physics/one_way_platform_contact.js"></script>

以上是部署後的 HTTPS 絕對網址，必須先上傳新零件才會存在；依賴 JS 必須先載入。

輸入參數

`options.previous_body`、`current_body`、`platform`：`{x,y,width,height}`（畫面 y 往下為正）；`velocity_y`：速度為正表示下降；`horizontal_margin`：可選非負橫向容差。

回傳結果

`{landed,corrected_y,suggested_velocity_y,platform_top}`；成功時將宿主角色 y 修正到平台頂面，垂直速度設為零，沒有副作用。

宿主實際接法

const result = SlowlyOneWayPlatformContact.inspect_landing({
  previous_body: { x: 10, y: 10, width: 8, height: 8 },
  current_body: { x: 10, y: 20, width: 8, height: 8 },
  platform: { x: 0, y: 25, width: 30, height: 5 },
  velocity_y: 10
});
if (result.landed) console.log(result.corrected_y);

限制與錯誤

橫向區間檢查引用 `SlowlyRectangleOverlap2D`；不幫宿主移動玩家、不做重力與畫面滾動，預設向下 y 正方向。

JS 會針對非法資料或缺少依賴明確拋出錯誤；宿主應自行 try/catch 處理使用者輸入。純計算零件沒有 destroy 生命週期；Undo 使用 clear 清空歷史。外觀、聲音與動畫完全由宿主控制。
