Form Draft v1.0.0

管理表單或編輯流程中的暫存草稿， 並保留初始 snapshot 供 dirty / changed 判斷。

本模組不讀 DOM、不知道 input ID，也不處理欄位型別轉換。 宿主只把整理好的值交給 Draft。

本模組沒有 UI，因此不需要宿主載入 CSS。

引用

<script src="https://lib.stillnessbyslowly.com/state/form_draft.js"></script>

基本使用

const draft = FormDraft.create({
  name: "",
  price: "",
  tags: []
});

draft.set("name", "鍵盤");

draft.patch({
  price: 1200,
  tags: ["3C", "鍵盤"]
});

console.log(draft.get());
console.log(draft.dirty);
console.log(draft.changed("name"));

宿主同步表單

draft.patch({
  name: nameInput.value.trim(),
  price:
    priceInput.value === ""
      ? ""
      : Number(priceInput.value),
  note: noteInput.value.trim()
});

trim、Number、日期格式、tags parser 等規則仍由宿主決定， Form Draft 不推測 schema。

reset / commit

draft.set("name", "新名稱");

draft.reset();
// 回到建立 Draft 時的初始資料

draft.set("name", "確定的新名稱");
draft.commit();
// 把目前草稿設成新的基準
// dirty 重新變成 false

API

API 說明
FormDraft.create(initialData)建立草稿。
get()取得目前草稿的新物件。
getValue(key)取得單一欄位值。
set(key, value)設定單一欄位。
patch(values)合併更新多個欄位。
replace(values)整份取代目前草稿，不改初始基準。
remove(key)移除欄位。
reset()回復初始基準。
commit()把目前草稿設成新的初始基準。
snapshot()取得 initial、current、dirty 快照。
changed(key)判斷指定欄位是否相對初始基準改變。
has(key)判斷目前草稿是否存在欄位。
dirty整份草稿是否已改變。

設計邊界

  • 不操作 DOM。
  • 不綁 input / select / textarea。
  • 不自動 trim 或 Number 轉換。
  • 不處理檔案上傳與圖片 Blob。
  • 不負責 localStorage / database。
  • 不做表單驗證。
