grid_occupancy｜使用說明

功能：矩形格子的邊界、固定障礙及動態佔位檢查

公開 API

`SlowlyGridOccupancy.inspect(position, options)` 及 `can_enter(position, options)`。

依賴與載入順序

無（零件本體沒有其他軍火庫依賴）

<script src="https://lib.stillnessbyslowly.com/game/grid/grid_occupancy.js"></script>

以上是部署後的 HTTPS 絕對網址，必須先上傳新零件才會存在；依賴 JS 必須先載入。

輸入參數

`position`: 整數 `{r,c}`；`options.rows`、`options.columns`：正整數；`options.is_blocked(position)` 與 `is_occupied(position)`：可選同步布林回呼。回呼只會在合法格上執行。

回傳結果

`{in_bounds, blocked, occupied, can_enter}`；越界時三個檢查旗標為 false，`can_enter` 為 false。純查詢，不更新宿主格子。

宿主實際接法

const walls = new Set(["1:2"]);
const boxes = new Set(["2:2"]);
const options = {
  rows: 4,
  columns: 5,
  is_blocked: position => walls.has(`${position.r}:${position.c}`),
  is_occupied: position => boxes.has(`${position.r}:${position.c}`)
};
const result = SlowlyGridOccupancy.inspect({ r: 2, c: 2 }, options);
console.log(result.can_enter); // false

限制與錯誤

不處理地圖顯示、推動、狀態更改或尋路；無效整數和尺寸會拋錯。宿主可用自己的 Set、Array 或資料庫查詢 callback。

JS 會針對非法資料或缺少依賴明確拋出錯誤；宿主應自行 try/catch 處理使用者輸入。純計算零件沒有 destroy 生命週期；Undo 使用 clear 清空歷史。外觀、聲音與動畫完全由宿主控制。
