Hold Charge Control｜使用說明

按下→持續時間→放開/取消的蓄力生命週期。蓄力數值直接透過既有 ChargeState.create 管理。

檔案與載入順序

<script src="https://lib.stillnessbyslowly.com/game/combat/charge_state.js"></script>
<script src="https://lib.stillnessbyslowly.com/state/hold_charge_control.js"></script>

公開 API

window.SlowlyHoldChargeControl

  • create({duration_seconds?, minimum_progress?, maximum_progress?, on_release?}) → instance
  • instance.press() → boolean（成功開始）
  • instance.update(delta_seconds) → 狀態快照
  • instance.release() → {progress, elapsed_seconds} 或 null
  • instance.cancel() → boolean；instance.reset() → 狀態快照
  • instance.get_state() → {charging, elapsed_seconds, progress, last_release_progress}

選項、數值與輸出

  • 必須先載入 game/combat/charge_state.js。
  • duration_seconds > 0；minimum_progress、maximum_progress 介於 0..1 且後者 ≥前者。
  • update 使用秒數，由宿主每幀呼叫，不設計瀏覽器內部定時器。
  • 放開結果中的 progress 為 [minimum_progress, maximum_progress] 的線性值；on_release 只通知一次。

使用範例（請先按上列順序載入腳本）

const hold = SlowlyHoldChargeControl.create({ duration_seconds: 1.5 });
hold.press();
hold.update(0.5);
const result = hold.release();
console.log(result.progress);

錯誤、清理與限制

不含發射力量公式、控制鍵位或 UI；數值管理委託既有 ChargeState API，不重新實作累積器。

若輸入格式錯誤、非法負值或非有限數字，原則上拋出 TypeError 或 RangeError。 需保留狀態的物件可使用 reset/cancel/clear/destroy 或非同步 stop，實際方法以上列 API 為準。

這顆 JS 不附加遊戲造型、不依賴打包工具，使用獨立 IIFE ＋ window API。 本頁文中的 HTTPS 新零件網址須等使用者部署後才會可用。
