Slowly Custom File v1

自訂檔案選擇 UI 元件。隱藏瀏覽器原生 file input 的可見外觀，以自訂按鈕觸發原生檔案選擇器；原生 input 仍保留作為 files、change、accept、multiple、disabled 等真正能力來源。

定位

Custom File 只負責「選擇檔案」的 UI 與互動，不負責讀取、解析或轉換檔案內容。JSON.parse、FileReader、圖片壓縮、DataBackup 等應由宿主頁面或其他模組處理。

引用

<link rel="stylesheet" href="custom_file.css">
<script src="custom_file.js"></script>

基本 HTML

<div class="slowly-file" id="myFile">
  <input class="slowly-file-native" type="file">
  <button class="slowly-file-trigger" type="button">
    <span class="slowly-file-label">選擇檔案</span>
  </button>
</div>

尚未選擇

初始化

SlowlyCustomFile.initAll();

也可以只初始化單一元件：

SlowlyCustomFile.init("#myFile");

取得檔案

直接監聽原生 input 的 change。Custom File 不改變原生資料來源。

const input = document.querySelector("#myFile .slowly-file-native");

input.addEventListener("change", () => {
  const file = input.files?.[0];
  if(!file) return;

  console.log(file);
});

檔案類型

使用原生 accept，不需要修改 Custom File。

<!-- JSON -->
<input class="slowly-file-native" type="file"
       accept="application/json,.json">

<!-- 圖片 -->
<input class="slowly-file-native" type="file"
       accept="image/jpeg,image/png,image/webp">

<!-- JS -->
<input class="slowly-file-native" type="file"
       accept=".js,text/javascript">

<!-- 不限制 -->
<input class="slowly-file-native" type="file">

多檔案

<input class="slowly-file-native" type="file" multiple>

選擇多個檔案時，預設標籤會顯示「已選擇 N 個檔案」。真正的檔案仍由 input.files 取得。

重設

若處理完成後需要讓同一個檔案可以再次觸發 change，可主動重設：

SlowlyCustomFile.reset("#myFile");

Custom File 不會自動 reset，避免在其他 change listener 尚未處理完成前清掉原生 files。由宿主在適合的時機決定。

Theme / Color Override

元件本體使用中性預設色。宿主頁面請優先覆寫 CSS 變數，不直接修改 custom_file.css。

#backupArea .slowly-file{
  --sf-bg:var(--panel);
  --sf-text:var(--ink);
  --sf-border:var(--line);
  --sf-hover:var(--surface-soft);
  --sf-focus:var(--accent);
}

職責邊界

Custom File：原生 input 隱藏、自訂 trigger、檔名顯示、disabled 同步、初始化與 reset。

宿主／其他模組：FileReader、file.text()、JSON.parse、DataBackup、圖片壓縮、格式驗證、儲存與上傳。
