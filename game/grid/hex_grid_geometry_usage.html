hex_grid_geometry｜使用說明

功能：奇偶列水平錯位的六角格（row-offset）位置和六鄰接

公開 API

`SlowlyHexGridGeometry.cell_center(position, options)`、`neighbors(position, options)`、`in_bounds(position, options)`。

依賴與載入順序

無（零件本體沒有其他軍火庫依賴）

<script src="https://lib.stillnessbyslowly.com/game/grid/hex_grid_geometry.js"></script>

以上是部署後的 HTTPS 絕對網址，必須先上傳新零件才會存在；依賴 JS 必須先載入。

輸入參數

`options={rows,columns,radius,odd_row_offset?,origin_x?,origin_y?}`；radius 為正數；預設奇數列向右偏移一個 radius，中心原點 (radius,radius)，垂直間距 √3×radius。

回傳結果

`cell_center` 回傳 `{x,y}`；`neighbors` 回傳邊界內鄰格陣列；`in_bounds` 回傳布林。

宿主實際接法

const grid = { rows: 6, columns: 7, radius: 15 };
const center = SlowlyHexGridGeometry.cell_center({ r: 1, c: 2 }, grid);
const neighbors = SlowlyHexGridGeometry.neighbors({ r: 1, c: 2 }, grid);
console.log(center, neighbors.length);

限制與錯誤

只支援 row-offset 錯位六角格；不宣稱支持 axial 或 cube 坐標。中心越界會拒絕；不提供顏色與群組擴張。

JS 會針對非法資料或缺少依賴明確拋出錯誤；宿主應自行 try/catch 處理使用者輸入。純計算零件沒有 destroy 生命週期；Undo 使用 clear 清空歷史。外觀、聲音與動畫完全由宿主控制。
