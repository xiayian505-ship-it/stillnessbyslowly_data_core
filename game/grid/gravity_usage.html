Grid Gravity v1.0.0

通用二維格狀向下重力核心。只負責把非空格子往下壓實，並可選擇由宿主補入新格子。

載入

<script src="https://lib.stillnessbyslowly.com/game/grid/gravity.js"></script>

最小使用

SlowlyGridGravity.down(grid);

自訂空格與補格

SlowlyGridGravity.down(grid, {
  isEmpty(cell) {
    return cell.empty === true;
  },

  createCell() {
    return {
      color: randomColor(),
      empty: false
    };
  }
});

回傳

{
  grid,     // 原地修改後的同一個 grid
  moved,    // 有實際改變列位置的既有格子數
  filled    // createCell 建立的新格子數
}

格子的內容、隨機方式、特殊物件與 Render 都由宿主決定。
