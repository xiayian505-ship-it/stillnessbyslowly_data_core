Demo 功能測試

Story Event Player｜故事事件播放器

讀取單篇 JSON 事件，推進 scene、narration、dialogue、text，支援同篇 choice.goto 跳轉；challenge 暫停等待宿主。

一、載入方式

本地開發測試：

<script src="./story_event_player.js"></script>

正式部署在你的軍火庫後，其他宿主可以採絕對網址：

https://lib.stillnessbyslowly.com/state/story_event_player.js

注意：本 ZIP 尚未部署，上列 HTTPS 網址為預計發布路徑，不代表目前已上線。

二、公開 API

全域物件：SlowlyStoryEventPlayer；版本 1.0.0。錯誤輸入通常丟出 TypeError／RangeError／Error，應由宿主捕捉。

函式用途與輸入輸出
create()建立獨立實例
load(events)驗證並載入新事件陣列；空陣列可載入
start()進入第一事件；空資料立即完成
current()目前事件的副本或 null
advance()一般事件推進；choice / challenge 保持等待
choose(optionIndex)choice 選項，goto 僅限同篇已存在的 ID
completeHost()宿主完成 challenge 後再往下
seekByIndex(index)依索引定位；越界丟 RangeError
seekById(id)依字串 ID 定位；不存在丟 RangeError
snapshot() / reset()取得快照／重設為 idle
subscribe(callback)監聽狀態更新，回傳取消訂閱函式

三、最小使用範例

const player = SlowlyStoryEventPlayer.create();
player.load([
  { id: "intro", type: "narration", text: "序章開始。" },
  { id: "question", type: "choice", options: [
    { text: "重新開始", goto: "intro" },
    { text: "繼續" }
  ] },
  { type: "challenge" }
]);
player.start();
player.advance();
player.choose(1);
// challenge 由宿主處理成功後，再呼叫 player.completeHost();

四、相依及宿主責任

核心獨立運作，沒有強制依賴任何其他軍火庫零件。這不代表要重做既有能力：宿主仍應使用適當的軍火庫零件處理逐字效果、導航、牌組合法性、卡牌升級與儲存等工作。

僅單篇事件、不跨篇導航、無條件式劇情、不記錄選項歷史；未知事件類型拒絕。文字繪製、逐字動畫和外部戰鬥由宿主負責。
