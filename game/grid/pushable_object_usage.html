pushable_object｜使用說明

功能：單一可推動佔位物件的下一格推動方案

公開 API

`SlowlyPushableObject.plan_push(options)`。

依賴與載入順序

game/grid/grid_occupancy.js

<script src="https://lib.stillnessbyslowly.com/game/grid/grid_occupancy.js"></script>
<script src="https://lib.stillnessbyslowly.com/game/grid/pushable_object.js"></script>

以上是部署後的 HTTPS 絕對網址，必須先上傳新零件才會存在；依賴 JS 必須先載入。

輸入參數

`options.position={r,c}`：目前被推物體所在格；`options.direction={r,c}`：恰好一步的上下左右向量；`options.occupancy_options`：原樣交給 `SlowlyGridOccupancy.inspect` 的完整尺寸與 callback。

回傳結果

`{allowed,from,to,reason}`；拒絕原因含 `source_not_occupied`、`source_blocked`、`destination_occupied`、`destination_blocked`、`destination_out_of_bounds`。完全不修改物件集合。

宿主實際接法

const boxes = new Set(["2:2"]);
const occupancy_options = {
  rows: 5, columns: 5,
  is_blocked: position => position.r === 1 && position.c === 3,
  is_occupied: position => boxes.has(`${position.r}:${position.c}`)
};
const plan = SlowlyPushableObject.plan_push({
  position: { r: 2, c: 2 },
  direction: { r: 0, c: 1 },
  occupancy_options
});
if (plan.allowed) {
  boxes.delete(`${plan.from.r}:${plan.from.c}`);
  boxes.add(`${plan.to.r}:${plan.to.c}`);
}

限制與錯誤

只推一件、一格；不移動玩家、不提交箱子狀態、不做求解器。依賴 `SlowlyGridOccupancy.inspect`，缺少即報錯。

JS 會針對非法資料或缺少依賴明確拋出錯誤；宿主應自行 try/catch 處理使用者輸入。純計算零件沒有 destroy 生命週期；Undo 使用 clear 清空歷史。外觀、聲音與動畫完全由宿主控制。
