路徑：component/text_generator/text_generator_vertical_component.js。

只負責由上而下的建議字位，以及串接共通核心。字體、顏色、尺寸、裝飾與整張 SVG 均由宿主控制。直式完成品不需要載入另一種排列完成品。

Blob URL 零件可省略。生成／預覽 SVG 不依賴 PNG 零件；輸出 PNG 需要 Canvas PNG，直接下載還需要 PNG Download。

最小宿主範例

const art = SlowlyVerticalTextGenerator.create({
  maxChars: 4,
  sourceSize: { width: 720, height: 1100 },
  renderSVG(text, helpers, layout) {
    const glyphs = helpers.splitCharacters(text).map((char, index) => {
      const slot = layout.slots[index];
      return `<text x="${slot.x}" y="${slot.y}" text-anchor="middle" dominant-baseline="middle">${helpers.escapeXML(char)}</text>`;
    }).join("");
    return `<svg xmlns="http://www.w3.org/2000/svg" width="720" height="1100" viewBox="0 0 720 1100">${glyphs}</svg>`;
  },
  presets: {
    png: { scale: 2 },
    cover: { width: 700, height: 1000, fit: "contain", paddingX: 48, paddingY: 54 }
  }
});

art.generateSVG("穿林打葉");
await art.downloadPNG("穿林打葉", "png");
await art.downloadCover("穿林打葉");

設定與回傳

選項說明
maxChars宿主決定的字數上限，預設 4；採 Unicode 字素而非 UTF-16 單位
sourceSize{width,height} 或 (text) => {width,height}，須與 SVG viewBox 一致
renderSVG(text, helpers, layout)宿主提供完整 SVG 字串；helpers 含 XML 安全跳脫與字素切分等函式
getPositions(text, size)可選，回傳每字一個 {x,y} 物件的陣列，覆蓋預設字位
presets可選，PNG 倍率或固定輸出尺寸；留白與 contain 由宿主控制
filenames可選，自訂 SVG／PNG／cover 檔名

layout 物件

{
  orientation: "vertical",
  sourceSize: { width: 720, height: 1100 },
  slots: [{ index: 0, x: 100, y: 100 }, ...]
}

單字置中；多字由上而下均勻排列。這只是字位參考，不會替宿主畫文字，也不強制套色或字型。

輸出 API

art.normalize(text);
art.layout(text);
art.generateSVG(text);
art.sourceSize(text);
art.createPreview(imageElement); // set(text), clear(), destroy()
art.svgBlob(text);
art.formatSize(text, "png");
art.formatSize(text, "cover");
await art.pngBlob(text, "png");
art.downloadSVG(text);
await art.downloadPNG(text, "png");
await art.downloadCover(text);

背景預設透明；如果宿主 SVG 本身包含底圖，核心不會擅自移除。fit: "fill" 可用，但會拉伸，不建議用於書封；通常應選 contain。
