CSV Parse / Stringify 使用說明

用途

CSV Parse / Stringify 是通用 CSV 資料轉換核心， 處理 CSV 文字與 JavaScript 二維陣列／物件陣列之間的轉換。

支援 BOM、引號、欄位內逗號、欄位內換行與雙引號跳脫。

載入

<script src="csv_parse_stringify.js"></script>

CSV → 二維陣列

const rows = SlowlyCSV.parse(csvText);

CSV → 物件陣列

const data = SlowlyCSV.parse(csvText, {
  header: true
});

第一列會作為欄位名稱。

自訂分隔符

const rows = SlowlyCSV.parse(text, {
  delimiter: ";"
});

略過空白列

const rows = SlowlyCSV.parse(text, {
  skipEmptyLines: true
});

Safe Parse

const result = SlowlyCSV.parse(text, {
  safe: true
});

if (result.ok) {
  console.log(result.value);
} else {
  console.error(result.error);
}

二維陣列 → CSV

const text = SlowlyCSV.stringify([
  ["name", "age"],
  ["Slowly", 20]
]);

物件陣列 → CSV

const text = SlowlyCSV.stringify(
  [
    { name: "Slowly", age: 20 },
    { name: "Test", age: 30 }
  ],
  {
    header: true
  }
);

若未指定 headers，會依物件中出現的 key 建立欄位。

指定欄位順序

const text = SlowlyCSV.stringify(data, {
  header: true,
  headers: ["id", "name", "age"]
});

輸出 BOM

const text = SlowlyCSV.stringify(data, {
  header: true,
  bom: true
});

可用於部分試算表軟體需要 BOM 才能正確辨識 UTF-8 的情境。

責任邊界

這組不處理：

  • File / Blob 讀取。
  • 檔案下載。
  • Excel XLS/XLSX。
  • 資料型態自動推論。
  • Schema 驗證。
  • DOM 預覽與表格 UI。
  • localStorage 或後端儲存。

組合方式

Custom File
    ↓
File Reader.text()
    ↓
SlowlyCSV.parse()
    ↓
Data Validation / Data Diff / Data CRUD

反向則可：

JavaScript Data
    ↓
SlowlyCSV.stringify()
    ↓
Blob / Download 積木
