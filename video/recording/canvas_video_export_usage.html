公開 API：window.SlowlyCanvasVideoExport

const supported = SlowlyCanvasVideoExport.get_supported_formats();
const session = SlowlyCanvasVideoExport.create({
    canvas: document.querySelector("#drawing_canvas"),
    duration_seconds: 3,
    frames_per_second: 20,
    format: "webm",  // 支援 MP4 時可改成 "mp4"
    video_bits_per_second: 3500000,
    async draw_frame({ canvas, context, elapsed_seconds, frame_index }) {
        context.clearRect(0, 0, canvas.width, canvas.height);
        context.fillRect(Math.floor(elapsed_seconds * 40), 20, 30, 30);
    },
    on_progress(ratio) { console.log(ratio); },
    signal: abort_controller.signal
});
const result = await session.start();
// result: { blob, mime_type, format, width, height, duration_seconds }
// session.stop() 可提前完成輸出；session.cancel() 中止且 reject。

參數、回傳值與限制

get_supported_formats() 回傳 {webm: mime_or_null, mp4: mime_or_null}；內容直接來自 SlowlyVideoRecorderMime.choose()。

create({canvas,draw_frame,duration_seconds,frames_per_second,format,video_bits_per_second,on_progress,signal}) 建立單次錄製實例。

start() 開始真實時間錄製，完成後回傳影片 Blob 與格式資訊；只能呼叫一次。

stop() 提前結束並輸出已錄製內容；cancel() / signal.abort() 取消並拒絕 Promise。

state 可查詢 idle、recording、finished、failed 或 cancelled；mime_type 是原生錄製格式。

錄製需要 Canvas.captureStream 與 MediaRecorder；WebM / MP4 是否可輸出取決於瀏覽器實際支援，絕不自動轉碼。

使用既有軍火庫三顆錄影零件，不重寫 MIME / Recorder / Chunks；宿主處理下載、保存與 CSS。
