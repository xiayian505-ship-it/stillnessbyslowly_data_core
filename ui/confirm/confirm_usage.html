Slowly Confirm

通用確認視窗。只負責詢問並回傳確認結果， 不負責刪除、儲存、導航或其他宿主業務規則。

載入

<link
  rel="stylesheet"
  href="https://lib.stillnessbyslowly.com/ui/confirm/confirm.css"
>

<script
  defer
  src="https://lib.stillnessbyslowly.com/ui/confirm/confirm.js"
></script>

基本使用

const ok = await SlowlyConfirm.show({
  title: "刪除這封信？",
  message: "刪除後無法復原。",
  confirmText: "刪除",
  cancelText: "取消"
});

if (ok) {
  // 宿主自行執行刪除
}

Options

{
  title: "請確認",
  message: "",
  confirmText: "確認",
  cancelText: "取消",
  className: "",
  closeOnBackdrop: true,
  closeOnEscape: true,
  initialFocus: "cancel" // "cancel" | "confirm"
}

其他 API

SlowlyConfirm.confirm();
SlowlyConfirm.cancel();
SlowlyConfirm.close(false);

SlowlyConfirm.isOpen();
SlowlyConfirm.pendingCount();

SlowlyConfirm.destroy();

設計原則

Slowly Confirm 不知道「確認」代表什麼。 宿主可以拿它確認刪除、覆蓋、離開、送出或任何其他行為。
