Custom Select

用自訂 HTML 介面取代原生 select 的可見選單， 但保留原本的 select 作為真正的 value / change 資料來源。

引用

<link rel="stylesheet"
  href="https://lib.stillnessbyslowly.com/ui/custom_select.css">

<script
  src="https://lib.stillnessbyslowly.com/ui/custom_select.js"></script>

HTML

<select id="mySelect">
  <option value="TWD">TWD</option>
  <option value="JPY">JPY</option>
  <option value="USD">USD</option>
</select>

初始化

const mySelect = SlowlySelect.create("#mySelect");

使用者切換 Custom Select 時， 原本的 select.value 會同步更新， 並正常觸發原生 change 事件。

原本的 change 可直接沿用

document.querySelector("#mySelect")
  .addEventListener("change", (e)=>{
    console.log(e.target.value);
  });

程式修改 value

const el = document.querySelector("#mySelect");

el.value = "USD";
mySelect.sync();

API

mySelect.sync();
mySelect.open();
mySelect.close();
mySelect.destroy();

同頁多顆

SlowlySelect.create("#selectA");
SlowlySelect.create("#selectB");
SlowlySelect.create("#selectC");

每一顆都獨立管理自己的 options，不共用 option 範圍。

批次初始化

<select data-slowly-select>...</select>
<select data-slowly-select>...</select>

<script>
  SlowlySelect.createAll();
</script>

改色

不要修改 custom_select.css。 在宿主頁面覆寫 .slowly-select 的 --ss-* 變數即可。 

#currencyArea .slowly-select{
  --ss-bg:var(--panel);
  --ss-text:var(--ink);
  --ss-border:var(--line);
  --ss-hover:var(--surface-soft);
  --ss-selected-bg:var(--accent-soft);
  --ss-selected-text:var(--accent);
  --ss-focus:var(--accent);
}
