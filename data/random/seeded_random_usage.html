Seeded Random｜可播種亂數

路徑：data/random/seeded_random.js；公開名稱：window.SlowlySeededRandom；版本：1.0.0。

它讓「同一個 seed ＋同樣的 API 呼叫順序」產生同一串偽隨機數，並且支援保存與恢復亂數狀態。每次 create(seed) 都是獨立實例。

注意：此元件不是密碼學安全亂數，不可用於密碼、Session Token、安全驗證碼、保證唯一 ID。也不會自動幫整款遊戲保存玩家操作或回放。

1. 載入方式

正式部署後，以軍火庫公開 HTTPS 絕對路徑引用（上傳前新路徑尚未上線）：

<script src="https://lib.stillnessbyslowly.com/data/random/seeded_random.js"></script>

核心只使用原生 JavaScript 的 TextEncoder、Math.imul 等能力，不需要載入舊 random.js，也不改寫 Math.random。

2. 完整 API

方法輸入回傳說明
SlowlySeededRandom.create(seed)字串或安全整數 number，必填獨立實例沒有預設 seed，不讀時鐘或系統亂數。
float(min=0, max=1)有限的數值，且 max ≥ min，跨度有限number原始亂數均落在 [0,1)；外推至指定範圍後，IEEE-754 捨入可能剛好等於 max。
int(min, max)安全整數，上下界皆包含；區間數量 1～2³²number無偏拒絕採樣；區間超過 2³² 明確拒絕。
chance(probability=0.5)0～1 的有限數值boolean機率判斷。
get_state()無新的 JSON 可序列化快照物件記錄演算法、種子、目前狀態、原始抽樣次數。
set_state(snapshot)同 seed、同演算法及版本的完整有效快照恢復後的新快照在所有欄位驗證完成後才恢復；拒絕損毀或不同種子快照。
reset()無重置後的新快照回到建立時的種子，抽樣次數歸零。

3. 基本使用與中途接續

const generator = SlowlySeededRandom.create("EMPIRE_001");

const result_a = generator.int(1, 100);
const result_b = generator.float();
const saved_state = generator.get_state();
const result_c = generator.chance(0.5);

// 恢復到 result_c 抽樣前。
generator.set_state(JSON.parse(JSON.stringify(saved_state)));
const repeated_c = generator.chance(0.5);
console.log(result_c === repeated_c); // true

generator.reset();
console.log(generator.int(1, 100) === result_a); // true

相同的 seed 搭配相同版本與相同方法呼叫順序，才會取得相同序列。兩個實例互不干擾。float／int／chance 都不依賴 this，能直接傳給其他零件作為 callback。

4. 種子與抽樣規則

  • 字串接受 ""、中文、空白及特殊字元；不 trim、不轉大小寫、不做 Unicode 正規化。
  • 數字接受正、負安全整數及 0；0 與 "0" 是不同 seed；數值 -0 等同 0。
  • null、undefined、布林、物件、陣列、浮點數、NaN 和 Infinity 均拒絕。
  • 同一種子有穩定序列，但不同 seed 理論上可能碰撞，也可能產生相同的有限次抽樣結果。
  • float(x,x)、int(x,x)、chance(0)、chance(1) 不消耗原始亂數；非法參數也不消耗。
  • 其他有效抽樣會前進序列。int 使用無偏拒絕採樣，一次呼叫可能消耗多個 32-bit 數字。draw_count 記錄的是原始抽樣總數，而非方法呼叫次數。
  • 有效參數不保證不會碰到瀏覽器的極端數字精度邊界；需要跨版本回放時，請固定輸入與程式版本。

5. 演算法版本與快照

版本 1.0.0 使用 UTF-8 種子（先加型別前綴 s:／n:）→ FNV-1a 32-bit → Mulberry32。對外演算法標記 mulberry32、algorithm_version: 1。不同版本不可擅自沿用狀態。

例如，在 seed "EMPIRE_001" 的實例消耗五筆原始 32-bit 抽樣後：

{
  "algorithm": "mulberry32",
  "algorithm_version": 1,
  "seed_type": "string",
  "seed_value": "EMPIRE_001",
  "state_uint32": 1313967721,
  "draw_count": 5
}

允許 JSON 字串化再還原；不能拿不同原始種子、版本、或與抽樣次數不一致的狀態強行恢復。同樣種子的新實例可以使用該快照。

固定測資："EMPIRE_001" 前三筆原始 unsigned 整數為 2503744885、1837685430、1854699735，可透過 float() * 4294967296 驗證。

6. 與既有軍火庫積木接線：Solvable Pair Layout

只需載入兩支公開 JS，**不需要修改**既有生成器：

<script src="https://lib.stillnessbyslowly.com/data/random/seeded_random.js"></script>
<script src="https://lib.stillnessbyslowly.com/game/grid/solvable_pair_layout.js"></script>
<script>
  function make_board(seed) {
    const seeded = SlowlySeededRandom.create(seed);
    return SlowlySolvablePairLayout.generate({
      rows: 4,
      columns: 6,
      types: ["A", "B", "C"],
      random_int: seeded.int
    });
  }
  console.log(JSON.stringify(make_board("BOARD_001")) ===
              JSON.stringify(make_board("BOARD_001"))); // true
</script>

7. 其他現成接入口

掃雷（Minefield Rules）

<script src="https://lib.stillnessbyslowly.com/game/grid/minefield_rules.js"></script>
<script>
  const seeded = SlowlySeededRandom.create("MINES_001");
  const board = SlowlyMinefieldRules.create_board({
    rows: 8,
    columns: 8,
    mines: 10,
    first_position: { r: 0, c: 0 },
    random_int: seeded.int
  });
</script>

此示例只建立同種子的布雷結果；掃雷的點擊與勝負仍由宿主處理。

節奏譜面（Rhythm Chart Generator）

<script src="https://lib.stillnessbyslowly.com/audio/tempo/beat_time.js"></script>
<script src="https://lib.stillnessbyslowly.com/game/rhythm/rhythm_chart_generator.js"></script>
<script>
  const seeded = SlowlySeededRandom.create("SONG_001");
  const chart = SlowlyRhythmChartGenerator.generate({
    duration_ms: 12000,
    bpm: 120,
    lanes: 4,
    random_int: seeded.int
  });
</script>

節奏譜面另外需要既有 BeatTime 的節拍換算 API；請依該零件的 Usage 核對載入路徑。

音訊 Noise

<script src="https://lib.stillnessbyslowly.com/audio/source/noise.js"></script>
<script>
  const seeded = SlowlySeededRandom.create("RAIN_001");
  const buffer = SlowlyAudioNoise.createBuffer(audio_context, {
    random: () => seeded.float()
  });
</script>

音訊比較要固定取樣率、時長與選項；真實 Noise 的 createBuffer options 請以該元件公開 API 為準。Random ID 預設採用 crypto.randomUUID()，不適合直接拿來示範穩定 ID。

8. 錯誤、安全與不負責範圍

輸入型別錯誤會拋 TypeError；超出合法區間、快照種子／版本不相容、狀態不一致會拋 RangeError。例外發生前不會消耗任何原始亂數。

不負責：完整遊戲回放、遊戲規則改版相容、玩家操作事件、影片畫面、密碼學安全、帳號驗證、全域亂數替換、Worker 排程、DOM 與計時器。需要可重現遊戲，宿主還需固定初始化選項、外部狀態及操作順序。
