Weather Ambience｜程序化風雨環境音

由 Noise、Oscillator、Filter、Gain 組成風雨環境音，不用音檔；AudioContext 由宿主提供。

載入方式

將以下 URL 作為 script src，並按需要先載入既有依賴：

https://lib.stillnessbyslowly.com/audio/effects/weather_ambience.js

本 ZIP 是待合併更新包，URL 代表部署後的預定位置，並非已確認在線。

公開全域 API

SlowlyWeatherAmbience｜1.0.0

方法說明
create(options)必須提供 context；可指定 destination、rainVolume、windVolume、masterVolume、fadeIn、fadeOut 及風雨濾波配方。
start()Promise<boolean>。需要使用者手勢；resume 失敗會拋錯。
stop()Promise<boolean>；淡出後停止音源（若被新 start 中斷，回傳 false）。
setVolume(value)調整主音量，0～1。
setRainVolume(value)調整雨聲音量，0～1。
setWindVolume(value)調整風聲音量，0～1。
getState()回傳當前狀態及音源數；0 表示已釋放。
destroy()停止並釋放本實例節點；絕不關閉宿主 AudioContext。

最小使用範例

const context = SlowlyAudioContext.create();
const weather = SlowlyWeatherAmbience.create({ context });
await weather.start(); // 使用者點擊事件內
await weather.stop();
weather.destroy(); // 不關閉共用 Context

依賴、限制、宿主責任

需要 AudioContext、Noise、Oscillator、BiquadFilter、Gain 五個既有零件。start() 受瀏覽器使用者手勢限制，resume 失敗會拋錯；stop() 等待淡出、停止音源，短時間內新 start() 會中斷舊停止流程（舊 stop Promise 回傳 false）。不會關閉宿主的 AudioContext。音色需透過 Demo 人工試聽。
