GIF Encoder｜使用說明

慢慢軍火庫獨立零件。由宿主決定輸入、操作、外觀和結果如何使用。零件不建立網站 UI。

載入順序


<script src="https://lib.stillnessbyslowly.com/Image/gif/gif_encoder.js"></script>

公開 API：window.SlowlyGIFEncoder

const frame_pixels = context.getImageData(0, 0, width, height).data;
const gif_blob = await SlowlyGIFEncoder.encode({
    frames: [new Uint8ClampedArray(frame_pixels)],
    width,
    height,
    fps: 10,
    transparent: true,
    onProgress(ratio) { console.log(ratio); }
});
// gif_blob 是 Blob；預覽 / 下載交由宿主決定。

參數、回傳值與限制

encode({frames,width,height,fps,transparent,onProgress}) 回傳 Promise<Blob>，Blob.type = image/gif。

frames 必須是非空 Uint8ClampedArray[]，每幀 length 必須等於 width * height * 4。

width/height 是 1～65535 的整數，fps > 0 且 <= 100（GIF 延遲單位 1/100 秒）。

transparent 預設 false；alpha 小於 128 會對應透明色索引。GIF 無法完整保留半透明邊緣。

調色盤最高 256 色，所有影格共用調色盤；不保證無損還原色彩。

此模組不解析 SVG、不建立 Canvas、不下載檔案，也不做視覺外觀。
