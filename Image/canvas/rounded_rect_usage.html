Canvas Rounded Rect

建立 Canvas 2D 圓角矩形 path，不自動 fill 或 stroke。

載入

<script src="https://lib.stillnessbyslowly.com/Image/canvas/rounded_rect.js"></script>

使用

SlowlyCanvasRoundedRect.createPath(ctx, 24, 24, 300, 180, 28);
ctx.fillStyle = "#edf5f6";
ctx.fill();

API

SlowlyCanvasRoundedRect.createPath(ctx, x, y, width, height, radius)
