Slowly Calendar Component

完整可呼叫萬年曆元件。預設 1 個月，農曆、節慶、節氣全開。

載入

<link rel="stylesheet" href="calendar_component.css">

<script src="https://lib.stillnessbyslowly.com/calendar/lunar_data.js"></script>
<script src="https://lib.stillnessbyslowly.com/calendar/lunar.js"></script>
<script src="https://lib.stillnessbyslowly.com/calendar/lunar_festivals_data.js"></script>
<script src="https://lib.stillnessbyslowly.com/calendar/lunar_festivals.js"></script>
<script src="https://lib.stillnessbyslowly.com/calendar/solar_festivals_data.js"></script>
<script src="https://lib.stillnessbyslowly.com/calendar/solar_festivals.js"></script>
<script src="https://lib.stillnessbyslowly.com/calendar/solar_terms_data.js"></script>
<script src="https://lib.stillnessbyslowly.com/calendar/solar_terms.js"></script>
<script src="https://lib.stillnessbyslowly.com/calendar/calendar.js"></script>

<script src="calendar_component.js"></script>

最簡單呼叫

<div id="calendar"></div>
<script>
  SlowlyCalendar.mount("#calendar");
</script>

顯示範圍

SlowlyCalendar.mount("#calendar", {
  view: "month" // month / 3weeks / 2weeks / week
});

Options

SlowlyCalendar.mount("#calendar", {
  view: "2weeks",
  gridLines: true,
  showLunar: true,
  showFestivals: true,
  showSolarTerms: true,
  bold: {
    solarDate: false,
    weekend: true,
    lunar: false,
    festival: true,
    solarTerm: false
  }
});

已 mount 後

const calendar = SlowlyCalendar.mount("#calendar");
calendar.setView("week");
calendar.goToday();
calendar.setDate("2026-09-08");
calendar.update({ gridLines: true });

改色

Slowly Calendar 預設使用中性色。嵌入既有網站時，不需要修改 calendar_component.css；請在使用端覆寫 .slowly-calendar 的 CSS Variables。

如果宿主網站已經有自己的色票，優先直接對應既有變數：

#calendar .slowly-calendar {
  --sc-bg: var(--panel);
  --sc-text: var(--ink);
  --sc-muted: var(--muted);
  --sc-soft: var(--surface-soft);

  --sc-weekend: var(--accent);
  --sc-lunar: var(--muted);
  --sc-festival: var(--accent);
  --sc-solar-term: var(--accent-secondary);

  --sc-grid-line: var(--line);
  --sc-selected-bg: var(--selected-bg);
  --sc-selected-text: var(--ink);
  --sc-selected-border: var(--accent);
  --sc-today-ring: var(--accent);
}

也可以直接填入色碼：

#calendar .slowly-calendar {
  --sc-bg: #fff;
  --sc-text: #222;
  --sc-muted: #777;
  --sc-soft: #f6f6f6;
  --sc-weekend: #b84d4d;
  --sc-lunar: #777;
  --sc-festival: #a34f4f;
  --sc-solar-term: #4f6f7a;
  --sc-grid-line: #ddd;
  --sc-selected-bg: #eee;
  --sc-selected-text: #111;
  --sc-selected-border: #aaa;
  --sc-today-ring: #777;
}

原則：Calendar Component 負責結構與功能，宿主頁面負責自己的視覺風格。 優先覆寫變數，不直接修改 Component CSS。

Responsive 依元件自己的容器寬度，不依整台裝置 viewport。
