Slowly Tax Calculator Component

純前端含稅金額拆分元件。輸入含稅金額與稅率後， 自動顯示營業額與稅額。預設稅率為 5%，可由宿主修改。

核心採用「未稅金額＝含稅金額 ÷（1＋稅率）」的單一百分比稅率模型， 不代表所有國家、地區或稅制皆適用。

載入

<link rel="stylesheet"
  href="https://lib.stillnessbyslowly.com/ui/responsive.css">

<link rel="stylesheet"
  href="https://lib.stillnessbyslowly.com/component/data/tax_calculator_component.css">

<script src="https://lib.stillnessbyslowly.com/data/Tax.js"></script>
<script src="https://lib.stillnessbyslowly.com/component/data/tax_calculator_component.js"></script>

最簡單呼叫

<div id="tax-calculator"></div>

<script>
  const calculator = SlowlyTaxCalculator.create({
    target: "#tax-calculator",
    defaultRate: 5
  });
</script>

Options

設定預設說明
target無必要。selector 或 HTMLElement。
title含稅金額計算元件標題。傳空字串可隱藏。
defaultRate5預設稅率百分比，例如 5 代表 5%。
amountLabel金額（含稅）金額欄位文字。
rateLabel稅率稅率欄位文字。
salesLabel營業額未稅金額顯示文字。
taxLabel稅額稅額顯示文字。
localezh-TW結果數字格式使用的 locale。

核心直接呼叫

const result = SlowlyTax.splitInclusive(2900, 5);

// {
//   total: 2900,
//   rate: 5,
//   sales: 2762,
//   tax: 138
// }

已 create 後

calculator.calculate();
calculator.getValue();
calculator.setAmount(2900);
calculator.setRate(5);
calculator.focus();
calculator.destroy();

事件

每次成功重算後，元件會發出 slowlytaxchange。

document
  .querySelector("#tax-calculator")
  .addEventListener("slowlytaxchange", (event) => {
    console.log(event.detail);
  });

改色

Component 只負責結構與基本可用性，宿主頁面可覆寫 CSS Variables。

#tax-calculator .slowly-tax-calculator {
  --stc-text: var(--text);
  --stc-muted: var(--muted);
  --stc-line: var(--line);
  --stc-surface: var(--surface);
}
