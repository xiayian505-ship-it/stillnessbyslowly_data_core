Blob URL

將 Blob / File 建立為瀏覽器暫時 Object URL，並在使用完畢後回收。

載入

<script src="https://lib.stillnessbyslowly.com/data/blob/blob_url.js"></script>

建立 URL

const url = SlowlyBlobURL.create(blob);

回收 URL

SlowlyBlobURL.revoke(url);

搭配 Canvas PNG

const blob = await SlowlyCanvasPNG.toBlob(canvas);
const url = SlowlyBlobURL.create(blob);

previewImage.src = url;

// 確定不再使用後
SlowlyBlobURL.revoke(url);

API

SlowlyBlobURL.version
SlowlyBlobURL.create(blob)
SlowlyBlobURL.revoke(url)

不負責建立 Blob，也不負責預覽、下載或儲存。
