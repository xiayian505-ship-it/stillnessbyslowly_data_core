Damage Roll

通用整數擲值核心。依指定 min / max 產生包含上下限的隨機整數， 並可額外加入 bonus。

只負責「數值怎麼擲出來」，不管理角色、HP、護盾、Charge、回合、卡牌或 UI。

引入

<script src="./damage_roll.js"></script>

取得完整結果

const result = DamageRoll.roll(3, 6, {
  bonus: 4
});

console.log(result);
// {
//   base: 3 ~ 6,
//   bonus: 4,
//   total: base + 4,
//   min: 3,
//   max: 6
// }

只取得最後數值

const damage = DamageRoll.value(3, 6, {
  bonus: 4
});

宿主自行決定 bonus 是什麼

const charge = 4;

const damage = DamageRoll.value(
  enemy.atkMin,
  enemy.atkMax,
  { bonus: charge }
);

// 是否消耗 charge，由宿主自己處理。
charge = 0;

可注入 rng

測試或需要固定結果時，可自行傳入回傳 0～1 數值的函式。 

const result = DamageRoll.roll(3, 6, {
  rng: () => 0,
  bonus: 2
});

// base = 3
// total = 5

主要 API

  • DamageRoll.roll(min, max, options)：回傳 base、bonus、total 與正規化後的範圍。
  • DamageRoll.value(min, max, options)：只回傳最後 total。
  • DamageRoll.normalizeRange(min, max)：整理整數範圍；min 大於 max 時會自動交換。
