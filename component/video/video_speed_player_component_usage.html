Slowly Video Speed Player｜使用說明

完成品採 mount 指定容器，自動建立原生影片、檔案選取、倍速按鈕與匯出 UI。所有必要積木從軍火庫 HTTPS 絕對路徑引用。

外觀與換皮

完成品 CSS 預設使用 Slowly Piano 展示頁完全相同的粉紅色碼；並非連動載入 Piano。宿主只需在 CSS 中覆寫容器的 --svsp-* 變數即可換皮（參見 README）。

API

const player = SlowlyVideoSpeedPlayer.mount(container, options);
await player.loadFile(file);
player.setSpeed(1.5);
await player.startExport();
await player.stopExport();
player.reset();
player.destroy();
player.elements.video; // 原生 video，可直接控制

匯出並非手機系統螢幕錄影：使用 captureStream + MediaRecorder 在頁面本機重新錄製，會花實際播放時間。請保持前景，螢幕不要鎖定；播放和錄製能力取決於瀏覽器。

個人歷史紀錄：原版影片播放器在 Samsung Galaxy S25 Ultra（S25U）與 Galaxy Note20 Ultra（N20U）可使用；新版完成品尚待實機驗證。
