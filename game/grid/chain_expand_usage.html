Slowly Grid Chain Expand v1.0.0

通用二維格子連鎖擴散核心。宿主提供起始座標與 expandAt()，元件只負責去重、分波擴散與停止條件。

載入

<script src="https://lib.stillnessbyslowly.com/game/grid/chain_expand.js"></script>

基本使用

const result = SlowlyGridChainExpand.expand(grid, [
  { r: 2, c: 2 }
], {
  maxWaves: 12,

  expandAt({ r, c, cell, rows, cols }) {
    if (!cell?.active) return [];

    return [
      { r: r - 1, c },
      { r: r + 1, c },
      { r, c: c - 1 },
      { r, c: c + 1 }
    ];
  }
});

console.log(result.positions);
console.log(result.waves);
console.log(result.exhausted);

邊界

expandAt() 可以回傳超出 grid 的座標；元件會自動忽略。重複座標只保留第一次加入。
