Tree Selection v1.0.0

管理樹狀介面常見的「選取」與「展開」狀態。 模組不碰 DOM，也不要求特定 tree schema。

本模組沒有 UI，因此不需要宿主載入 CSS。

引用

<script src="https://lib.stillnessbyslowly.com/state/tree_selection.js"></script>

基本使用

const tree = TreeSelection.create();

tree.select("keyboard/mechanical");
tree.toggle("keyboard/folding");

tree.expand("digital");
tree.toggleExpanded("games");

console.log(tree.getSelected());
console.log(tree.getExpanded());

單一展開

const tree = TreeSelection.create({
  expansion: "single"
});

tree.expand("digital");
tree.expand("games");

// 只保留 games
console.log(tree.getExpanded());

帶入既有狀態

const tree = TreeSelection.create({
  selected: ["A", "B"],
  expanded: ["group-1", "group-2"],
  expansion: "multiple"
});

API

API 說明
select(value)加入選取。
unselect(value)移除選取。
toggle(value)切換選取狀態，回傳切換後是否選取。
has(value)查詢是否選取。
clearSelection()清除全部選取並回傳清除數量。
replaceSelected(values)整批取代選取值。
getSelected()取得選取值的新陣列。
expand(value)展開指定 key。
collapse(value)收合指定 key。
toggleExpanded(value)切換展開狀態。
isExpanded(value)查詢是否展開。
collapseAll()全部收合並回傳收合數量。
replaceExpanded(values)整批取代展開 key。
getExpanded()取得展開 key 的新陣列。
selectedCount目前選取數量。
expandedCount目前展開數量。

設計邊界

  • 不建立分類樹。
  • 不解析 parent / child 關係。
  • 不操作 DOM。
  • 不儲存 localStorage。
  • 不決定選取後畫面如何呈現。
