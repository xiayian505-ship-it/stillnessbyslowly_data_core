Linear Story Reader｜線性故事閱讀控制器

版本 1.1.0。組合既有故事索引載入、事件播放與閱讀進度，提供逐格閱讀、跨小節、書籤恢復與完讀。每一個 events 項目是一格，不按字數拆分。

不負責文字轉譯、對話辨識、選項、遊戲戰鬥、畫面、CSS、動畫、網路／本機持久化。旁白與人名可由宿主依 view.event.type 和 view.event.speaker 呈現。

<script src="https://lib.stillnessbyslowly.com/state/story_manifest_loader.js"></script>
<script src="https://lib.stillnessbyslowly.com/state/story_event_player.js"></script>

公開全域為 SlowlyLinearStoryReader。單機離線使用時，請下載以上四支 JS 作為本機檔案並使用本機路徑；離線閱讀器不應引用 CDN。

公開 API

方法用途
create({ loader, player, progress })注入三個既有核心的實例。
await initialize(manifestSource)載入索引；有效書籤優先，否則從第一個未完成小節開始。
await next()下一格，必要時跨小節；末格後再呼叫一次才算完成。
await previous()上一格／上一小節末格；完成後可返回最後一個有內容的格。
await openSection(sectionId)開啟指定小節；空小節往後尋找有內容的小節。
await readFromStart()從第一個有內容的格重讀，不清除完讀紀錄。
getView()取得與內部隔離的閱讀狀態、事件及進度快照。
subscribe(listener)訂閱狀態並取得取消訂閱函式。

最小接線範例

const sections = {
  "chapter/a.json": {
    id: "first",
    events: [
      { id: "line1", type: "narration", speaker: "旁白", text: "門開了。" },
      { id: "line2", type: "dialogue", speaker: "甲", text: "你回來了。" }
    ]
  }
};
const baseUrl = "https://offline-reader.invalid/story-data/";
const loader = SlowlyStoryManifestLoader.create({
  baseUrl,
  fetcher: async function (url) {
    const base = new URL(baseUrl);
    const request = new URL(url);
    const path = request.origin === base.origin && request.pathname.startsWith(base.pathname)
      ? decodeURIComponent(request.pathname.slice(base.pathname.length)) : "";
    const data = sections[path];
    return { ok: Boolean(data), status: data ? 200 : 404,
      json: async function () { return data; } };
  }
});
const player = SlowlyStoryEventPlayer.create();
const progress = SlowlyStoryReadingProgress.create();
const reader = SlowlyLinearStoryReader.create({ loader, player, progress });

reader.subscribe(function (view) {
  // 宿主自行顯示 view.event.speaker / view.text，及保存 view.progress。
  console.log(view.state, view.event && view.event.speaker, view.text);
});
await reader.initialize({
  main: [{ id: "chapter", title: "第一章", sections: [
    { id: "first", title: "第一節", file: "chapter/a.json" }
  ] }], extras: []
});
await reader.next();

正式行為與限制

  • 空小節：自動標記已完成並略過；全書均為空時進入 complete，不顯示無內容的閱讀格。
  • 結尾：看到最後一格仍是 reading；再呼叫 next() 才進入 complete。重複 next() 不會循環。
  • 書籤：有事件 ID 時優先依 ID 恢復；ID 已失效時返回同小節第一格，view.recovery.reason 為 bookmark-position-missing，不使用舊 index 冒充。
  • 失效小節：若書籤指向的小節不存在，回到第一個未完成小節（全部完讀則維持完成），並提供 bookmark-section-missing。
  • 空小節書籤：略過後回報 bookmark-empty-section；恢復原因會在下一次主動導航後清除。
  • 操作鎖：同一實例非同步讀取期間的重複操作會被忽略，不排隊；已註冊的通知回呼若拋錯，將與核心狀態隔離。
  • 錯誤：無效索引、未知小節、讀取失敗與互動事件會拒絕並進入 error；保留先前書籤，宿主可呼叫 openSection() 或 initialize() 恢復。
  • 輸出：getView() 包含 state（idle／loading／reading／complete／error）、busy、error、recovery、event、text、章節和格數、progress。資料均為安全副本。
  • 持久化：核心不接觸 localStorage；宿主自行保存 view.progress，下次建構 SlowlyStoryReadingProgress.create(savedData) 即可恢復。

互動型 choice、challenge 事件不支援，並會明確報錯；不得悄悄略過。
