Combo Streak State｜使用說明

管理連續成功次數、歷史最佳連擊和可選的遊戲時間超時清零。

正式 HTTPS 引用順序

<script src="https://lib.stillnessbyslowly.com/state/combo_streak_state.js"></script>

以上為 GitHub Pages 完成部署後的預期路徑。若尚未上傳，網址不會自動存在。

公開 API

window.SlowlyComboStreakState，版本 1.0.0。

create({timeout_ms?}) → instance；instance.success(now_ms)；instance.failure(now_ms)；instance.check_timeout(now_ms)；instance.snapshot()；instance.reset({keep_best?})；instance.clear_best()。

參數與單位

timeout_ms 預設 null（沒有超時），設定時為非負毫秒；每次 success／failure／check_timeout 傳入宿主遊戲時鐘 now_ms，禁止時間倒退。

回傳結果

snapshot 為 {current_streak,best_streak,last_success_ms,latest_time_ms,timeout_ms}；check_timeout 回傳 {timed_out,state}；reset 預設保留 best_streak。

實際宿主接法

const combo = SlowlyComboStreakState.create({timeout_ms:1500});
combo.success(100);
combo.success(500);
combo.check_timeout(2000); // timed_out=true，current_streak=0
combo.reset(); // 保留本局最高連擊

錯誤／退化情境

非法時間／超時拋錯；到期條件採 elapsed >= timeout_ms；失敗清除當前連擊但保留最佳紀錄；reset 重新開始遊戲時鐘。

職責邊界、清理與限制

不判斷 Perfect／Miss、加分、排行榜、音效或實際啟動時鐘；由宿主傳入時間。

除了有狀態零件需在宿主結束局面時呼叫 reset()，其餘純運算 API 不保留 DOM 監聽器，也不需 destroy。所有輸入時間單位、可選依賴及限制以上述公開函式契約為準。
