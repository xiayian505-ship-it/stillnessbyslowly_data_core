minefield_rules｜使用說明

功能：只排除首次點擊格的掃雷布雷與八鄰域雷數

公開 API

`SlowlyMinefieldRules.create_board(options)`。

依賴與載入順序

data/random/random.js

<script src="https://lib.stillnessbyslowly.com/data/random/random.js"></script>
<script src="https://lib.stillnessbyslowly.com/game/grid/minefield_rules.js"></script>

以上是部署後的 HTTPS 絕對網址，必須先上傳新零件才會存在；依賴 JS 必須先載入。

輸入參數

`rows`、`columns`：正整數；`mines`：0 到格數−1；`first_position={r,c}`：合法首格；`random_int(lower,upper)`：可選，須回傳含端點的整數；預設直接使用 `SlowlyRandom.int`。

回傳結果

`{rows,columns,mines,first_position,grid}`，每格 `{mine:boolean,around:number|null}`，雷格的 `around=null`；棋盤的外層陣列與格子為唯讀。

宿主實際接法

const board = SlowlyMinefieldRules.create_board({
  rows: 6, columns: 8, mines: 8, first_position: { r: 2, c: 3 }
});
console.log(board.grid[2][3].mine); // false
// 開啟零格區域時，宿主可另以 SlowlyGridChainExpand.expand(...) 計算擴散。

限制與錯誤

**只保證首格沒有雷，不保證相鄰八格安全。** 不管理插旗、開格、勝負、音效；零格擴張使用既有 `SlowlyGridChainExpand`，不在此實作 BFS。

JS 會針對非法資料或缺少依賴明確拋出錯誤；宿主應自行 try/catch 處理使用者輸入。純計算零件沒有 destroy 生命週期；Undo 使用 clear 清空歷史。外觀、聲音與動畫完全由宿主控制。
