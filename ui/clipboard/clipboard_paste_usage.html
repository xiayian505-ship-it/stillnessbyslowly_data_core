Clipboard Paste

只負責讀取剪貼簿文字，或貼入指定 input / textarea。瀏覽器可能要求 HTTPS、權限與使用者操作。

載入

<script src="https://lib.stillnessbyslowly.com/ui/clipboard/clipboard_paste.js"></script>

API

const text = await SlowlyClipboardPaste.read();
await SlowlyClipboardPaste.paste("#text");

paste 會在目前選取範圍或游標位置插入文字，並觸發 input 事件。
