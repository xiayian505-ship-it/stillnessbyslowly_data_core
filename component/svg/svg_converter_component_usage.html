Slowly SVG Converter Component｜使用說明

本完成品負責 SVG 預覽與 PNG／GIF／影片輸出的操作組裝；不改寫底層零件。宿主可以自行覆蓋版型、色彩、字型、設定與匯出後處理方式。

最小組裝範例

<div id="svg_converter"></div>
<script>
const converter = SlowlySVGConverterComponent.mount("#svg_converter", {
    width: 320,
    duration_seconds: 2,
    frames_per_second: 10,
    transparent: true,
    on_export(result) {
        console.log(result.file_name, result.blob);
    }
});
// 也可由宿主程式載入：
// await converter.load_text(svg_xml_string, "example.svg");
// const gif_blob = await converter.export_gif();

</script>

公開 API：window.SlowlySVGConverterComponent

  • mount(target, options?)：target 是容器元素或 CSS 選擇器；回傳完成品實例。
  • instance.load_file(file)、await instance.load_text(svg_text, name?)：載入本機檔案或字串，回傳狀態。
  • instance.set_zoom(number)、await instance.replay()：預覽縮放與重播。
  • await instance.export_png()、await instance.export_gif()、await instance.export_video()：回傳 Blob，並在完成品結果區提供預覽／下載連結；不自動下載。
  • instance.cancel_export()：對 GIF 擷取／影片錄製發出取消；PNG 完成當前擷取後停止提交結果。GIF 編碼本身是既有同步工作的非即時取消限制。
  • instance.get_state()：取得目前檔案、支援格式、匯出可用狀態與工作狀態。
  • await instance.clear()、await instance.destroy()：等待工作中斷、回收 Blob URL 與內部 SVG 擷取節點；destroy 會清空該容器。

設定 options

  • width：預設輸出寬度；宿主可從 UI 修改，預設 480。
  • duration_seconds：GIF／影片時長，預設 2，允許大於 0 至 60 秒。
  • frames_per_second：GIF／影片 FPS，預設 10，允許 1～60。
  • transparent：預設 true。影片即使不填底色，其實際 alpha 支援仍取決於編碼器，建議影片選不透明背景。
  • background：不透明背景色，預設 #ffffff；由 Frame Extractor 驗證。
  • maximum_upload_bytes：SVG 大小限制，預設 8 MiB。
  • maximum_frame_bytes：GIF 全部 RGBA 影格的最大記憶體，預設 96 MiB。
  • maximum_output_dimension：最大寬／高，預設 2048；Frame Extractor 最高仍為 4096。
  • zoom：預覽初始滑桿倍率，完成品操作介面提供 25%～400%。
  • show_controls：設為 false 隱藏右側轉檔設定；仍可透過 API 呼叫。
  • on_state(state)、on_error(error)、on_export({blob, extension, mime_type, file_name})：宿主回呼。

輸出流程與安全限制

Viewer 採 <img> 安全預覽；Frame Extractor 使用隔離 Shadow DOM 取得 CSS／SMIL 狀態，驗證規則更嚴格。若來源只通過 Viewer 而未通過 Extractor，仍能預覽但不能轉檔，完成品會顯示原因。

PNG：Extractor.capture → SlowlyCanvasPNG.toBlob；GIF：Extractor.capture_frames → SlowlyGIFEncoder.encode；影片：CanvasVideoExport.create，透過 draw_frame 回呼擷取每一幀，再交給既有 MIME、MediaRecorder、RecordedChunks 零件。

GIF 因為需要保存所有原始 RGBA 影格，可能很耗記憶體；請減少寬度／FPS／時長。影片依瀏覽器實際支援顯示 WebM 或 MP4 選項，不包含 MP4 轉碼。錄影是即時錄製，所需時間約等於選定的秒數。複雜 SVG path morph、腳本動畫、外部字型和其他不支援來源不保證能還原。

文件、預覽和匯出在使用者本機瀏覽器處理，不需上傳伺服器。是否上傳輸出由宿主自行實作。完成品不會設定全站 body、字型、背景或品牌配色；可以直接覆蓋 component/svg/svg_converter_component.css 的選擇器。
