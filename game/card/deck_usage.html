Deck

通用牌庫循環核心，管理抽牌堆、手牌與棄牌堆。模組只負責項目在三個區域之間的流動；卡片資料、使用條件、效果、戰鬥規則、UI 與儲存方式都由宿主決定。

基本使用

<script src="./deck.js"></script>
<script>
  const deck = Deck.create({
    items: myCards,
    handSize: 4
  });

  deck.drawToHand();
  deck.discardAt(0);

  const savedDeck = deck.snapshot();

  // 之後可把同一份快照還原回 Deck。
  deck.restore(savedDeck);
</script>

建立選項

選項用途預設
items宿主提供的任意項目陣列；也接受 cards。[]
handSizedrawToHand() 預設補到的手牌數。0
recycleDiscard抽牌堆空時是否自動回收棄牌堆。true
shuffleOnReset建立／重設牌庫時是否洗牌。true
shuffleOnRecycle棄牌堆回收時是否洗牌。true
random宿主可傳入自訂亂數函式。Math.random

API

reset(items?)重建抽牌堆並清空手牌、棄牌堆；未傳入新資料時使用目前保存的原始項目。
restore(snapshot)還原 snapshot() 產生的牌庫狀態，不洗牌、不抽牌、不回收棄牌堆；回傳 Deck 實例。
shuffle()洗目前的抽牌堆。
recycle()手動把棄牌堆移回抽牌堆。
draw(count)抽指定數量到手牌，回傳實際抽到的項目。
drawToHand(size?)把手牌補到指定數量。
discardAt(index)把指定手牌位置移到棄牌堆。
discardItem(item)依項目參照找到手牌並棄掉。
discardAll()把全部手牌移到棄牌堆。
setHandSize(size)修改預設手牌數。
snapshot()取得 sourceItems、drawPile、hand、discardPile、handSize 的快照。

存檔與還原

snapshot() 只建立牌庫狀態快照，Deck 本身不決定存到 localStorage、IndexedDB、資料庫或其他儲存層。

const saved = deck.snapshot();

// 儲存方式由宿主決定。
localStorage.setItem("battle-deck", JSON.stringify(saved));

// 讀回後再交給 Deck 還原。
const restored = JSON.parse(localStorage.getItem("battle-deck"));
deck.restore(restored);

Deck 1.1.0 的快照會另外保存 sourceItems。因此還原後再次呼叫 reset()，仍可回到存檔時所屬的原始牌組。舊版 1.0.0 快照若沒有 sourceItems，仍可還原 draw pile、hand、discard pile 與 handSize，但之後的 reset() 會沿用目前 Deck 實例既有的原始項目。

快照採陣列淺拷貝；項目本身的資料格式與序列化能力仍由宿主負責。
