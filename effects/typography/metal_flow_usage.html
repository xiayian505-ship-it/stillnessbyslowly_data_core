Slowly Typography｜Metal Flow 三顆零件

三支 CSS 互相不依賴。可以單吃，也可以由宿主自由組裝。

1. Metallic Text

<link rel="stylesheet" href="./metallic_text.css">

<span class="slowly-metallic-text">METALLIC</span>

只負責金屬材質，不負責任何動畫。

2. Text Gradient Flow

<link rel="stylesheet" href="./text_gradient_flow.css">

<span class="slowly-text-gradient-flow">FLOW</span>

只負責讓文字內的漸層移動。可由宿主用 --slowly-text-gradient 換成任意漸層。

3. Text Reflection

<link rel="stylesheet" href="./text_reflection.css">

<span
  class="slowly-text-reflection"
  data-text="REFLECTION"
>REFLECTION</span>

只負責反光帶。因為使用偽元素覆蓋原文字，宿主需同步提供 data-text。

三顆一起組裝

<span
  class="
    slowly-metallic-text
    slowly-text-gradient-flow
    slowly-text-reflection
  "
  data-text="SBS | MATCH3_V1"
>SBS | MATCH3_V1</span>

Match3 目前的感覺可由宿主設定兩個動畫皆約 18 秒：

.game-title{
  --slowly-text-flow-duration:18s;
  --slowly-reflection-duration:18s;
}
