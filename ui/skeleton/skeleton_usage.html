Skeleton 使用說明

用途：靜態占位 CSS，不是 Loader Progress；prefers-reduced-motion 下禁用 pulse 動畫。

載入（部署後 HTTPS 絕對路徑）

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/ui/skeleton/skeleton.css">

公開 API

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/ui/skeleton/skeleton.css">

輸入／設定：類別 slowly-skeleton＋ slowly-skeleton--line／--block／--circle，選配 --pulse；CSS 變數 width、height、size、color 可由宿主改。

實例操作：沒有 JS API；宿主切換 aria-busy、骨架與正式內容的 hidden 狀態

宿主接法示例

<section aria-busy="true"><span class="slowly-skeleton slowly-skeleton--circle" aria-hidden="true"></span><span class="slowly-skeleton slowly-skeleton--line slowly-skeleton--pulse" aria-hidden="true"></span></section>
<!-- 等宿主資料真正載入完成後，移除骨架並將 aria-busy 改為 false；不需 skeleton.js。 -->

生命週期與限制

靜態占位 CSS，不是 Loader Progress；prefers-reduced-motion 下禁用 pulse 動畫。

新 JS 使用 IIFE 並提供 window.（無）；錯誤 DOM／參數會明確報錯。不同宿主負責提供 UI 樣式、文字、實際業務操作，銷毀實例時清除監聽器和計時器。

部署前新網址只是預定位置；若還沒把檔案上架，請先以 ZIP 的相同路徑部署。若在本機測試，可使用測試伺服器映射同路徑。

提醒：這批不會複製已有的 Toast、Confirm、Tabs、Custom Select 或 Loader Progress；現有零件保留原樣。
