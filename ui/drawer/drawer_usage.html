Drawer 使用說明

用途：同一支 JS 支援 Hamburger（左右）及 Bottom Sheet（底部）；只在獨立把手開始下滑；不做多段停靠、路由或全域捲動鎖。

載入（部署後 HTTPS 絕對路徑）

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/ui/drawer/drawer.css">
<script src="https://lib.stillnessbyslowly.com/ui/drawer/drawer.js"></script>

公開 API

SlowlyDrawer.create({ dialog, trigger, handle, placement, close_on_backdrop, swipe_to_close, swipe_threshold, on_open, on_close })

輸入／設定：dialog 必須為 HTMLDialogElement；trigger/handle 為宿主 DOM（handle 須在 dialog 內）。placement=left/right/bottom；下滑閾值預設 70px。

實例操作：open()、close(reason?)、toggle()、is_open()、destroy()

宿主接法示例

<button id="open_nav">打開導覽</button><dialog id="nav_panel"><nav>宿主連結</nav></dialog>
<script>const drawer = SlowlyDrawer.create({trigger:'#open_nav',dialog:'#nav_panel',placement:'left'}); /* drawer.close(); drawer.destroy(); */</script>

生命週期與限制

同一支 JS 支援 Hamburger（左右）及 Bottom Sheet（底部）；只在獨立把手開始下滑；不做多段停靠、路由或全域捲動鎖。

新 JS 使用 IIFE 並提供 window.SlowlyDrawer；錯誤 DOM／參數會明確報錯。不同宿主負責提供 UI 樣式、文字、實際業務操作，銷毀實例時清除監聽器和計時器。

部署前新網址只是預定位置；若還沒把檔案上架，請先以 ZIP 的相同路徑部署。若在本機測試，可使用測試伺服器映射同路徑。

提醒：這批不會複製已有的 Toast、Confirm、Tabs、Custom Select 或 Loader Progress；現有零件保留原樣。
