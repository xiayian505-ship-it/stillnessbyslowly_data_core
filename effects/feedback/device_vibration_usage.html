Device Vibration｜裝置震動

將瀏覽器 Vibration API 包裝成可重用的獨立積木。不是音效，也不是畫面晃動。

一、職責與限制

只負責檢查裝置是否提供震動能力、播放宿主提供的節奏、啟用與停用及停止震動。

不內建攻擊、治療、勝利等事件名稱，不儲存選項、不建立 UI、不播放聲音。

瀏覽器是否真的震動取決於裝置與瀏覽器政策；桌面瀏覽器和部分手機瀏覽器不支援，即使回傳 true 也不代表能量測到實際馬達運作。

二、HTTPS 絕對路徑

<script src="https://lib.stillnessbyslowly.com/effects/feedback/device_vibration.js"></script>

本零件沒有 CSS 依賴；是否顯示震動控制鈕，以及控制鈕樣式，完全交給宿主。

三、公開 API

全域名稱：SlowlyDeviceVibration

函式說明
isSupported()查詢瀏覽器是否提供原生 Vibration API。
create(options?)建立獨立實例。可設定 enabled 與 skipWhenHidden（皆預設 true）；vibrationFunction 僅供測試替身或特殊介接。
instance.play(pattern)播放正整數或非負數的毫秒數；陣列交替表示震動、停頓、震動。回傳瀏覽器是否接受要求。
instance.stop()送出 0 毫秒，請求取消目前震動；即使停用實例也能呼叫。
instance.setEnabled(boolean)切換啟用狀態。關閉時會要求停止震動；不寫入 localStorage。
instance.isEnabled()讀取該實例的啟用狀態。
instance.isSupported()查詢該實例是否有震動介面；測試替身可支援模擬。

四、最小使用範例

const vibration = SlowlyDeviceVibration.create({
  enabled: true,
  skipWhenHidden: true
});

button.addEventListener("click", function () {
  // 宿主決定何時觸發，以及傳入哪個節奏。
  vibration.play([45, 55, 75]);
});

// 宿主自己的設定介面負責保存偏好。
vibration.setEnabled(false);
vibration.stop();

震動通常需要使用者互動才能觸發。失敗或不支援時，play() 回傳 false，不影響宿主流程。

傳入負數、NaN、無限大、非數字或空陣列屬於程式使用錯誤，會拋出明確例外。

五、驗收

Demo 展示：可在支援的手機上直接點擊測試震動，並提供停用與停止按鈕。

功能測試：使用模擬震動函式檢查 API，避免測試時讓手機不斷震動。
