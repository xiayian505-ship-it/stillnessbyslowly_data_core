Focus Confirm｜聚焦後確認

首次選取只聚焦、第二次相同 ID 才確認；不需要限時雙擊、不綁 DOM。

載入方式

將以下 URL 作為 script src，並按需要先載入既有依賴：

https://lib.stillnessbyslowly.com/state/focus_confirm.js

本 ZIP 是待合併更新包，URL 代表部署後的預定位置，並非已確認在線。

公開全域 API

SlowlyFocusConfirm｜1.0.0

方法說明
create({items})傳入唯一且非空的字串 ID 陣列，可為空。
select(id)回傳 {status: focused|confirmed|invalid, id, focused}。
getFocused()回傳目前聚焦的 ID 或 null。
clear()清除聚焦狀態。
setItems(ids)更新可選 ID；移除被聚焦 ID 時自動清除。
destroy()清除資料並標記銷毀，之後不可操作。

最小使用範例

const menu = SlowlyFocusConfirm.create({ items: ["story", "start"] });
menu.select("start"); // focused
menu.select("start"); // confirmed
menu.clear();

依賴、限制、宿主責任

完全不依賴 DOM、不提供導覽、也不要求 dblclick 的連點時間。無效 ID 回傳 invalid 並保留焦點。與 Tree Selection／Action Menu 的职责不同，適合多個獨立選單實例。
