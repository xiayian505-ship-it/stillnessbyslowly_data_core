Klondike Draw 1｜使用說明

慢慢軍火庫的傳統接龍完成品，固定翻1張。包含隨機開局、七欄發牌、合法移牌、回收牌、翻牌與棄牌回收、主動結束、勝利判定及末盤自動收牌。無資料庫、UID、存檔、音效或特效。

HTTPS 引用方式

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/component/solitaire/Klondike/Klondike.css">
<div id="my-klondike"></div>
<script src="https://lib.stillnessbyslowly.com/game/card/deck.js"></script>
<script src="https://lib.stillnessbyslowly.com/component/solitaire/Klondike/Klondike.js"></script>
<script src="https://lib.stillnessbyslowly.com/component/solitaire/Klondike/KlondikeDraw1.js"></script>
<script>
  const game = window.SlowlyKlondikeDraw1.mount("#my-klondike");
</script>

先載入軍火庫 Deck 積木，再載入共用核心 Klondike.js，最後載入本難度入口。全部是 HTTPS 絕對路徑。

基本規則

使用 52 張牌，七欄初始牌依序 1～7 張，僅頂牌朝上。移牌時必須紅黑交錯、點數由大到小，只有 K 可放空欄。牌庫每次翻1張到棄牌區，只能移動棄牌區頂牌；牌庫用完後可將剩餘棄牌收回再翻（不重新洗牌）。回收格各按花色由 A 疊到 K，且回收格頂牌可移回牌桌。

當牌庫及棄牌都空了，所有牌桌剩餘牌均已翻開，且可依序直接放入回收格時，會自動回收並判定勝利。若尚需整理牌面則不會自動結束。

「結束遊戲」主動終止當局，不會發送勝利事件；結束或過關後可再隨機開始。

JavaScript API

const game = window.SlowlyKlondikeDraw1.mount("#my-klondike");
game.start();       // 隨機開局
game.draw();        // 每次翻1張，牌庫空時收回棄牌
game.end();         // 主動結束
game.getState();    // 取得獨立的目前狀態快照
game.destroy();     // 卸載

宿主事件

const host = document.querySelector("#my-klondike");
host.addEventListener("klondike:start", event => {});
host.addEventListener("klondike:draw", event => {});
host.addEventListener("klondike:move", event => {});
host.addEventListener("klondike:collect", event => {});
host.addEventListener("klondike:win", event => {});
host.addEventListener("klondike:end", event => {});

事件可冒泡，detail.draw 為本模式每次翻牌數，detail.moves 為目前步數。主動結束的 detail.reason 是 manual。

外觀

CSS 僅提供必要結構與不透明卡片，宿主可自訂 --skl-board-bg、--skl-card-bg、--skl-card-back、--skl-red、--skl-black、--skl-border、--skl-step-up 等 CSS 變數。Demo 不設定頁面底色。
