Action Pattern

通用循環行動模式核心。只負責保存 pattern、目前索引， 並依序回傳下一個 action；不執行攻擊、防禦、蓄力、動畫或任何遊戲效果。

引入

<script src="./action_pattern.js"></script>

基本使用

const pattern = ActionPattern.create(
  ["attack", "attack", "guard", "charge"],
  { fallback: "attack" }
);

pattern.next(); // "attack"
pattern.next(); // "attack"
pattern.next(); // "guard"
pattern.next(); // "charge"
pattern.next(); // "attack"

宿主決定 action 的意義

const action = pattern.next();

switch (action) {
  case "attack":
    doAttack();
    break;
  case "guard":
    doGuard();
    break;
  case "charge":
    doCharge();
    break;
}

Action Pattern 不知道 attack、guard 或 charge 是什麼；這些行動名稱與實際效果全部由宿主決定。

主要 API

  • ActionPattern.create(pattern, options)：建立循環模式。
  • next()：取得目前 action，並把索引移到下一格。
  • peek()：查看目前 action，但不移動索引。
  • reset(index)：重設目前索引，預設回到 0。
  • setPattern(pattern, { keepIndex })：替換 pattern。
  • setFallback(action)：設定空 pattern 時使用的 fallback。
  • getPattern()：取得 pattern 副本。
  • getIndex()：取得目前索引。
  • getState()：取得目前 pattern、index 與 fallback。
