Canvas Wrapped Text

依照目前 Canvas 字型的 measureText() 結果逐字換行，可限制最大行數。

載入

<script src="https://lib.stillnessbyslowly.com/Image/canvas/wrapped_text.js"></script>

直接繪製

ctx.font = '700 40px "Noto Serif TC", serif';

const result = SlowlyCanvasWrappedText.draw(
  ctx,
  title,
  58,
  88,
  704,
  58,
  2
);

console.log(result.lines);
console.log(result.endY);

只計算行

const lines = SlowlyCanvasWrappedText.buildLines(
  ctx,
  text,
  704,
  2
);

API

SlowlyCanvasWrappedText.buildLines(ctx, text, maxWidth, maxLines?)
SlowlyCanvasWrappedText.draw(ctx, text, x, y, maxWidth, lineHeight, maxLines?)
