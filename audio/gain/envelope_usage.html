Audio Envelope

排程 AudioParam 的線性／指數變化，可用於 GainParam，也不限定只能處理音量。

最小使用

SlowlyAudioEnvelope.attack(gain.gain, {
  startAt: ctx.currentTime,
  duration: 0.01,
  from: 0.0001,
  to: 0.12
});
SlowlyAudioEnvelope.release(gain.gain, {
  startAt: ctx.currentTime + 0.01,
  duration: 0.08,
  from: 0.12,
  to: 0.0001
});
