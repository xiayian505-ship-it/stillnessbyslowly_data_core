Slowly Elapsed Format v1.0.0

通用經過時間格式化核心。輸入毫秒，輸出不限制 24 小時的 HH:MM:SS。

載入

<script src="https://lib.stillnessbyslowly.com/date/timer/elapsed_format.js"></script>

基本使用

SlowlyElapsedFormat.formatHMS(0);          // 00:00:00
SlowlyElapsedFormat.formatHMS(3723000);    // 01:02:03
SlowlyElapsedFormat.formatHMS(90061000);   // 25:01:01

邊界

負數、Infinity、NaN 或無法轉成有限數字的值會以 0 處理；毫秒的小數部分會向下取整到整秒。

刻意不負責

不建立計時器、不排程更新、不讀寫 DOM、不處理日期／時區，也不決定何時開始、暫停或停止。
