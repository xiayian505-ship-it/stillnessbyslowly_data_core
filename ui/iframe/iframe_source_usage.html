Iframe Source

只負責讀取、設定與清除既有 iframe 的 src。不建立 iframe、不處理顯示／隱藏、不管理 History，也不處理 postMessage。

載入

<script src="https://lib.stillnessbyslowly.com/ui/iframe/iframe_source.js"></script>

HTML

<iframe id="viewer" title="內容"></iframe>

設定來源

SlowlyIframeSource.set("#viewer", "story.html");

讀取來源

const src = SlowlyIframeSource.get("#viewer");

清除來源

SlowlyIframeSource.clear("#viewer");

也可以傳入 iframe 元素

const viewer = document.querySelector("#viewer");
SlowlyIframeSource.set(viewer, "story.html");

Public API

SlowlyIframeSource.get(target)
SlowlyIframeSource.set(target, url)
SlowlyIframeSource.clear(target)
