trick_taking_rules｜使用說明

功能：通用吃墩遊戲的跟首花色與本墩贏家／得分

公開 API

`SlowlyTrickTakingRules.legal_cards(hand,trick,options?)`、`resolve_trick(trick,options?)`。

依賴與載入順序

無（零件本體沒有其他軍火庫依賴）

<script src="https://lib.stillnessbyslowly.com/game/card/trick_taking_rules.js"></script>

以上是部署後的 HTTPS 絕對網址，必須先上傳新零件才會存在；依賴 JS 必須先載入。

輸入參數

`hand` 為 `{suit,rank}` 陣列；`trick` 為按出牌順序 `{player,card}` 陣列。`can_lead(card,context)`、`can_discard(card,context)` 決定 Hearts 等專用限制；`allow_when_none` 預設 true（沒有合法替代牌時回退）。結算可傳 `compare_rank(first,second)` 與 `score_card(card,play)`。

回傳結果

`legal_cards`：新的可出牌陣列；`resolve_trick`：`{winner,lead_suit,points,winning_card}`，空墩 winner=null。未自訂分數則所有牌 0 分；未自訂比牌則數值大者勝。

宿主實際接法

const hand = [{ suit: "H", rank: 2 }, { suit: "C", rank: 10 }];
const trick = [{ player: "A", card: { suit: "C", rank: 2 } }];
console.log(SlowlyTrickTakingRules.legal_cards(hand, trick)); // 僅 C10
const result = SlowlyTrickTakingRules.resolve_trick([
  ...trick, { player: "B", card: { suit: "C", rank: 10 } }
], { score_card: card => card.suit === "H" ? 1 : 0 });
console.log(result.winner); // B

限制與錯誤

Hearts 首墩梅花 2、不能先領紅心、首墩扣分牌限制應由宿主的 callback 控制；不寫死人數、不洗牌、不開新回合。

JS 會針對非法資料或缺少依賴明確拋出錯誤；宿主應自行 try/catch 處理使用者輸入。純計算零件沒有 destroy 生命週期；Undo 使用 clear 清空歷史。外觀、聲音與動畫完全由宿主控制。
