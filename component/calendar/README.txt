Slowly Calendar Component v1

檔案
- calendar_component.js
- calendar_component.css
- calendar_component_demo.html
- calendar_component_usage.html

定位
- 完整可呼叫萬年曆元件
- 不是多月/A4 Calendar Generator
- 不包含事件新增、編輯、刪除

顯示範圍
- month
- 3weeks
- 2weeks
- week

預設內容
- 西曆
- 農曆
- 國曆/農曆節慶
- 24 節氣

v1 Responsive
- 大：格內完整資訊
- 中：格內西曆 + 農曆，下方完整資訊
- 小：格內只留西曆，下方完整資訊
- 依 Component 容器寬度判斷

視覺
- 基礎中性色
- 六日紅色
- CSS 上方有可改色 variables
- 格線可開/關

這是第一版實物，斷點、字級、格高、selected/today 強弱都應該看 Demo 後再調。
