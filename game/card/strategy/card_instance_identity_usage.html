卡牌實體身分｜使用說明

分辨卡種和實體卡，建立實體卡、查找、依卡種分組及找出重複身分。

一、職責與界線

分辨卡種和實體卡，建立實體卡、查找、依卡種分組及找出重複身分。

宿主負責產生唯一的實體卡 ID、決定卡種資料及保存方式；本零件不提供 UUID 產生器或收藏系統。

二、相依與載入

無。

三、公開 API

全域物件：CardInstanceIdentity。名稱、參數與回傳結果以此頁和實際原始碼為準。

函式行為與結果
createCardInstance(cardDefinition, instanceIdentifier, instanceProperties?) 以宿主提供的卡種資料與唯一身分建立新卡物件；不修改來源。
findByInstanceId(cardCollection, instanceIdentifier, options?) 依實體 ID 查找卡牌，找不到回傳 null。
groupByCardType(cardCollection, options?) 依卡種分組，回傳 Map。
findDuplicateInstanceIds(cardCollection, options?) 列出重複出現的實體 ID。

四、最小使用範例

const firstCard = CardInstanceIdentity.createCardInstance(
  { cardId: "stone", name: "石之卡" },
  "instance-001"
);

const secondCard = CardInstanceIdentity.createCardInstance(
  { cardId: "stone", name: "石之卡" },
  "instance-002"
);

const groups = CardInstanceIdentity.groupByCardType([firstCard, secondCard]);
console.log(groups.get("stone").length); // 2
