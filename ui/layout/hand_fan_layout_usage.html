可操作 Demo 功能測試

動態扇形手牌排列｜使用說明

依宿主卡片數量、卡片寬度及容器寬度，計算扇形角度、上下錯位與重疊距離；不創建卡片，也不判斷出牌。

一、負責什麼

排列宿主已存在的卡片元素，並維持獨立的選取視覺狀態。ResizeObserver 偵測容器寬度變化；增減卡片後由宿主呼叫 refresh()。

二、不負責什麼

不提供卡牌美術、牌庫、手牌資料、出牌判斷、滑鼠點擊邏輯或永久儲存。原有 effects/hover/card_fan.css 保持不變。

三、宿主使用 HTTPS 絕對路徑引用

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/ui/layout/hand_fan_layout.css">
<script src="https://lib.stillnessbyslowly.com/ui/layout/hand_fan_layout.js"></script>

在正式部署前，隨包提供的測試頁及 Demo 使用同資料夾的檔案驗收，不需要先上傳或依賴尚未發布的 HTTPS 網址。

四、HTML 結構

<div id="myHand" aria-label="手牌">
  <button type="button" data-hand-fan-card>卡片 A</button>
  <button type="button" data-hand-fan-card>卡片 B</button>
  <button type="button" data-hand-fan-card>卡片 C</button>
</div>

五、JavaScript 使用範例

const hand = SlowlyHandFanLayout.create("#myHand", {
  maxFanAngle: 30,     // 首尾總角度差（度）
  edgeDrop: 20,        // 越靠近兩端越往下（px）
  selectedLift: 38,    // 已選卡片上浮量（px）
  hoverLift: 18,       // 滑鼠懸停或鍵盤聚焦上浮量（px）
  minimumSpacing: 24,  // 窄容器的最低卡片中心間距（px）
  maximumGap: 8        // 寬容器中卡片間最多額外留的空隙（px）
});

// 宿主決定選牌行為；零件只改變卡片的視覺狀態。
hand.setSelected(1);
hand.setSelected(null);

// 宿主新增、移除或更換卡片後：
hand.refresh();

// 可以在不改卡片資料的情況下調整扇形角度。
hand.updateOptions({ maxFanAngle: 44 });

// 移除使用時清除 Observer 與本零件設定的樣式。
hand.destroy();

六、公開 API

瀏覽器全域物件：SlowlyHandFanLayout。不要從檔案名稱猜 API。

名稱用途或回傳值
create(target, options?) 傳入 CSS selector 或 HTMLElement；同一根元素重複初始化回傳原實例。
instance.refresh() 重算目前直屬卡片的布局，回傳 { count, spacing }。
instance.setSelected(index | null) 指定卡片索引（由 0 開始）；null 取消選取，回傳目前索引。
instance.selectedIndex 目前選取的卡片索引，沒有時為 -1。
instance.updateOptions(options) 更新部分布局參數並重新排列。
instance.destroy() 取消監聽、復原本零件改動的 class、樣式及選取屬性。

七、重要限制與宿主責任

所有卡片需是容器的直屬子元素，且標記 data-hand-fan-card；建議同組卡片的可見寬度一致。卡面寬高與外觀由宿主設定。容器太窄且卡片太多時，仍可能產生重疊，宿主應視需要調整卡片尺寸、最低間距或改用其他排列方式。

八、驗收與展示

Demo 可以互動操作， 功能測試 在瀏覽器中列出 PASS／FAIL。 兩種頁面職責獨立，且均不屬於 JS 零件本體。
