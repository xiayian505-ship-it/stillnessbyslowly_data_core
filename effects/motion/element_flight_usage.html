元素飛行動畫｜使用說明

將來源元素的視覺副本沿弧線飛往指定目標。只做動畫，原始 DOM 不移動；不綁定攻擊、治療或遊戲結果。

一、負責什麼

量測來源與目標的視窗座標，建立不參與互動的視覺副本，使用 Web Animations API 飛行並清理副本。

二、不負責什麼

不替宿主選擇角色、不進行傷害計算、不播放聲音、不自動補命中特效，不修改來源元素與目標元素。

三、宿主使用 HTTPS 絕對路徑引用

<link rel="stylesheet" href="https://lib.stillnessbyslowly.com/effects/motion/element_flight.css">
<script src="https://lib.stillnessbyslowly.com/effects/motion/element_flight.js"></script>

在正式部署前，隨包提供的測試頁及 Demo 使用同資料夾的檔案驗收，不需要先上傳或依賴尚未發布的 HTTPS 網址。

四、HTML 結構

<button id="flightSource" type="button">飛出的卡片</button>
<div id="flightTarget">目標區域</div>

五、JavaScript 使用範例

const controller = new AbortController();

const result = await SlowlyElementFlight.play({
  source: "#flightSource",       // 也可以傳入 DOM Element
  target: "#flightTarget",
  duration: 470,                 // 毫秒
  arcHeight: 35,                 // 弧線中途向上位移（px）
  endScale: 0.25,                // 抵達時的縮放比例
  rotation: 9,                   // 末端旋轉度數
  signal: controller.signal      // 可省略
});

if (result.status === "finished") {
  // 若宿主需要提示、擊中動畫或遊戲事件，在這裡自行決定。
}

// 需要中途取消時呼叫：controller.abort();

六、公開 API

瀏覽器全域物件：SlowlyElementFlight。不要從檔案名稱猜 API。

名稱用途或回傳值
play({ source, target, ...options }) 回傳 Promise<{ status, reason? }>。source、target 必填。
duration 可選，預設 470 毫秒；0 表示立即略過動畫。
arcHeight 可選，預設 35px；中段上拋高度，可設負值。
endScale 可選，預設 0.25，飛行結束時副本縮放比例。
rotation 可選，預設 9 度；旋轉角度。
signal 可選 AbortSignal；中途取消時回傳 cancelled。

七、重要限制與宿主責任

status 可為 finished、cancelled 或 skipped（reason 如 reduced_motion_or_zero_duration、missing_geometry、animation_unsupported）。動畫只顯示複製節點；包含 canvas/video 之類特殊內容時，原生 cloneNode 並不保證複製影像畫面，宿主可傳入可複製的視覺替身。prefers-reduced-motion 或 Web Animations API 不可用時會直接略過；宿主仍應正常繼續自己的流程。

八、驗收與展示

Demo 可以互動操作， 功能測試 在瀏覽器中列出 PASS／FAIL。 兩種頁面職責獨立，且均不屬於 JS 零件本體。
