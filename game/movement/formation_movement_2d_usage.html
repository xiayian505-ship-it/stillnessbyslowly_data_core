Formation Movement 2D｜使用說明

整隊碰邊同步折返下移，與單體追蹤／反彈機制不同。

本頁是已編寫的使用說明；正式公開網址需在檔案上傳部署後才可使用。

職責與邊界

全隊任一有效矩形在下一幀碰及左右界線，就只下移一次、反向一次；不做碰撞、計分、Canvas 繪製或時間迴圈。來源靈感是小蜜蜂的 moveEnemies()，但改為不突變純計算。

輸入參數

欄位意義
entities含 x/y/width/height 的矩形陣列；可有額外 id、active。
direction1 向右，-1 向左。
speed、delta_seconds非負有限數；相乘為本幀水平位移。
left_bound、right_bound、margin水平方向合法界線及兩側安全邊距。
drop_distance碰邊時整隊下移的非負距離。
is_active(entity,index)可選；預設 entity.active !== false。

回傳、細節與限制

{ entities, direction, bounced, displacement, active_count }。輸入陣列與每個物件均不直接修改；額外欄位為淺層複製，其內巢狀物件仍共用引用。無有效成員、速度 0、delta 0 不碰邊。單次位移跨越很遠時保守地只折返下移，不移動 X；宿主應控制合理步長。初始有效矩形若超出合法邊界就拒絕。

測試與部署

請先部署這支核心，再打開 可操作 Demo 與 PASS／FAIL Test。不依賴任何額外舊軍火庫腳本。

完整引用範例（部署後 HTTPS 絕對路徑）

<script src="https://lib.stillnessbyslowly.com/game/movement/formation_movement_2d.js"></script>
<button id="next_frame">下一幀</button>
<script>
let members = [{ x: 20, y: 10, width: 20, height: 20, active: true }];
let direction = 1;
document.querySelector("#next_frame").addEventListener("click", function () {
  const result = window.SlowlyFormationMovement2D.plan_step({
    entities: members,
    direction,
    speed: 100,
    delta_seconds: 0.016,
    left_bound: 0,
    right_bound: 500,
    margin: 6,
    drop_distance: 16
  });
  members = result.entities;
  direction = result.direction;
});
</script>
